# /owner-reviews — контур согласований с владельцем

Жёсткое правило уже стоит в `AGENT_GUIDE.md`: всё, чего агент хочет ОТ владельца, живёт ТОЛЬКО в
`interviews/` (или в названном документе очереди решений). Этот навык — ОПЦИОНАЛЬНЫЙ контур
сверху: интервью и исходящие черновики рендерятся локальным HTML, решения фиксируются с автором и
временем, отправки механически загейчены одобрением. Главный полевой урок — первым: **HTML — не
цель, а транспорт; цель — СТРАЖ** — правило места вопросов нарушал агент, который его знал, а
страж нашёл два никем не увиденных вопроса, висевших 5 и 13 дней.

KAIF фиксирует ИМЕНА и ИНВАРИАНТЫ; реализация — за агентом проекта. Ноль внешних зависимостей
поощряется прямо: полевой контур — мини-рендерер markdown ~100 строк, localhost-сервер на штатной
библиотеке, живущий секунды (отдал → записал → погас), штатные системные утилиты для
голоса/звука/уведомления/браузера; страница самодостаточна и открывается офлайн. Соблазн взять
генератор статики или UI-фреймворк велик, выигрыш нулевой.

## Порядок работ (выправлен полем: «наш был хуже»)

1. **Страж места вопросов** — не зависит ни от чего, приносит пользу сразу, показывает масштаб.
2. **Рендер + запись решения** — ядро; здесь же контракт метаданных.
3. **Гейт на стороне отправки** — делает одобрение механическим; без него страница — украшение.
4. **Сигнализация** — бесполезна раньше, чем есть что показывать.
5. **Накопление для автоциклов** — нужно ровно при включении практики в дневные/ночные циклы.
6. **Пилот на НАСТОЯЩИХ данных** — единственное, что ловит дефекты стыков.

**Критерий приёмки:** полный цикл рутины проходит **без единого уточнения в чате**. Не «страница
открылась», а «владелец одобрил, и агенту не пришлось ничего переспрашивать».

## Инварианты (норматив — без них контур разваливается)

- **I1. md — источник, HTML — производное. Всегда.** Страница собирается из документа и никогда не
  правится руками — иначе вторая правда, и следующая сессия с пустым контекстом не видит решений.
- **I2. Ответ записывается в ТРИ места:** обратно в исходный md (следующая сессия читает документ)
  · `<док>.decision.json` рядом (машинная сверка перед отправкой) · копия в архив решений с `by` и
  `at` (кто и когда решил). Имя файла решения ПРОИЗВОДНО от имени документа — общий файл решений
  затирается следующим интервью.
- **I3. Одобрение привязано к SHA-256 ТЕЛА, а не к клику.** Текст изменился после одобрения =
  одобрение аннулировано, проверяет машина. **И договоритесь о нормализации** — кто, на каком шаге
  и что срезает: самый дорогой полевой дефект — страница хэшировала байты файла, отправщик — текст
  после срезания хвостового `\n`; оба self-test'а зелёные, гейт отказывал бы на любом артефакте
  всегда. Поймал только сквозной пилот на реальных данных.
- **I4. Гейт стоит на стороне ОТПРАВКИ, fail-closed.** Отправляющий инструмент сам читает решение,
  требует `approved` именно у ЭТОГО артефакта, пересверяет хэш — и отказывает ненулевым кодом даже
  при явном `--apply`, если решения нет, стоит `rejected` или текст уплыл. Любое сомнение = отказ.
  Запрос никогда не самоодобряется по таймауту.
- **I5. Сигнал — следствие успешно открытой страницы:** зови владельца из рендерера, после того как
  страница поднялась; иначе класс «позвали, а показать нечего».
- **I6. Тишина перебивает всё**, включая явно запрошенный голосовой уровень: автоцикл → тихие часы
  → настройка. Окно ПЕРЕСЕКАЕТ ПОЛНОЧЬ (напр. 23:00–09:00) — наивное `from <= now <= to` молчит
  весь день и звучит всю ночь; это сравнение заслуживает отдельного стража.
- **I7. Автоциклы накапливают, а не блокируются.** Флаг «в очередь» кладёт документ в папку
  ожидания; одна страница «Накопилось N» (каждая карточка ведёт на свой документ) зовёт владельца
  ОДИН раз на пачку. Без этого практика несовместима с дневными/ночными циклами.

## Контракт имён (кандидат, обкатан на четырёх продуктовых рутинах)

Блок метаданных в шапке документа (огороженный YAML): `title` · `kind` (интервью / черновик
внешней отправки / …) · `artifacts:` — список одобряемых тел, каждое `{id, target («Slack ·
#канал»), format, body_file}`. **`body_file` — ССЫЛКА, не копипаста**: страница показывает ровно
те байты, которые уйдут наружу, и хэш считается по ним же; копия в метаданных — вторая правда,
ломающая I3. Запись решения: `kind, document, by, at, comment` + `artifacts: {<id>: {status,
sha256}}` для черновиков / `answers: {Q1: {choice, text, comment}}` для интервью. `by` — не
украшение: именно оно делает архив читаемым спустя месяцы.

## Грабли (по убыванию цены)

1. Хэш без договорённости о нормализации → гейт отказывает всегда при зелёных самопроверках (I3).
2. **Инструмент построен — агент им не пользуется:** в день запуска страницы агент пересказал
   вопросы в чате — чат дешевле в моменте. Инструмент ВНЕДРЁН, только когда в ритуале есть
   исполняемая команда, показывающая нарушения («покажи ВСЕ неотвеченные интервью одной
   страницей»).
3. **Exit 0 ≠ человек получил сигнал** — нативные уведомления молча глушатся настройками фокуса ОС
   при успешном коде возврата. Сигналу, который обязан дойти, — путь, не зависящий от настроек
   пользователя; доставка подтверждается У ЧЕЛОВЕКА, не по exit-коду.
4. **Фикстуры не ловят живые документы** — три дефекта рендерера нашлись только на реальных файлах
   проекта. Прогон по ВСЕМ существующим документам — условие сдачи инструмента.
5. **Ложная тревога стража опаснее пропуска** — приучает игнорировать вывод; каждую закрывай своим
   стражем. Норма шума стража текстового правила ~10 ложных на 1 настоящую; исключения явные, с
   причиной в строке.
6. **Обе темы ОС** — тёмное-на-тёмном в блоках кода поймал владелец, не самопроверка.
7. **Регулярки не-ASCII:** в Node `\w`/`\b` — ASCII-only даже с флагом `u`; для кириллицы — `\p{L}`
   / `(?!\p{L})` с флагом `u`, иначе страж тихо не видит собственный язык.

## Параметры и совместимость

- Звук/TTS — ПАРАМЕТРЫ: имя голоса — параметр, а не меню (на полевой машине из 185 голосов рабочий
  один); тихие часы обязательны, не опциональны.
- Индустриальная четвёрка на странице: **Approve / Reject-с-причиной / Edit / Respond**; payload
  виден целиком; аудит-трейл хранит и отказы.
- Сила ответа не зависит от транспорта: **HTML = md = чат** — всё это слово владельца, фиксируемое
  с `by`/`at` (правило эквивалентности, `/interview`).
- Интервью без контура работает ровно как раньше — сахар никогда не становится обязанностью.
