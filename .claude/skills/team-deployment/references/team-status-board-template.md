# TEAM_STATUS — статус-доска команды <имя команды>

> Шаблон навыка KAIF `team-deployment`. Скопируй в корень ГЛАВНОЙ копии проекта как
> `TEAM_STATUS.md`, по строке на место одобренного дизайна. Правила — конституция команды
> (`TEAM_CONSTITUTION.md` § 4); этот файл несёт саму доску, правила её формы и КОНТРАКТ
> инструмента доски, который строит агент проекта.
>
> Доска — состояние В МОМЕНТЕ, прозрачное всей команде: агенты не перебивают друг друга,
> уважают чужую занятость и видят, где нужна помощь. Эстафету между сессиями по-прежнему несёт
> `STATUS.md` проекта; доска его никогда не заменяет.
> **Существующая ЖИВАЯ команда: иди adopt-путём навыка — не копируй этот шаблон поверх её доски
> и её инструмента;** инструмент, уже держащий контракт ниже, — совпадение, а не дефект.

## Доска

| Роль | Состояние | Что делаю | Жду | Обновлено |
|---|---|---|---|---|
| manager | 🟢 свободен | — | — | <метка> |
| <роль> | 🟢 свободен | — | — | <метка> |

*(«Что делаю» — одна короткая строка: что и по чьей постановке. «Жду» — АДРЕС того, кто
блокирует, или «—». «Обновлено» — каноническая метка момента проекта.)*

**Четыре состояния, и каждое — РОЛЬ с обязательством** (двух состояний не хватило: три места из
шести однажды стояли «занят», стоя на месте, а колонка «Жду» никого ни к чему не обязывала):

| Состояние | Смысл | Обязательство места | Обязательство Менеджера |
|---|---|---|---|
| 🟢 свободен | постановки в руках нет | доложить о готовности; взять следующую постановку | дать её или сказать «жди» |
| 🔴 занят | работает по названной постановке | «Что делаю» называет её; строка обновляется на каждом срезе | не перебивать (§ 2 п. 4) |
| 🟡 заблокирован | не может продолжать | «Жду» называет АДРЕС и предмет; одно сообщение держателю | реагировать на `audit-waiting` (п. 7 контракта) — заблокированное место есть очередь Менеджера |
| ⚫ офлайн | окно закрыто / сессия пропала | строка очищена на остановке (§ 9); замки отданы | снять строку и замки пропавшего места (переопределение только Менеджера) |

## Замки ресурсов

| Ресурс | Держатель | Взят |
|---|---|---|
| <ресурс-синглтон 1 из N> | — свободен — | — |

*(по строке на синглтон из § 7 конституции: стенд, эмуляторы, превью на портах… Взял → прогнал →
отдал; держать «на всякий случай» запрещено.)*

## Правила формы (из полевого заказа владельца — сохраняй)

- **Статусы краткие; документ не растёт** — строки ПЕРЕЗАПИСЫВАЮТСЯ, никогда не дописываются.
- Обновляй свою строку при КАЖДОЙ смене состояния: взял задачу · жду · освободился.
- Успехи и трудности — законное содержание статуса: так соседи видят, где помочь.
- Чтение доски перед сообщением кому-либо — часть регламента общения (конституция § 2 п. 4).

## Где живёт доска — состояние сессии ВНЕ git

Доска — состояние момента, а не история: она переписывается при каждой смене состояния, поэтому
ОТСЛЕЖИВАЕМАЯ git-ом доска делает дерево `main` грязным по построению (поле: 105 коммитов доски
за десять дней, 14 из них — только чтобы очистить дерево перед гейтом). Поэтому:

- **`TEAM_STATUS.md` — ignore-first** — одна строка в `.gitignore`, когда операция 3 её
  материализует (тот же класс, что `.kaif/refresh-marker.json` и heartbeat); она никогда не
  коммитится.
- **В ретроспективу едет снимок:** операция 5 копирует доску в том виде, в каком она стояла на
  конец смены, в документ ретроспективы — там и живёт её история.
- **Именованный опт-аут:** команда, которой нужна отслеживаемая доска (аудит-след, нет общего
  диска), вписывает опт-аут в § 4 конституции с названной ценой — грязное дерево при каждой
  смене состояния — и поимённо изымает доску из гейтов чистоты дерева.

## Инструмент доски — контракт (строит агент проекта)

KAIF фиксирует инварианты; реализация принадлежит агенту проекта, в стеке проекта.
Референс-реализация в полевом проекте-истоке — ~500 строк Node.js без зависимостей. Инструмент
ОБЯЗАН держать:

1. **Одна доска на команду.** Доска живёт в главной копии; инструмент, вызванный из ЛЮБОГО
   рабочего места, находит единственную настоящую доску (для git worktree — через общий
   git-каталог, например `git rev-parse --git-common-dir`, — никогда через локальный чекаут:
   доска-копия в каждом месте дала бы каждой роли личную доску, которую никто не читает).
2. **Роль вызывающего ВЫВОДИТСЯ из рабочего каталога** (инвариант именования, конституция § 1),
   а не передаётся заявлением. Инструмент правит ТОЛЬКО строку вызывающего и отказывает на
   чужих; снять зависшую строку пропавшей роли может только Менеджер явным флагом.
3. **Одновременные записи безопасны:** файловый замок рядом с доской (create-exclusive с
   ретраями; замок старше названного таймаута считается брошенным), запись атомарна
   (временный файл + rename).
4. **Строка замка называет держателя с его адресом**, где ресурс отображается на пер-ролевые
   параметры (порты, слоты): читатель обязан видеть, ЧЬИ порты заняли место — строки ёмкости
   (места) и адреса ролей (слоты) — разные вещи; их смешение — оплаченный полевой дефект.
5. **Метки — канонический формат момента проекта**, снятый инструментом у системных часов —
   никогда «сессия помнит».
6. **Доказан на сломанном случае до доверия** (канон тестирования проекта): правка чужой строки
   отвергнута; брошенный замок снят; два одновременных писателя не портят таблицу.
7. **`audit-waiting` — колонка ожидания кого-то обязывает.** Инструмент перечисляет каждую
   🟡 заблокированную строку и судит её: клетка «Жду» обязана называть место его АДРЕСОМ
   (совпадение по границам слова, понимающим письменность проекта, а не ASCII `\b`); названное
   место, которое не 🔴 занято, означает «над тем, чего ты ждёшь, никто не работает»; неназванный
   адресат означает «проверять нечего». Любая такая строка — ТРЕВОГА: ненулевой код выхода, и
   Менеджер реагирует раньше всего остального (переназначить, разблокировать или снять). Доказан
   красным на фикстуре с мёртвым адресатом и безымянным ожиданием.

Предлагаемая поверхность команд (имена адаптируй под проект):

```
<инструмент> set [--busy|--free|--blocked] [--doing "…"] [--waiting "<адрес>: …"]   # только моя строка
<инструмент> lock <ресурс> | unlock <ресурс>                      # замки синглтонов (N строк-слотов при ёмкости N)
<инструмент> show                                                 # напечатать доску
<инструмент> audit-waiting                                        # заблокированные строки судятся; exit ≠ 0 при тревоге
<инструмент> set --role <р> …                                     # только Менеджер: снять зависшую/офлайн строку
```
