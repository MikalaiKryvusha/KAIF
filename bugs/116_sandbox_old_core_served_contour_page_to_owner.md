## Root cause

1. **Генератор контура — единственная машинерия, обращённая к человеку**, и её действия по умолчанию — окно и голос.
2. **Свод гоняет генератор, который отстаёт от самого свода**, а такой генератор на незнакомый новый флаг отвечает действием по умолчанию: «показать документ». Два пути к этому: шов `KAIF_DIST` со СТАРЫМ ядром (четыре вечерних окна) и разработка, когда ассерт нового флага уже написан, а генератор его ещё не знает (утреннее окно `MtDf0m`). Тишина окружением закрывает оба: она не зависит от того, какую версию генератора запустил свод.
3. **`runGen` свода отдавал ребёнку полное окружение пользователя** — PATH с `cmd.exe` и `powershell.exe`, голосовой инструмент — и не ставил срока: старый сервер ждал человека бесконечно (I9).
4. **Заявления о побочных эффектах свода против ДРУГОЙ версии ядра выводились из сегодняшнего кода**, а не наблюдались на той версии: «без окна» было правдой для 2.7 и ложью для 2.6 — дважды (ответ владельцу в 23:10, промпт судьи в ≈ 23:58).
5. **Известный урок без механизма — главный корень класса.** Утром 2026-09-12 сессия 59 наступила на ровно этот класс и записала его из первых рук (EXP-0126, 10:05): свод до пересборки → старый генератор → страница и зов; урок назвал два механизма-кандидата — полигон отказывается стартовать на несвежем `dist` и генератор отвергает незнакомый флаг ДО подъёма страницы — и пометил их «none-cheap», кандидатами в 2.8 (`ideas/30` п. 15). Механизма не появилось, а сессия 63 урок не вспомнила: перед красными прогонами против старого ядра грепа `EXPERIENCE.md` по тегам `#contour #polygon` не было. Через тринадцать часов тот же класс сработал четыре раза. Это ровно правило журнала опыта: «повторившийся урок — урок, проваленный как текст … обязан стать исполняемым». Вред из песочницы теперь механизирован для любой версии генератора (`quietEnv()` + преполёт); корень поставки — отказ генератора на незнакомый флаг и полигон против несвежего `dist` — остаётся в `ideas/30` п. 15: он меняет отгружаемое поведение, и его место в версии решает владелец.

## Fix

- `tools/lib/sandbox-run.mjs` → `quietEnv()` и `QUIET_TIMEOUT_MS`: PATH указывает в несуществующий каталог рядом с node (в нём нет программ), `KAIF_VOICE_TOOL` / `KAIF_VOICE` вычеркнуты, `KAIF_CONTOUR_TICK_MS=300`, `KAIF_CONTOUR_SILENCE_MS=900`; node своды запускают абсолютным путём. Первая редакция брала каталог из `tmpdir()` по фиксированному имени — полигон покраснел стражем `bugs/59`, путь перенесён.
- **Селфтест тишины — и его собственная безвредность** (2026-09-13 01:11 +03:00). Первая редакция пробы запускала из тихого ребёнка `cmd.exe` · `powershell.exe` · `msedge` · `chrome` с аргументами `/c exit 0` и ждала ENOENT. Перечитывая её перед судом, я увидел близнеца инцидента внутри починки: сломайся тишина — браузер принял бы `/c`, `exit`, `0` за адреса и открыл окна, а на macOS `say` произнёс бы аргументы вслух; вдобавок `msedge` и `chrome` не лежат в обычном PATH, так что их ENOENT ничего не доказывал — генератор на Windows открывает окно только через `cmd.exe /c start`. Проба переписана: имена — ровно те, что генератор запускает по имени (Windows — `cmd.exe`, `powershell.exe`; macOS — `open`, `say`; Linux — четыре имени Chromium и `xdg-open`); каждое сначала ИЩЕТСЯ по PATH и рабочему каталогу ребёнка без запуска, и только две оболочки Windows затем реально запускаются — скрыто, с немедленным выходом. Зелёный: «cmd.exe=ENOENT powershell.exe=ENOENT». Красный на копиях скретчпада: реальный PATH → «cmd.exe=FOUND powershell.exe=FOUND» (ничего не запущено); реальный PATH без поиска → «cmd.exe=ran powershell.exe=ran» (скрыто, exit 0).
- Своды `s22` (`runGen`), `s12` (`run`) и проба `ic3` (`runNode`) — `env: quietEnv(), timeout: QUIET_TIMEOUT_MS`.
- Преполёт `tools/sandbox-suite.mjs` — `@guard sandbox-quiet-child`: файл свода или пробы, который запускает генератор контура дочерним процессом без `quietEnv(`, красит полигон поимённо; селфпруф на синтетическом источнике в каждом прогоне; долг нулевой — это ГЕЙТ.
- **Наблюдение на пути угрозы** (2026-09-13 00:30 +03:00): генератор 2.6 из дерева `2Hinbl`, копия каталога, `quietEnv()`, аргументы `interviews/interview_052_probe.md --check` → «Page is up: http://127.0.0.1:62581/» · «NO WINDOW OPENED — open it yourself» · «Window: none» · «CALL: beeps failed (no PowerShell?) — voice next.» · «CALL: system voice — engine not installed; beeps and banner did the call (I36).» · «Outcome: the page has been silent longer than 0.015 min (two strikes) — ending the contour» · `exit 2` за ~1 с. Экран владельца при этом не снимался — доказано, что запуск окна и звука невозможен, а не что экран пуст. Лог этого запуска не сохранён файлом: вывод цитируется из транскрипта сессии 63 (чат), в отчётах прогона строки у него нет.
- Своды: `s22` зелёный за ~7 с (раньше каждый запуск ждал 15-секундный такт вахты), `s12` зелёный, полигон «all 26 suites green» с новым преполётом (2026-09-13 00:32 → 00:35, лог скретчпада `polygon6.log`).
