## Root cause / Hypotheses

Ось имён событий (`s14:224-288`) писалась как ЛЕЧЕНИЕ `bugs/66` №4 и охват действительно ВЫЧИСЛЯЕТ — но
вычисляет по фиксированному ПАТТЕРНУ имени, а не по составу модуля; `bugs/66` в закрытии обещал «судятся
ВСЕ образцы, найденные в развёрнутом модуле». Ассерт формы писался как «флаг назван явно» и потому
проверяет присутствие подстроки, а не принадлежность значения домену. Таблица README появилась в фазе O5
как честный документ, и её честность была обещана человеком (`plans/60` критерий 4), тогда как страж был
обещан только ОБРАЗЦАМ (критерий 3). Общий корень — «страж, делящий слепое пятно с проверяемым»
(`bugs/66`, вхождение №1).

## Fix plan (or the fix, if done)

1. **F1:** в оси имён — «каждый `*.json` развёрнутого модуля» вместо `^sample-.*\.json$`;
   `settings-fragment.json` внести в `EVENT_CONTRACT` (источник — `researches/19` §Claude Code);
   добавить ассерт ПАРЫ «скрипт → событие» обходом ключей события, а не текста файла. Механизм «конфиг без
   названного контракта ПАДАЕТ» уже написан (`s14:265-268`) — перестать его обходить.
2. **F2:** сделать список форм машинно-читаемым (`--emit-list` или экспорт таблицы) и требовать РОВНОГО
   совпадения `--emit <shape>` с формами ИМЕННО запускаемого скрипта; на неизвестной форме — строка в
   stderr (stdout не менять, фолбэк сохранить).
3. **F3:** разобрать таблицу README машинно (строка → три ячейки → первый символ `✅/❌/⚠`) и выводить
   матрицу `must`/`mustNot` ИЗ НЕЁ, оставив `EVENT_CONTRACT` из разведки; ряды без образцов — одним
   объявленным списком. Вторая половина — сократить число истин: сегодня их три

4. Каждый фикс доказывается АДРЕСНОЙ мутацией: мутант M → краснеют ровно названные ассерты, и только они;
   нетронутый код → 0 красных.
5. НЕ трогать: `matcher === 'compact|clear'` (`s14:75`), присутствие трёх событий (`:73`), `mustNot`

   `command`+`args` фрагмента (долг `plans/73` п. 4), `EVENT_CONTRACT` и его источник.
