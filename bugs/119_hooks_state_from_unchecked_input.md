## Repro (deterministic)

Класс-условие: любой проект, где хук решает по значению из события или из файла-метки, не проверив его, и
свод подаёт хуку только чистые фикстуры.

1. `cwd`: копия модуля; корень со свежим маркером; `node <hook> < event.json`, где `event.json` несёт
   `"cwd":"<корень>"` → тишина; то же с `"cwd":"<корень>/src/deep"` → приказ «no refresh witness found
   this session». Страж STATUS: корень с `STATUS.md` старше 5 ч и грязным деревом → блок; `cwd` =
   подкаталог → тишина.
2. `at` в будущем: записать `{"at":"<now+2h ISO>","docs":[],"trigger":"hour"}`, состарить mtime файла на
   5 ч (`utimesSync`) → хук молчит; контроль `at` = 5 ч назад → приказ «last refresh 300 min ago».
3. BOM: подать то же событие с префиксом `\uFEFF` (буфером или файлом — НЕ строкой в argv, `EXP-0121`):
   `session-start-refresh` с `source:"clear"` → `"trigger": "compaction"` вместо `"ritual:/clear"`;
   `prompt-resume-word` с `prompt:"resume\n…"` → ПУСТО.

## Forensics

- Прогоны исполнителя 2026-09-18: 08:51 (будущий `at` → тишина; 2030-01-01 → тишина; контроль → приказ) ·
  08:53 (`cwd` корень → тишина, `cwd` `src/deep` → приказ; страж в подкаталоге → тишина) · 09:02 (BOM:
  `clear` без BOM → `ritual:/clear`, с BOM → `compaction`; `resume`-хук с BOM → тишина).
- Независимо у скептиков чистым контекстом: семь состояний `at` (включая `""`, `null`, отсутствие поля →
  приказ, то есть фолбэк работает и ровно поэтому будущее в него не попадает); таблица четырёх хуков с
  BOM и без; измеренные байты stdin из PowerShell 5.1 — `ef bb bf` для строки через пайп,
  `Write-Output`, `Get-Content` и `cmd /c "… < file"`; чистый только `cmd /c "echo … |"`.
- Живая улика по `cwd`: в ЭТОЙ сессии (worktree истока, хуки подключены в `.claude/settings.json`)
  событие с `cwd` рабочего дерева даёт приказ «no refresh witness», хотя маркер корня свеж (08:13:04).
- `grep -n "feff|BOM" tools/sandbox/s14-refresh-hooks.mjs` → 0 (ни один свод не подаёт хуку BOM);
  `utimesSync` в своде касается только `STATUS.md`.

## Root cause / Hypotheses

Все три — один корень: ВХОД хука объявлен доверенным. Шапки описывают предикаты в терминах «возраст
маркера», «работа сессии», «первое слово промпта», а код читает поля, которые пишет другая сторона
(агентская система, сам агент, оболочка), и не проверяет ни их семантику (`cwd` ≠ корень проекта), ни их
правдоподобие (`at` в будущем), ни их кодировку (BOM). Политика «непонятный ввод → дефолт/тишина, exit 0»
верна как правило живучести, но она же превращает любое непонимание в состояние, неотличимое от
неподключённого модуля. `EXP-0042` предупреждал ровно об этом: портируемость решает не событие, а ПОЛЕ —
и здесь поле есть, но означает не то.

## Fix plan (or the fix, if done)

1. **`cwd`:** искать корень ВВЕРХ от `cwd` (первый каталог с `.kaif/` или `STATUS.md`), либо читать корень
   из окружения, когда система его даёт (`CLAUDE_PROJECT_DIR`; у Grok — `workspaceRoot`/`GROK_WORKSPACE_ROOT`,
   `researches/19:154`), и только затем падать на `cwd`.
2. **`at`:** одна строка — `if (Number.isNaN(at) || at > Date.now() + 60_000) at = statSync(markerPath).mtimeMs;`
   (допуск на дребезг назван в комментарии).
3. **BOM:** снять ведущий U+FEFF перед `JSON.parse` в четырёх хуках — той же процедурой, что принята в
   `tools/commit.mjs:107`. **Класс шире четырёх хуков:** BOM не снимают и ридеры МАРКЕРОВ —
   `framework/hooks/prompt-refresh-timer.mjs:69`, `framework/tools/kaif-testrun-lint.mjs:178`,
   `framework/tools/kaif-voice-lint.mjs:317,323` — и `framework/installer/KAIF-CORE.mjs:3575`
   (`.kaif/kaif.json`), при том что `readJson` на `:149` ТОГО ЖЕ файла BOM снимает; плюс
   `KAIF-CORE.mjs:1811,3499`, `KAIF-LOADER.mjs:97`, `framework/tools/contour/review.mjs:805,1144`.
   Починка только хуков закрывает класс наполовину.
4. В `s14` — по ассерту на ось: событие с `cwd` = подкаталог даёт тот же вывод, что с `cwd` = корень;
   будущий `at` при старом mtime → приказ; событие в двух лицах (с BOM и без) → побайтно равный вывод.
   Каждый ассерт доказан снятием своего фикса.
5. НЕ трогать: фолбэк `cwd = process.cwd()` при нечитаемом stdin; «не краснеть там, где не наблюдаем»
   (не-git проект; проект без `STATUS.md`); фолбэк «битый `at` → mtime» и тишину на свежем маркере;
   политику exit 0 на любой внутренней ошибке.
