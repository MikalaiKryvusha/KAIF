# Bug 11 — Гейты проверяют не то свойство: ANON из CLI-флага, наличие вместо содержимого

**Status:** 🟡 partial (2026-07-27: ANON из маркера (=фикс GH#1) + скан плейсхолдеров по всем поверхностям + сверка зеркал + сфера + команда sync; хвост — валидация схемы маркера)
**Version/build:** 1.6 · **When/context:** 2026-07-27, метасинтез (`researches/07`, П4) —
отчёты 01, 02, 05, 06, 07, 08 + GitHub issue #1 (открыт 2026-07-17, воспроизводится в 1.6).

## Symptom

Пять граней одного класса — гейт судит не то свойство или не в том объёме:

1. **`check` берёт анонимность из CLI-флага, а не из маркера**: на анонимной установке без
   `--mode anonymous` — ложные «MISSING» по origin-tied артефактам (7 у отчёта 01, 18/20 у 02/08,
   exit 1), причём пункт `recheck` апдейт-задачи предписывает этот запуск — «инструкция фреймворка
   красит здоровое дерево», а слабую модель красный гейт **подталкивает развернуть origin-навыки и
   сломать анонимность** (отчёт 08). Это GitHub issue #1.
2. **`check` проверяет наличие/размер, не содержимое**: зеркало агент-системы с мусором проходит
   зелёным (отчёт 07); дрейф копий жил девять дней и релиз (отчёт 05: 92/113).
3. **`scanPlaceholders()` сканирует 2 поверхности** (AGENT_GUIDE + `.claude/skills/*`) из всех:
   плейсхолдеры в `.agents/…` (отчёт 01: 4 файла), `.grok/.cline/.roo` (отчёт 02, с 1.5!) и
   `.kaif/spheres/` (отчёт 06) проходят гейт.
4. **Сфера маркера не проверяется на существование библиотеки**: `sphere: game-design` при
   отсутствующей `.kaif/spheres/game-design.md` — «обязывающая инструкция указывает в пустоту»,
   fable-цикл без evidence set и таблицы фродов (отчёты 04, 01).
5. **Схема маркера не валидируется** («существует и непустой») — смену `agent`→`agents` в 1.5 не
   поймал бы ни один штатный гейт (отчёт 07, №5).

## Repro (deterministic)

При `"tracking": "anonymous"` в `.kaif/kaif.json`: `node .kaif/kaif-core.mjs check` →
«INCOMPLETE: N artifacts missing» (exit 1); с `--mode anonymous` → «manifest satisfied» (exit 0).
Код: `KAIF-CORE.mjs:41-42` (MODE/ANON только из CLI), `:632-633` (agents из маркера уже читается —
паттерн есть), `okOnDisk` (наличие/размер).

## Root cause

Гейты писались под свежую установку (один контекст, один вызов CLI) и не пересмотрены для жизни
ПОСЛЕ неё: контекст (tracking/agents/lang) живёт в маркере, а читается из argv; проверка «файл
есть» не эквивалентна «файл правильный» (EXP-0010 — тот же урок на производных поверхностях).

## Fix plan

(а) ANON производный: `MODE флаг || marker.tracking` — 3 строки (закрывает issue #1); (б) check
сверяет содержимое зеркал с каноном и плейсхолдеры по всему манифесту (`paths` + `agents`);
(в) проверка существования `.kaif/spheres/<marker.sphere>.md`; (г) схема маркера — один источник в
машинерии, валидатор читает её. Каждый страж — проверить на сломанной версии. В 2.0 эпик №1 это
фаза «гейты содержимого».

## Прогресс (2026-07-27, Фаза 1 плана 20)

Отгружено в ядро: (1) **ANON выводится из `tracking` маркера**, когда `--mode` не передан —
песочница S2: голый `check` на анонимной установке при живом бандле зелёный (репро issue #1 снят);
явный CLI-флаг сильнее маркера; (2) `scanPlaceholders()` кроет все зеркала (.agents/.grok/.cline/
.roo) и `.kaif/spheres/`; (3) `check` сверяет СОДЕРЖИМОЕ зеркал с каноном (предупреждение — между
update и update-verify зеркала законно отстают); (4) громкое предупреждение о заявленной сфере без
библиотеки (S2); (5) `resyncCopies` выставлен командой **`sync`** и не возвращает origin-tied
навыки анонимной установке. Осталось: схема маркера как источник истины валидатора — эпик №1
(карта модулей опишет схему). GH issue #1 можно закрывать при релизе 2.0 со ссылкой на фикс.
