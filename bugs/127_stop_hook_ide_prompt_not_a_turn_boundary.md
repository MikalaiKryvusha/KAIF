## Symptom

Посреди хода владелец написал четыре слова подряд; агент ответил на каждое отдельным ответом со строкой «⏩». Хук конца хода дважды вернул
ход с требованием «this response does not answer it yet» и списком из четырёх слов, два из которых были отвечены ответом раньше. Один раз
ход кончился молча: ответ стоял, последняя строка «⏩ Коммит `dist/` …» — работа не продолжилась, владелец написал «ты чего стоишь?».

## Forensics

Запись сессии 77 (`~/.claude/projects/…/<сессия>.jsonl`): все промпты владельца («го», «ты чего стоишь?», первый — вставленный текст)
записаны `type: "user"` с `promptSource: "sdk"`, `origin: {kind: "human"}` и `message.content` — **массивом** `[{type: "text", …}]`.
Строкой с источником — ни одного: строками записаны только отзывы хуков («Stop hook feedback: …», без источника, `isMeta`).
Результатов инструментов — 117, источника нет ни у одного.

## Root cause

`opensTurn` признавал началом хода только `typeof message.content === 'string'` — форму терминального клиента (наблюдена сессией 76 в
облаке). В IDE-клиенте граница не находилась: `start = -1`, весь хвост записи (4 МБ) — один ход. Отсюда (1) слова прошлых ходов требовались
снова; (2) ответ засчитывался только ПОСЛЕДНИМ ответом (`last_assistant_message`) — слово, отвеченное ответом раньше, снова «не отвечено»;
(3) под продолжением (`stop_hook_active: true`) блок «ответь» пропускается, а блок «продолжай» требует, чтобы неотвеченных не было, —
ход кончался молча.

## Fix

`opensTurn`: источник (`promptSource`/`origin`) И (строка ИЛИ массив с текстовым блоком). Ответ: слово засчитано, если его первые три слова
открывает любой текст ассистента после него в этом ходу или итоговый ответ из события. Мутанты: M19 (якорь обновлён), M32 (массив не
открывает ход), M33 (считается только последний ответ) — `tools/sandbox/probes/hooks-mutants.mjs`.
