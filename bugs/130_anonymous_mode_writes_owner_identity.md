# Bug 130 — Обезличенная установка (`--mode anonymous`) пишет git-имя владельца и логин в адресе репозитория в дерево, которое обещает обезличить

**Status:** 🔴 OPEN — заведён по полевому отчёту (тикет origin #135, находка R1), не воспроизведён у истока; разбор и починка — 2.10
(решение владельца №146: «остальное — в 2.10»; `ideas/32`).
**Severity:** S2 — личные данные владельца (имя и логин) попадают в дерево обезличенного проекта; страж обезличенности проекта поля
покраснел и поймал это до публикации.
**Version/build:** KAIF 2.8 (обновление 1.5 → 2.8, маршрут bootstrap с репетицией); на 2.9 не проверено.
**When/context:** сессия 84, 2026-10-16 15:08 +03:00 — разведка тикетов #133–#142 перед вопросом владельцу (интервью №044).
**Fixing:** после выпуска 2.9 (реестр 2.10).
**Fix accepted when (observable):**
- Ситуация. Проект с git-именем автора и адресом удалённого репозитория с логином внутри; установка KAIF `--mode anonymous`.
- Действие. Агент исполняет установку (или обновление обезличенного развёртывания).
- Результат. Ни в развёрнутых документах, ни в `.kaif/deploy-manifest.json` нет git-имени автора и логина из адреса репозитория.
- Проверка. Свод полигона с обезличенной установкой: `git grep -c "<имя из git config>"` по дереву → 0, в манифесте нет `@` в адресе; красный на 2.8.

## Symptom

Слова полевого отчёта (#135, R1, дословно): «anonymous mode writes the owner's git identity into the tree it promises to keep anonymous».
Рендер `AGENT_GUIDE.md` нёс символ веры с `<git user.name>`, а `.kaif/deploy-manifest.json` — `"<REPO_URL>": "https://<login>@<forge>/<…>.git"`
(логин в адресе); собственный страж обезличенности проекта покраснел на руководстве и манифесте; ядро в дереве между прогоном и
`update-verify` несло `ORIGIN` — обезличивалось только на `update-verify`.

## Repro (deterministic)

Не снят у истока. Ход: свежий git-проект с `user.name` и `remote.origin.url` вида `https://login@host/repo.git`, `install --mode anonymous`
из этой сборки, `git grep` имени и логина по дереву и манифесту.

## Root cause / Hypotheses

Не разобрано. Гипотезы (не проверены): заполнение `<AUTHOR>`/`<REPO_URL>` в обезличенном режиме берёт значения из git без подмены; манифест
хранит `values` до обезличивания.

## Decisions made without the owner

- `[ИИ]` Уровень S2, не S1: страж поля поймал данные до публикации.
