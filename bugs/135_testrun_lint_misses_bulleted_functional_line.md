# Bug 135 — Линтер отчётов прогона не видит строку «- Functional run:» в форме списка и краснит честный отчёт `pass`

**Status:** 🔴 OPEN — тикет поля #161 (2026-10-18 06:39 +03:00); разбор `researches/40` §3 · **Severity:** S3 (проект узнаёт о форме строки только на
первом `pass`; семь отчётов одной ночи в поле переписаны руками)
**Version/build:** KAIF 2.9 · **When/context:** 2026-10-18, полевое развёртывание (KUMM), ночная серия отчётов прогона.
**Fix accepted when (observable):** отчёт, чьи строки «Гигиена:» и «Функциональный прогон:» начинаются маркером списка (`- `, `* `, `1. `), с
вердиктом `pass` проходит `kaif-testrun-lint check`; без строки функционального прогона — по-прежнему красный.
**Fixing:** версия KAIF 2.10, эпик HC, если владелец возьмёт строку разреза (`researches/40` §5).

## Вектор цели (Avoid)

Линтер формы отчёта не краснит отчёт, написанный по канону в форме списка: красный значит «строки функционального прогона нет», а не «строка
стоит в списке».

## Готово, когда (критерии приёмки)

- Ситуация. Отчёт прогона: «Проверки» открываются строками `- Гигиена: …` и `- Функциональный прогон: …`; вердикт `pass`.
- Действие. `node framework/tools/kaif-testrun-lint.mjs check <дом>`.
- Результат. Код 0, находок нет.
- Проверка. `selftest` линтера: случай «строка списком считается» на каждом языке поставки — красный на v2.9, зелёный после; случай без
  строки функционального прогона остаётся красным.

## Symptom

`pass-without-functional-run: Verdict says pass while Checks carries no "Functional run:" line` на отчёте со строкой `- Functional run: …`; тот
же отчёт с вердиктом `partial` проходит молча.

## Repro (deterministic)

1. Любой отчёт с заполненными «Проверками»; перед двумя строками поставить `- `; вердикт `pass`.
2. `node .kaif/tools/kaif-testrun-lint.mjs check` → `pass-without-functional-run`.
3. Убрать `- ` → зелёный.

## Forensics

HEAD `0d5c7ce`, `framework/tools/kaif-testrun-lint.mjs:84` (`LINE_LABEL_RE` — `^\\s*(?:…)\\s*:`) и `:88` (`FUNCTIONAL_LINE` —
`^[^\\S\\n]*(?:…)[^\\S\\n]*:`): перед меткой допускаются только пробелы.

## Fix plan

Необязательный маркер списка перед меткой в обеих регулярках (`(?:[-*+]|\d+[.)])?`); случай selftest на язык; одна строка-комментарий в
шаблоне отчёта, что строки — обычные строки. `TWINS:` — метки «Гигиена:» и прочие метки отчёта той же формой.
