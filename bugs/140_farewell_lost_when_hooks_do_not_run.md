## Symptom

Сессия 102 кончилась итоговым отчётом, который отправлял владельца перезагрузить окно и открыть новый чат. Файл прощания остался от
2026-11-07: последние слова чата следующий чат не прочитал бы.

## Repro (deterministic)

1. Сессия в папке без доверия Claude Code (`node framework/hooks/context-window.mjs --alive` → код 1).
2. Чат кончается сообщением владельцу (ритуал закрытия или отчёт «перезагрузите окно»).
3. `FAREWELL_MESSAGE_FROM_THE_PREVIOUS_CHAT.md` — прежний.

## Root cause

Единственный писатель файла — хук остановки `framework/hooks/stop-farewell-capture.mjs`, и пишет он только ход с вызовом навыка закрытия
(`/end-chat-soft` · `/end-chat-force`). Две дыры: (1) хуки не запускаются вовсе (`bugs/138` — папка без доверия), и навыки закрытия писать
файл сами не велели; (2) отчёт, который отправляет владельца в новый чат без ритуала закрытия, не пишет ни хук, ни агент. Класс — «подключено ≠
работает» (EXP-0210): механика держалась на одном хуке без ручной половины.

## Fix

- `/end-chat-soft` шаг 5 и `/end-chat-force` шаг 3 обоих слоёв: прощание сначала пишется в файл самим агентом, потом выводится; хук только
  повторяет запись.
- `/resume` шаг 0 обоих слоёв, ветка «хуки не работают» (код 1): до доверия сообщение, которым кончается чат, — прощание ритуала или отчёт,
  отправляющий владельца в новый чат, — агент пишет в файл сам.
- Гард сборки 5z (`tools/check-framework.mjs`): три навыка поставки несут эти строки; проба `tools/sandbox/probes/farewell-by-hand-red.mjs` —
  красный ровно на трёх текстах ревизии `7eebb9c`.
- Нота сборщика 2.10 называет шаг полю.
- У истока последние слова сессии 102 записаны в файл руками 2026-11-17 ≈ 21:53 +03:00.

- `[ИИ]` хук не менять (пишет только ходы закрытия — «спасибо» после прощания не затирает файл); ручная запись — в навыках, а не новый хук.
