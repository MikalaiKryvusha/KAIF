## Вектор цели

**Avoid:** записанный ответ владельца никогда не затирается и не читается за ответ на другой документ — что бы ни лежало в именах файлов.
**Maintain:** каждая уже существующая запись поля читается без миграции.

## Symptom

Поле (тикет #199): две картинки-макета `qa_runs/caption005_compare/compare.webp` (ответ владельца 2026-11-17 10:40 →
`interviews/decisions/compare.decision.json`, поле `"document"` — первая картинка) и `qa_runs/caption_look_compare/compare.webp` (готовилась
к показу). Имя записи выводится без папки — вердикт второй картинки лёг бы в ту же запись (место 2), и очередь, долг и страница первой показали
бы чужой ответ. Проба поля на неисправленном ядре: `refused second: false · b reads: B answer · a reads: B answer`.

## Repro (deterministic)

1. Временный корень с `interviews/decisions/`; файлы `a/compare.webp` и `b/compare.webp`.
2. `recordDecision(root, 'a/compare.webp', { kind: 'mockup', comment: 'A answer' })`.
3. `recordDecision(root, 'b/compare.webp', { kind: 'mockup', comment: 'B answer' })`.
4. `readDecision(root, 'a/compare.webp').comment` → `'B answer'` (ожидалось `'A answer'`).

## Root cause

`framework/tools/contour/core.mjs` → `docBase` — `basename(docPath)` без расширения: пространство записей плоское (`interviews/decisions/`), а
документы живут во многих папках. Сгенерированные картинки носят общие имена (`compare.webp`, `preview.png`, `mock.png`), и `x/compare.md`
с `x/compare.webp` тоже делят имя. `recordDecision` пишет место 2, не спросив, чья запись там стоит; `readDecision` возвращает её, не сверив
поле `document`, хотя его несёт каждая запись.

**Класс:** производное имя теряет часть ключа — путь документа сжат до голого имени, и два ключа сходятся в одно имя файла.

## Fix

Одна функция имени на оба пространства — `ownedStem` (`core.mjs`): документ остаётся при голом имени, пока голое имя свободно или уже его;
документ, чьё голое имя держит ДРУГОЙ документ (поле `document` записи · поле `doc` замка), получает имя `<имя>--<8 знаков sha256 пути>`;
документ, у которого такое имя уже есть, остаётся при нём. Запись поверх записи другого документа — отказ со строкой; чтение чужой записи —
`null`. Ни одна существующая запись поля не переименовывается.

`FORK: options <A отказ на коллизии, как локальная починка поля | B имя с папкой всегда + миграция всех записей | C голое имя у своего документа, имя с меткой пути только у второго + отказ поверх чужого> · price of error <затёртый или чужой ответ владельца; сломанные чтения записей поля после обновления> · consulted <локальная починка поля в тикете #199 (отказ на коллизии, доказана мутацией) и его слово «a fuller fix … is the origin's choice»; практика путевых ключей хранилищ — VS Code workspaceStorage называет папку хешем её адреса; правило «не затирать» — запись с проверкой владельца, как O_EXCL / no-clobber>` — выбрано C: отказ поля сохранён целиком как предохранитель, а второй документ получает своё имя без миграции чужих записей.
