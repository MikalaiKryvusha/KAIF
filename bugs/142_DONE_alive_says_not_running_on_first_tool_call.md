## Вектор цели

**Avoid:** проверка «хуки этой сессии работают?» никогда не утверждает отказ хуков, которого нет, — в каком бы вызове сессии её ни запустили.

## Symptom

Шаг 0 `/resume`: `--alive` в первом вызове сессии — код 1 и приказ владельцу «Trust folder»; через один вызов — код 0, запись сессии на месте.

## Repro (deterministic)

1. Новая сессия Claude Code в папке истока (доверие дано, хуки подключены).
2. Первым вызовом инструмента — `node framework/hooks/context-window.mjs --alive`.
3. Код 1, «NOT running»; `.kaif/context-window.json` не знает этой сессии. Второй вызов — код 0.

## Root cause

`--alive` судит по записи сессии в `.kaif/context-window.json`, а хук окна пишет её только вместе с замером — когда в журнале сессии уже есть
ответ модели с расходом токенов. На первом промпте сессии (`UserPromptSubmit`) такого ответа ещё нет — записи нет; первая запись ложится на
`PostToolUse` первого вызова, то есть ПОСЛЕ того, как первый вызов отработал. Проверка в первом вызове смотрит на состояние, которое ещё не
может существовать. Класс — «свидетель, который не успевает родиться к моменту вопроса» (родня `bugs/138` — «подключено ≠ работает»).

## Fix

Хук окна записывает присутствие сессии на КАЖДОМ своём событии — с первого промпта, даже когда расход ещё не виден и журнала сессии ещё нет;
ступени окна по-прежнему судятся только по замеру. Самопроверка хука — живой запуск хука дочерним процессом с событием первого промпта
(журнал без ответа модели · журнала ещё нет): запись сессии появляется, `--alive` — код 0; та же проверка на хуке до починки — красная.

**Проверено** (отчёт прогона выше): Гигиена: самопроверка хука — случай «alive from the first prompt (bugs/142)» зелёный, мутанты G7 · G8
(`tools/sandbox/probes/gate-close-mutant.mjs`) — ровно этот случай, G1–G6 — на прежних адресатах. Функциональный прогон: настоящий хук,
запущенный как его запускает Claude Code, на первом промпте (журнал без ответа модели · журнала ещё нет) — обе сессии «--alive exit 0»; хук
HEAD — обе «exit 1» (`tools/sandbox/probes/bugs142-first-prompt-alive.mjs`); живая сессия истока — `--alive` код 0. Не наблюдён — первый
вызов нового чата (условие DONE).
