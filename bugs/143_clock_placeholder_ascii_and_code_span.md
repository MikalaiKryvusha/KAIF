## Вектор цели

**Avoid:** момент, который агент хотел получить от часов машины, никогда не остаётся молча буквой заполнителя, и пример заполнителя в
тексте никогда не превращается в чужое время.

## Symptom

1. ASCII `[NOW]` в записанном файле — буква; хук молчит, ошибки нет.
2. Заполнитель, процитированный в код-спане как пример, заменён временем.

## Repro (deterministic)

1. Write файла с текстом «Создан: [NOW]» (ASCII-скобки) в развёртывании с подключённым хуком часов → в файле буква «[NOW]».
2. Write файла с текстом «пишите `⟦NOW⟧`» без обратной косой перед заполнителем (код-спан) → в файле время вместо примера.
   **Воспроизведено живьём этим документом:** первая запись `bugs/143` в ≈ 01:18 +03:00 несла пример без обратной косой — в файле встало
   «2026-11-18 01:18 +03:00»; пример выше записан с обратной косой, которую хук снимает.

## Root cause

(1) Строка хука называет символы словами («white square brackets»), а модель берёт ближайшие знакомые — ASCII; хук судит только точную форму
и о близкой форме не говорит. (2) Хук заменяет заполнитель везде, где встретил, не отличая текст О заполнителе (код-спан, блок кода) от места
момента; защита «перенесённое слово остаётся буквой» (TK7z) покрывает только слово, уже стоявшее в файле.

## Fix plan

- Строка хука печатает точные символы (через escape в исходнике: прямо записанный символ хук заполнил бы в собственном тексте).
- Запись, несущая ASCII-форму, получает предупреждение тем же ходом — без остановки работы (решение №144: ни один хук KAIF не
  останавливает агента); форма и событие — разведкой контракта хуков вендора до кода.
- Код-спан и блок кода — заполнитель там остаётся буквой.

## Fix (сделано)

`framework/hooks/clock-now.mjs`: строка промпта печатает точные символы и «never ASCII [NOW]»; в markdown-файле заполнитель внутри код-спана
и блока кода остаётся буквой (`codeSplit`), вне кода — заполняется; запись markdown-файла с ASCII-формой вне кода, которой не было в заменяемом
тексте, получает одну строку агенту вместе с результатом вызова (`PreToolUse` · `additionalContext`), текст не меняется, разрешение не
берётся. Руководство обоих слоёв показывает заполнитель точными символами в код-спане.

**Проверено:** Гигиена: самопроверка хука — три случая «bugs/143» (код-спан и блок · не-markdown как прежде · ASCII-форма названа, в коде /
перенесённая / настоящий заполнитель / исходник — тишина); проба `tools/sandbox/probes/pt1-clock-now.mjs` — 10 из 10, на хуке HEAD красны
ровно новые (8)–(10). Функциональный прогон: живая сессия Claude Code истока — правка, принёсшая ASCII-форму в файл, получила строку хука
«this write keeps [NOW-ISO] · [NOW] as letters …» вместе с результатом (это была правка `.mjs` — ложное срабатывание; предупреждение сужено до
markdown, следующая правка `.mjs` прошла молча); правка `AGENT_GUIDE.md` обоих слоёв с заполнителем в код-спане — буква сохранилась.
