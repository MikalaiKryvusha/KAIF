# Bug 19 — Пакет мелких контрактных дефектов шаблонов и маркера (каждый чинится строкой)

**Status:** 🔴 OPEN
**Version/build:** 1.6 · **When/context:** 2026-07-27, метасинтез (`researches/07`, §4) —
отчёты 01, 03, 06, 08. Четыре независимых микро-дефекта сведены в один документ-пакет ради фокуса
беклога (решение зафиксировано в `researches/07`, «Решения без владельца», п.1); владелец может
велеть расщепить.

## 1. `<COMMIT_COMMAND>` — двусмысленный контракт (отчёт 08, Д5; задел ещё 1.5)

В шаблонах плейсхолдер употребляется и как самостоятельная команда, и как префикс с сообщением —
никакое одно заполнение не удовлетворяет оба употребления.
**Repro:** заполнить полной командой → в `release` на диске
`git add -A && git commit -m "<msg>" && git push "docs: README…"` — push в «ремоут» с таким именем.
**Fix:** развести на `<COMMIT_COMMAND>` и `<COMMIT_WITH_MESSAGE>` (или единая форма без аргумента)
+ требуемая форма заполнения прямо в адаптационной задаче.

## 2. Бренд KAIF протёк в шаблон /release (отчёт 03)

Строка 87 шаблона `release/SKILL.md` в бандле 1.6 хардкодит «a short "what KAIF is" paragraph…» —
навык любого развёрнутого проекта велит вставлять абзац про KAIF в собственные релиз-ноты.
**Repro:** открыть строку 87 шаблона в бандле 1.6 (строки 79–80 — законные примеры, речь только
про 87). **Fix:** `<PROJECT_NAME>` вместо KAIF — правка в одно слово.

## 3. Маркер копит поля разных версий (отчёт 01, D7)

После апдейта 1.4→1.6 в `.kaif/kaif.json` живут и `agentsSupported` (1.4), и `agents` (1.6):
`{...legacyOld}` переносит всё, карта переименований есть только для `agent`→`agents`.
**Repro:** обновить установку 1.4 (писавшую agentsSupported) → оба поля на месте.
**Fix:** карта переименований/устареваний полей маркера при legacy-мердже.

## 4. Имя KAIF-FULL.md обещает полноту, а это подмножество (отчёт 06, T8)

Оффлайн-ассет содержит 44 блока из 134 (без языковых паков, сфер, references) — инструмент диффа,
взявший его за полный набор, «молча врал» про churn. Состав ассетов релиза нигде не описан.
**Repro:** посчитать FILE:-блоки в KAIF-FULL.md против бандла: 44 ≠ 134.
**Fix:** строка состава/назначения каждого ассета в `kaif-manifest.json` или теле релиза (или
переименование в KAIF-OFFLINE.md).

## Root cause (общий)

Контракты, живущие в прозе шаблонов и в неявных соглашениях, не имеют стражей; каждый дефект —
кандидат на строку линтера в `check-framework.mjs` (правило «фикс без стража — фикс в кредит»).
