# Bug 20 — обновление против ЦЕЛИКОМ переведённого развёртывания: удвоение документов (K1) и слепой флаг `i18n: translated` (K2)

**Status:** 🔴 OPEN
**Version/build:** 2.0 (build 68) · **When/context:** 2026-07-31, полевой отчёт ndim 1.6→2.0
(`ideas/ai_agents_reports/23`, находки K1+K2) — эпик B плана 23, Фаза B0.

## Symptom

Класс: развёртывание, переведённое **вместе с заголовками** (расхождение с каноном, но полевой
факт), при модульном обновлении получает результат, непригодный к сдаче.

- **K1 (🔴):** ни одна русская сигнатура диска не найдена в базе → все дисковые модули «добавлены
  владельцем» (сохранить); ни одна английская сигнатура шаблона не найдена на диске → весь шаблон
  «новые модули релиза» (вставить после `<preamble>`). Итог в поле: 22 навыка + 3 руководящих
  документа стали двуязычными дублями, **+6534/−216 строк**; лог при этом рапортует
  `↻ merged N module(s)` — формально правду, по смыслу противоположное.
- **K2 (🟠):** штатное лекарство `"i18n": "translated"` удвоение снимает, но: (а) обещанных
  per-module диффов НЕ существует — лог/комментарий/релиз-ноты говорят «per-module diffs only», а
  в коде путь один — `diverged.push` (в задании 45 файлов «влей руками», `## Module diffs`
  отсутствует — grep дал 0); (б) флаг выключает механическую замену и для файлов, которых проект
  не касался (в поле — 21 нетронутый EN-файл теряет обновление навсегда).

## Repro (deterministic)

Свод полигона `tools/sandbox/s07-translated.mjs` (Фаза B0 плана 23): фикстура развёртывания с
переведёнными сигнатурами 2–3 навыков и 1 ключевого документа → update на тестовую версию.
Стражи (доказать красными ДО фикса): (1) размер файла не растёт кратно / нет двуязычных пар
заголовков; (2) при `i18n: translated` задание содержит `## Module diffs` там, где апстрим менял
модуль; (3) нетронутый EN-файл под флагом всё равно заменяется механически.

## Forensics

**Красный прогон s07 на текущем коде (2026-07-31, до фиксов):** K1 воспроизведён —
`.claude/skills/check-backlog/SKILL.md` (переведён с заголовками) после update: **1043 → 4085
байт**, EN-H1 вставлен рядом с русским, лог рапортует «merged», задание файл не называет (4 стража
красные). K2 воспроизведён — под `i18n: translated` в задании нет `## Module diffs`, нетронутый
чисто-EN `TESTING_FRAMEWORK.md` не обновлён (2 стража красные). Санити зелёные: exit 0, русский
текст цел, правленное молча не заменено.

- `framework/installer/KAIF-CORE.mjs:613-625` — вставка «новых» модулей: единственный общий модуль
  `<preamble>` → весь шаблон встаёт перед переведённым текстом. Защитная сетка `localizedAgainst`
  (строка 598) недостижима **по построению**: она проверяет модуль, чья сигнатура СОВПАЛА с базой,
  а у переведённого заголовка сигнатура не совпадает никогда.
- `KAIF-CORE.mjs:651-652, 676, 682` — `i18nTranslated` выключает и ветку `untouched`, и
  `mergeModules` целиком → строка 691 `diverged.push(f.path)`; диффам физически неоткуда взяться.

## Root cause

Идентичность модуля = текст заголовка (`splitModules` → `signature`); перевод заголовка меняет
идентичность всех модулей сразу, и слияние логично-абсурдно интерпретирует файл как «всё владельца
+ всё новое». Флаг `i18n` сливает два решения в одно: «не заменять» и «не анализировать».

## Fix plan (отчёт ndim, по возрастанию стоимости; план 23 Фаза B1)

1. **K1, дешёвая сетка файла:** перед вставкой «новых» модулей — если из N дисковых сигнатур в
   базе найдено ≤1 (кроме `<preamble>`) И диск содержит письменность рабочего языка, а вставляемое
   — нет → файл «translated wholesale»: не вставлять ничего, в `diverged` с пометкой.
2. **K2, dry-run:** под `i18n: translated` вызывать `mergeModules` в режиме «ничего не писать, но
   собрать divergedList» → диффы в задание; флаг применять только к файлам, реально несущим
   письменность рабочего языка.
3. (дорого, НЕ в этом фиксе — кандидат будущего) стабильный id модуля вместо текста заголовка.
