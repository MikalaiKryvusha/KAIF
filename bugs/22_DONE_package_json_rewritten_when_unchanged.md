# Bug 22 — package.json переписывается целиком, даже когда все хендлы на месте (K4)

**Status:** ✅ DONE (2026-07-31)
**Version/build:** 2.0 (build 68) · **When/context:** 2026-07-31, отчёт ndim (`ai_agents_reports/23`, K4).

## Symptom

Шаг «wired kaif:* handles» пишет `JSON.stringify(pkg, null, 2)` безусловно — даже когда ни один
хендл не добавлен. На Windows-дереве с CRLF это фантомный дифф во весь файл (в поле: 52 строки
удалено / 52 добавлено, смысловая разница ноль — `diff` после `tr -d '\r'` пуст). Нарушает
git-гигиену канона: дифф, которого агент не намеревался делать.

## Repro (deterministic)

Свод: package.json с CRLF и уже вшитыми хендлами → install/bootstrap → сейчас файл переписан
(mtime/байты изменились); после фикса — не тронут.

## Forensics

**Красный прогон s07/T3 (2026-07-31):** package.json с CRLF и всеми тремя вшитыми хендлами после
`install` изменён байтово (страж «байт в байт не тронут» красный).

## Root cause

`framework/installer/KAIF-CORE.mjs:1131-1138` — `writeFileSync` вне проверки «изменилось ли»:
цикл `for … if (!pkg.scripts[k])` добавляет недостающее, но запись идёт всегда.

## Fix plan (план 23, Фаза B3)

Сериализовать, сравнить с прочитанным с диска текстом (по-байтно), писать только при реальном
отличии; лог различает «wired» и «already wired». Тот же паттерн проверить в остальных местах
записи конфигов юзера (TWINS-греп по `writeFileSync('package.json'` — второе место: строка 946,
ветка анонимной самоочистки — там запись по определению меняет файл, но проверить).

## ✅ STATUS: DONE (2026-07-31)

Запись только при реально добавленных хендлах/имени (`wired`-счётчик); лог различает «wired» и
«already wired — untouched». Страж s07/T3 (CRLF + вшитые хендлы → байт в байт) красный до /
зелёный после; полигон 7/7.
