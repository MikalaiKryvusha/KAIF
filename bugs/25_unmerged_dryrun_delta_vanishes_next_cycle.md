# Bug 25 — невлитая dry-run-дельта переведённого файла исчезает из СЛЕДУЮЩЕГО задания (находка F2 судьи)

**Status:** 🔴 OPEN
**Version/build:** 2.1-dev (build 74+) · **When/context:** 2026-07-31, адверсарное ревью фиксов
эпика B (судейский проход перед пушем Фазы B1); воспроизведено ревьюером двух-хоповым прогоном.

## Symptom

Проект с `i18n: translated`: обновление №1 кладёт диффы изменённых модулей переведённого файла в
задание (dry-run, K2-фикс — bugs/20). Если владелец/агент НЕ вливает дифф и приходит обновление
№2 — задание №2 файл **вообще не упоминает**, а диск правку так и не получил: дельта апстрима
исчезает навсегда без следа.

## Repro (deterministic)

Двух-хоповый прогон (скрипт ревьюера): install --lang ru → i18n: translated → русифицировать тело
модуля PHILOSOPHY → update →9.9 (дифф в задании; НЕ вливать) → update →10.0 → в задании №2 нет
PHILOSOPHY.md. Оформить сводом при фиксе.

## Root cause

`cmdUpdate` обновляет `moduleShas`/`templateShas` манифеста до НОВОЙ версии для всех файлов
поставки — включая dry-run-файлы, которым ничего не доставлялось. На цикле №2 нетронутый диск
читается как «owner-edited, апстрим не менял» → тишина.

## Hypotheses / fix candidates (не патчить вслепую)

1. Для dry-run-файлов **не пересвежать** moduleShas/templateShas (база = что реально доставлено) —
   честно по семантике, но диффы будут повторяться до ручного влития (шум вместо потери — надо
   продумать сценарий «владелец влил» и «владелец сознательно отверг»).
2. Хранить список «недоставленных дельт» в расписке/манифесте и переносить в следующее задание.
3. Считать процессным гейтом: пункт merge-modules чекпоинтится, update-verify не пройдёт без него
   (смягчение существует уже сейчас — но потеря при пропуске остаётся молчаливой).

## Mitigation (уже действует)

Штатный поток требует добить задание (checkpoint merge-modules) до `update-verify`; окно потери =
агент, бросивший задание. Зафиксировано как known limitation в bugs/20.

## Decisions made without the owner

Фикс отложен из Фазы B1 сознательно (рекомендация судьи «минимум — bug-док»): выбор между
шумом повторных диффов и новой сущностью в манифесте — решение, которое стоит принять на свежую
голову в Фазе B3/B4 плана 23, не в ночь фиксов.
