# Bug 26 — дрейф значений плейсхолдеров ломает сигнатуры adaptive-модулей: merge дописывает дубликат H1 в конец канона

**Status:** 🔴 OPEN
**Version/build:** 2.0 · **When/context:** 2026-07-31, третий полевой отчёт об обновлении до 2.0
(`ideas/ai_agents_reports/KAIF_2.0_UPDATE_REPORT.md`, дефект 1 — 🔴 высокий; анонимная установка,
живой проект web_site_ai_tester).

## Symptom

После механического апдейта `AGENT_GUIDE.md` вырос на 19 строк В КОНЦЕ: второй заголовок H1
(`# artifacts — AI Agent Guide`) + шапка + два боксовых правила — уже присутствующие в начале файла
под ДРУГИМ именем проекта. Тихо: ни лог, ни задание, ни один гейт не заметили; «слабая модель этого
не заметит вообще».

## Repro (deterministic; из отчёта — воспроизводится точно)

`detectValues()` пересчитывает `<PROJECT_NAME>` на каждом запуске (`pkg.name || имя каталога`).
Деплой прошёл ДО появления package.json (имя = каталог `web_site_ai_tester`), апдейт — ПОСЛЕ
(`"name": "artifacts"`). Дисковый H1 не найден в базе → «правка проекта», сохранён (верно);
шаблонный H1 с новым значением не найден на диске → ветка «модуль НОВЫЙ в релизе» → вставка; для
первого модуля соседа нет → `at = out.length` → **в самый конец файла**.

## Root cause (два независимых изъяна — лечить оба, из отчёта)

1. **Значения плейсхолдеров не зафиксированы за развёртыванием** — пересчитываются из окружения,
   которое между релизами меняется (package.json появился/переименован, каталог, git user.name,
   scripts.test). При этом класс `adaptive` присваивается модулю ИМЕННО за наличие плейсхолдера —
   у «подстановочных» модулей сигнатура нестабильна ПО ПОСТРОЕНИЮ.
2. **Ветка «вставить новый модуль» не защищена от `adaptive`**: отсутствие adaptive-модуля на диске
   по сигнатуре — почти наверняка переименование, а не новинка релиза.

## Fix plan (план 23, Фаза B3; минимальные исправления из отчёта)

1. Писать в `deploy-manifest.json` поле **`values`** (снимок подстановок развёртывания); на
   апдейте брать значения оттуда, пересчитывать только бывшие `unresolved` (манифест уже хранит
   снимок `marker` — тот же приём).
2. **Не вставлять** отсутствующие на диске модули класса `adaptive` — отдавать диффом в задание.
3. Дешёвый предохранитель: никогда не вставлять `#`-модуль в файл, где H1 уже есть, и никогда не
   добавлять H1 в конец документа.
4. Стражи s07 красными ДО фикса (сценарий: install без package.json → добавить package.json с
   другим именем → update → H1 один).
