# Bug 31 — класс L-1: перевод не защищён от ВСТАВКИ — английские модули в переведённых файлах («двухголовые» навыки)

**Status:** 🔴 OPEN (заведён триажем L1 эпика L 2.2)
**Version/build:** машинерия 2.1 · **When/context:** 2026-08-07, триаж 4 полевых отчётов об
обновлении до 2.1 (`ideas/ai_agents_reports/2.1_update_reports/`); класс L-1 — `researches/15` §3.

## Симптом (класс, не экземпляр)

Механика обновления обещает переведённому развёртыванию неприкосновенность («mechanical
replacement disabled»), но защита закрывает только ЗАМЕНУ файла — ВСТАВКА модулей остаётся
разрешённой. Итог: английские блоки шаблона вписываются в русские документы — вплоть до
«двухголовых» навыков с двумя противоречащими процедурами (в KrinikCam — у деструктивного
`/kaif-remove`). Отягчение: у части проектов защита выключена целиком, потому что маркер
до-2.0 развёртываний не несёт `i18n: translated`, а обновление флаг не проставляет.

## Repro (полевые, из отчётов; локальный песочный свод — в фазе фикса)

1. Развернуть KAIF с переведёнными заголовками (или `--lang ru` + полный перевод навыка,
   оставив EN только `name:` во frontmatter), обновиться → в файле два H1, две процедуры.
2. Предикат сети отдельным скриптом (KLAS): `PHILOSOPHY.md` — совпало 2 сигнатуры из 21
   (`KISS`, `DRY` — термины не переводят) → `baseFound (2) <= ceiling (1)` ложь → файл идёт в
   по-сигнатурное слияние.
3. Детектор двухголовости (KrinikCam): `grep -c '^# ' SKILL.md` > 1.

## Root cause (4 независимые причины, все подтверждены полем)

1. **Вставка не блокируется:** `i18n: translated` отключает замену, но модуль с «отсутствующей»
   (переведённой) сигнатурой вставляется рядом — даже при байт-идентичных шаблонах старой и
   новой версии (грань bugs/32: дифф не от предыдущего релиза).
2. **Абсолютный порог сети:** `wholesaleCeiling = 1` предполагает, что перевод меняет ВСЕ
   заголовки; реальный перевод оставляет термины (KISS, DRY) → 2 выживших сигнатуры ломают
   распознавание. Порог обязан быть долей (2 из 21 = 9,5 % — очевидный перевод); вырождение
   порогов на малых N — уже оплаченный класс EXP-0019.
3. **Кириллица в телах EN-шаблонов ослепляет сеть:** условие «во входящем шаблоне НЕТ письма
   владельца» ложно для `pause` и `kaif-remove` — авторские русские примеры в телах. Ровно эти 2 шаблона
   из 34 дали дубль в трёх проектах независимо (NDim грабля 1, KLAS D1 причина B, KCam Г2 —
   те же два файла). Инвариант
   §9.11 researches/15: кириллица не живёт в телах EN-шаблонов — примеры в языковые пакеты.
4. **Флаг некому ставить:** проекты, переведённые до 2.0, не имеют `i18n` в маркере; установщик
   не спрашивает, обновление не выставляет (KLAS D2). Запросы K2: авто-простановка при
   `language != en` + срабатывании сети хотя бы на одном файле.
