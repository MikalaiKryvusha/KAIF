# Bug 32 — класс L-2: задание строит диффы не от ПРЕДЫДУЩЕГО РЕЛИЗА — ложные пункты и молчаливые потери

**Status:** ✅ DONE (фикс L2, 2026-08-07; верификация — полигон s08 + регрессия s01–s07, 8/8)
**Version/build:** машинерия 2.1 · **When/context:** 2026-08-07, триаж 4 полевых отчётов об
обновлении до 2.1; класс L-2 — `researches/15` §3. Главный источник когнитивного налога
обновления (NDim: полезны ~80 строк задания из 352; KCam: 8 из 23 merge-diverged пунктов пустые).

## Симптом (класс, не экземпляр)

`KAIF_UPDATE_TASK.md` строится сравнением «шаблон ↔ диск» (по сигнатурам), а не «шаблон старой
версии ↔ шаблон новой». Следствия, все четыре наблюдены полем:

1. «NEW module in this release» при байт-идентичном шаблоне (модуля нет на диске, потому что
   заголовок переведён — а не потому, что апстрим что-то менял).
2. Файлы в `merge-diverged` при нулевой дельте апстрима (35 % самого дорогого раздела задания —
   пустые пункты).
3. Для translated-файлов задание вообще не несёт диффов — только прозаический список новостей
   релиза; агент, доверившийся заданию, молча теряет нормы (Unliminium насчитал 5 потерянных).
4. Ложные модульные диффы из-за дрейфа H1-сигнатуры при неизменном шаблоне.

## Repro (полевые)

Скачать бандлы двух релизов, распаковать `FILE:`-блоки, сравнить деревья (NDim: «30 строк
скрипта»; KCam: парсер фенсов переменной длины). Сверить полученную настоящую дельту со
списком пунктов задания → расхождение и есть класс.

## Root cause

Машинерия владеет обеими сторонами настоящего диффа в момент прохода (сама пишет «synthetic
baseline: v1.6's own KAIF-CORE-BUNDLE.md (52 templates)») и умеет строить дифф модулей
(`lineDiff`), но: для translatedWholesale-файла разбор прекращается раньше
(`return { translatedWholesale: true }` — Unliminium, `kaif-core.mjs:632`), а для остальных
пунктов сравнение идёт с ДИСКОМ, не с шаблоном предыдущей версии. Нулевое изменение апстрима
не отличимо от реального.

## Fix plan

Фаза **L2** родителя `plans/28_EPIC_kaif_2.2_L_update_field_fixes.md` (якорь: «### L2. Класс
перевода: детектор и вставка»): диффы задания — от ПРЕДЫДУЩЕГО РЕЛИЗА (синтетический
baseline уже скачивается); ноль изменений апстрима = ноль пунктов; для merge-diverged — флаг
«шаблон не менялся» и настоящий unified-дифф шаблонов (формат merge-modules); гейт — критерий
приёмки эпика №3 («пункт с пустым диффом невозможен по построению»).

## ✅ STATUS: DONE (2026-08-07, фаза L2 — `plans/41`)

Все четыре следствия закрыты в `framework/installer/KAIF-CORE.mjs`
(`[TESTED: 2026-08-07 · npm run test:core — 8/8 сводов]`):

1. **Фильтр нулевой дельты:** разошедшийся/переведённый файл, чей шаблон между релизами НЕ
   менялся (сверка `templateShas`), не порождает ни пункта, ни вставки — «ноль изменений
   апстрима = ноль пунктов» по построению (s08/F1c, F2b). Ложные «NEW module» при нулевой
   дельте убиты гейтом вставки (сравнение с СИГНАТУРАМИ СТАРОГО ШАБЛОНА, не с диском) — гейт
   изолированно стережёт s08/F7a (уточнение судьи: F1a стережёт вставки на диск, гейт — свой
   изолятор), «19 фантомов NDim» невозможны.
2. **Настоящие диффы от предыдущего релиза:** `cmdUpdate` строит синтетический baseline
   старой версии (артефакт её же релиза; `--baseline <dir|url>` — оверрайд), расширенный
   ТЕКСТАМИ шаблонов (`templateTexts`); для translated-wholesale файлов задание несёт
   по-модульный дифф «шаблон старой версии → шаблон новой» (`templateDelta`; s08/F2a —
   KLAS D12 «Module diffs пуст» закрыт), для file-level diverged без модульной нарезки —
   цельнофайловый шаблонный дифф.
3. **Честная деградация вместо пустого пункта:** baseline недостижим → дельта всё равно
   ДЕТЕКТИТСЯ по sha снапшота, пункт говорит «diff unavailable — pass --baseline …», а не
   молчит (s08 сценарий B — намеренно недостижимый baseline; риск 3 плана 41).
4. **Ориентация конфликтного диффа сохранена** («твоя версия → новый шаблон», канон 2.0,
   s02/S6): шаблон-к-шаблону применяется только там, где дисковый текст ничего не показывает
   (переведённые/wholesale/отсутствующие модули). Регрессия S6, пойманная полигоном при
   первом прогоне, откачена в тот же заход.
5. **Коллизия «новый файл релиза × файл владельца»** (остаточный пустой пункт, найден судьёй
   фазы): владельческий файл цел, а задание несёт пункт «(new file in this release)» с полным
   «+»-диффом входящего шаблона (s08/F8a-F8b); «новизна» отличается от «провенанс неизвестен»
   по списку путей прошлого деплоя. Плюс защита baseline: артефакт с чужой версией в манифесте
   не принимается за прошлый релиз (лог называет расхождение), сетевой fetch — под таймаутом.

**TWINS:** searched построение пунктов задания — все три генератора (`merge-modules` через
`divergedList`, wholesale через `templateDelta`, file-level diverged через цельнофайловый
дифф) переведены на дельту шаблонов/фильтр нулевой дельты; сводка «N module(s) await»
считается из тех же `divergedModules` — рассинхрон со списком невозможен (KCam Г9в).

## Decisions made without the owner

Триаж: KCam Г9в («8 module(s)» при 7 файлах — неоднозначная формулировка сводки) отнесён сюда
попутной косметикой переработки задания, отдельного документа не заслуживает. Закрытие:
(1) baseline на core-update пути скачивается ВСЕГДА (не только по флагу) — полевое поведение
из коробки, ради которого класс и заводился; офлайн деградирует честно и не блокирует
обновление; (2) конфликтные диффы оставлены «диск → новый шаблон» — решение агента по
живому стражу s02/S6 (правка владельческой копии обязана быть видима строками `-`), а не по
букве строки плана «сравнивает текст модуля между версиями шаблонов» (буква исполнена для
СРАВНЕНИЯ-условия, оно и раньше шло по sha шаблонов).
