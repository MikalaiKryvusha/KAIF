# Bug 34 — класс L-4: «зелёная ложь» — стражи зелёные без конфигурации, счётчики считают намерение, чекпоинты-галочки, слепой провенанс

**Status:** ✅ DONE (фикс L3, 2026-08-07; полигон 9/9) — одна грань ⏸ ждёт Q14 (см. закрытие)
**Version/build:** машинерия 2.1 + tool-модули · **When/context:** 2026-08-07, триаж 4 полевых
отчётов об обновлении до 2.1; класс L-4 — `researches/15` §3. Самый населённый класс триажа
(8 запросов + 9 наблюдений из 3 проектов) — и ровно тот фрод-класс, на который охотится
`/fable-judge` («зелёное без содержания хуже красного», инвариант §9.5).

## Симптом (класс, не экземпляр)

Проверки поставки отвечают «✅» там, где им нечего было проверять, нечем было проверять или они
не проверяли вовсе. Ненастроенный страж выходит нулём; счётчик сводки рапортует о работе,
которой не было; чекпоинт ставит галочку без прогона существующего сканера; провенанс-гейт
молчит зелёным на локализованном каноне («худший класс: ложное зелено, а не отказ»).

## Repro (полевые)

Однострочные вызовы из таблицы; каждый воспроизводится на свежем/ненастроенном/локализованном
развёртывании (Unliminium Г8 — «Воспроизведение: локализовать маркеры (`[ИИ]`), объявить
canonArtifacts, запустить report»).

## Root cause

Единый корень: успех и «нечего проверять» неразличимы по коду выхода и значку; счётчики
инкрементируются на намерении (до записи на диск); чекпоинт — запись в файл, а не исполнение
проверки; провенанс-модуль знает только английскую пару маркеров и не читает конвенцию из
маркера развёртывания.

## Fix plan

Фаза **L3** родителя `plans/28_EPIC_kaif_2.2_L_update_field_fixes.md` (якорь: «### L3.
CLI-безопасность и зелёная ложь»): ненастроенный страж → `SKIPPED` с отдельным кодом
(3); счётчики считают запись; чекпоинты с существующим сканером ИСПОЛНЯЮТ его; провенанс читает
локализованные маркеры из маркера развёртывания и исключает транзиенты; `check`/`report`
согласованы; ключ `canonArtifacts` сеется пустым при развёртывании (мёртвая инструкция
/derive-styleguide оживает); грань «check при дрейфе зеркал» — решение фазы (красный или
`recheck` зовёт `sync`). Гейт — критерий приёмки эпика №5; каждый страж доказан красным до
фикса.

## ✅ STATUS: DONE (2026-08-07, фаза L3 — `plans/42`; грань Q14 — ⏸ дефер)

Единый корень «успех неотличим от „нечего проверять“» закрыт по всем граням
(`[TESTED: 2026-08-07 · npm run test:core — 9/9 сводов; свод s09 G6–G14]`):

1. **SKIPPED ≠ passed:** ненастроенные стражи выходят кодом **3** с меткой `⊘ SKIPPED` —
   canon-lint без rules-файла и с нулём правил (пересмотр компромисса bug 30.2 по полевой
   цене: три проекта независимо получили «вечнозелёный гейт»); provenance без КЛЮЧА
   `canonArtifacts` — и `check`, и `report` согласованно (KCam Г7). Объявленный ПУСТЫМ канон —
   осознанное состояние: гигиена пар, зелёный. Policy-запись 2.2 предупреждает CI-интеграции.
2. **Ключ сеется:** `"canonArtifacts": []` пишется в маркер на свежей установке, легаси-
   bootstrap и update — мёртвая инструкция /derive-styleguide ожила (Unlim §3.2, KLAS D4).
3. **Локализованные марки:** маркер-ключ `aiMarks` (открывающие теги аналогов `[AI]`/`[AI-ed]`;
   закрывающие выводятся) — provenance видит `[ИИ]`-блоки (Unlim Г8: «91 блок» больше не
   невидим); longest-match обобщён на любые пары. Схема — KAIF_REFERENCE §12.1.
4. **Транзиенты исключены** из сканов обоих модулей (KAIF.md, задания, superseded) — гейт
   не краснеет на выводе самой машинерии (Unlim Г7).
5. **Счётчики считают запись:** «N skills trigger-aliased» = применённые переписывания
   description, не ключи пакета (KLAS D3; s09 G10 — фантомные ключи не завышают счёт).
6. **Чекпоинты исполняют существующие сканеры** (KLAS D5, Unlim §2.12-3): `placeholders` —
   ресинк зеркал (порядок bug 27) + скан + ОТКАЗ при литеральных слотах; `stale-claims` —
   перезапуск сканера с показом остатка (без отказа — «state why» легален); `recheck` —
   теперь сперва `sync` (закрывает окно дрейфа зеркал — KCam Г11/суд.1 — решение фазы),
   потом `check`. Голый `check` при дрейфе остаётся warning (дизайн bug 30.5: дрейф между
   update и verify штатен) — окно закрывают recheck и update-verify.
