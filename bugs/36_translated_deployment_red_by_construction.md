# Bug 36 — класс L-6: update-verify и аудит modules на переведённом развёртывании красны/шумны ПО ПОСТРОЕНИЮ

**Status:** 🔴 OPEN (заведён триажем L1 эпика L 2.2)
**Version/build:** машинерия 2.1 · **When/context:** 2026-08-07, триаж 4 полевых отчётов об
обновлении до 2.1; класс L-6 — `researches/15` §3. Формулировка поля: «дрессирует оператора игнорировать
аудит целиком, включая те 32 `differ`, где что-то настоящее».

## Симптом (класс, не экземпляр)

Выходные проверки ищут ДОСЛОВНЫЕ английские строки шаблонов на диске переведённого
развёртывания — где их не может быть никогда по решению владельца. Итог: сотни «MODULE ABSENT»
(218/290/216 в трёх проектах), «promised upstream line not found» на намеренно переведённых
строках, красная приёмка со второго захода — 100 %-ложный шум, неотличимый от реальной потери
модуля.

## Repro (полевые)

Unliminium: «перевести любой скилл, обновиться, запустить `update-verify`». Остальное — прогон
`update-verify`/`modules` на любом из трёх переведённых проектов.

## Root cause

Верификатор проверяет свойство «дословное присутствие строки шаблона», которое на переведённом
развёртывании ложно по построению; правильное свойство — «модуль на диске непуст и его
сигнатура известна» / «покрыт ли смысл модуля» (Unliminium Г11, KLAS §4.6). Отдельная грань:
плейсхолдеры ищутся по всем файлам, включая библиотеки чужих сфер (грань пересекается с
bugs/40 — адресация placeholders).

## Fix plan

Фаза **L4** родителя `plans/28_EPIC_kaif_2.2_L_update_field_fixes.md` (якорь: «### L4. Шум и
честность аудита»): отдельный режим переведённого развёртывания —
«absent ≠ дефект», «MODULE ABSENT» не печатается как дефект (или помечается «translated —
сверка по сигнатуре неприменима»); плейсхолдеры — только в файлах объявленной сферы. Гейт —
критерий приёмки эпика №7 («не красный по построению»); страж красным до фикса.
