## Симптом (класс, не экземпляр)

Релизные ноты обещают исполняемый механизм — в коде его нет; или приписывают канону нормы,
которые живут только в нотах. Проекты, поверившие обещанию, живут без стража (STATUS у трёх
проектов дорос до 1647/1928 строк при «мягкой цели ~200» — «предупреждать было некому») или
переносят нормы из нот, а не из шаблонов.

## Repro (полевые)

Unliminium: `grep -n "softTarget\|statusLines\|200" .kaif/kaif-core.mjs` → пусто. KLAS:
`grep -n '200\b' .kaif/kaif-core.mjs` → пусто; `AGENT_GUIDE.md 2.1 :: "Repro" → 0`.

## Root cause

Релизные ноты пишутся ОТДЕЛЬНО от кода и шаблонов, и ничто механически не сверяет обещание с
поставкой: нет линта «каждый обещанный механизм существует» (эта грань — bugs/38, линт бандла),
а сам страж длины STATUS просто не был написан (норма 2.1 осталась прозой — ровно класс
EXP-0001/0002).
