# Bug 37 — класс L-7: обещания релиза ≠ код — «warning-mode guard» длины STATUS не существует, новости сильнее шаблона

**Status:** 🔴 OPEN (заведён триажем L1 эпика L 2.2)
**Version/build:** релиз 2.1 (ноты + шаблоны + ядро) · **When/context:** 2026-08-07, триаж
4 полевых отчётов; класс L-7 — `researches/15` §3. Особо чувствительно для фреймворка, чей
собственный канон учит «два повтора → механизм» и «правило-как-проза не работает».

## Симптом (класс, не экземпляр)

Релизные ноты обещают исполняемый механизм — в коде его нет; или приписывают канону нормы,
которые живут только в нотах. Проекты, поверившие обещанию, живут без стража (STATUS у трёх
проектов дорос до 1647/1928 строк при «мягкой цели ~200» — «предупреждать было некому») или
переносят нормы из нот, а не из шаблонов.

## Repro (полевые)

Unliminium: `grep -n "softTarget\|statusLines\|200" .kaif/kaif-core.mjs` → пусто. KLAS:
`grep -n '200\b' .kaif/kaif-core.mjs` → пусто; `AGENT_GUIDE.md 2.1 :: "Repro" → 0`.

## Root cause

Релизные ноты пишутся ОТДЕЛЬНО от кода и шаблонов, и ничто механически не сверяет обещание с
поставкой: нет линта «каждый обещанный механизм существует» (эта грань — bugs/38, линт бандла),
а сам страж длины STATUS просто не был написан (норма 2.1 осталась прозой — ровно класс
EXP-0001/0002).

## Fix plan

Фаза **L4** родителя `plans/28_EPIC_kaif_2.2_L_update_field_fixes.md` (якорь: «### L4. Шум и
честность аудита»): warning-guard длины STATUS — СУЩЕСТВУЕТ (одна строка
в `check`: «STATUS.md: N строк при мягкой цели ~200 — пора на бонсай-стрижку»); нормы нот
сверяются с шаблонами линтом бандла (bugs/38). Гейт — критерий приёмки эпика №8 и инвариант
§9.7 («обещания релиза = код»); страж красным до фикса (наш собственный STATUS сейчас ~111
строк — фикстура для красного прогона строится в полигоне).
