## Симптом (класс, не экземпляр)

Пункт `placeholders` задания отправляет агента искать слоты «в канонической копии
`.claude/skills/`», где их нет: реальные слоты живут в файле чужой сферы или только внутри
бандла установщика. Ложный адрес — «первый шаг к тому, чтобы он начал ставить галочки не
глядя». Вторая грань: задание системно молчит о работе, которую не может сделать машинерия, —
секции для локально заведённых сфер, обвязка проекта (собственные валидаторы каркаса),
плейсхолдеры чужих сфер.

## Root cause

Список слотов пункта `placeholders` — статический текст, не результат скана дерева на момент
генерации; скоупы «локально заведённая сфера», «обвязка проекта», «чужая сфера в поставке» не
знакомы генератору задания как категории работы.

## Fix plan

Фаза **L5** родителя `plans/28_EPIC_kaif_2.2_L_update_field_fixes.md` (якорь: «### L5.
Остальные запросы + судья» — строка «placeholders с реальными адресами + строка про
сферы/обвязку/локальные валидаторы»): пункт placeholders строится сканом (реальные пути или
«слотов нет»); отдельные пункты задания — «в шаблон сферы добавлены секции X — перенеси в свою
сферу» и «обнови списки собственного валидатора каркаса». Смежно: плейсхолдеры чужих сфер не
блокируют приёмку (грань bugs/36, фаза L4).

## Разведка кода (L5, шаг 1 — 2026-08-07)

Точки генерации пункта `placeholders` (обе — статический текст без адресов):
- `framework/installer/KAIF-CORE.mjs` → `writeAdaptationTask` (~:404) — свежая установка:
  «Fill the remaining placeholders everywhere they occur (grep each)» — адресов нет вовсе;
- `writeUpdateTask` (~:568) — обновление: «fill each in the canonical .claude/skills/ copy» —
  ЛОЖНЫЙ адрес (полевые слоты жили в файле сферы и в трейлере end-chat).
- Фильтр `liveUnresolved` (cmdUpdate ~:1097; cmdInstall ~:1638) УЖЕ ограничивает пункт слотами,
  буквально лежащими на диске в деплой-`.md` (случай KLAS «слот только в бандле» отфильтрован);
  остаётся дефект ТЕКСТА — реальные пути не названы. Файлы сфер входят в deploy-набор →
  скан по deploy-файлам покрывает случай Unlim/KCam.
- Скоупы «локальная сфера» / «локальный валидатор»: пунктов не существует; материал для
  детекции есть — `marker.sphere` + отсутствие `.kaif/spheres/<sphere>.md` в deploy-наборе
  (локально заведённая сфера), дифф `templateShas` для `.kaif/spheres/_template.md` (шаблон
  сферы менялся в интервале), дифф множества скиллов `old.paths` vs `deployedPaths` (каркас
  менялся → локальные валидаторы протухли).
- Энфорсмент новых пунктов: `runFinalGates` (~:1313) выводит обязательные чекпоинты из ТЕКСТА
  задания; `cmdCheckpoint` (~:1796) валидирует id по тексту — новые пункты стерегутся без
  правки гейтов.
