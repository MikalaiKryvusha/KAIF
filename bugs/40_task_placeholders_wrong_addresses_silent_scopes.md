4 полевых отчётов; класс L-10 — `researches/15` §3.

## Симптом (класс, не экземпляр)

Пункт `placeholders` задания отправляет агента искать слоты «в канонической копии
`.claude/skills/`», где их нет: реальные слоты живут в файле чужой сферы или только внутри
бандла установщика. Ложный адрес — «первый шаг к тому, чтобы он начал ставить галочки не
глядя». Вторая грань: задание системно молчит о работе, которую не может сделать машинерия, —
секции для локально заведённых сфер, обвязка проекта (собственные валидаторы каркаса),
плейсхолдеры чужих сфер.

## Root cause

Список слотов пункта `placeholders` — статический текст, не результат скана дерева на момент
генерации; скоупы «локально заведённая сфера», «обвязка проекта», «чужая сфера в поставке» не
знакомы генератору задания как категории работы.

## Fix plan

Фаза **L5** родителя `plans/28_EPIC_kaif_2.2_L_update_field_fixes.md` (якорь: «### L5.
Остальные запросы + судья» — строка «placeholders с реальными адресами + строка про
сферы/обвязку/локальные валидаторы»): пункт placeholders строится сканом (реальные пути или
«слотов нет»); отдельные пункты задания — «в шаблон сферы добавлены секции X — перенеси в свою
сферу» и «обнови списки собственного валидатора каркаса». Смежно: плейсхолдеры чужих сфер не
блокируют приёмку (грань bugs/36, фаза L4).
