## Симптом (класс, не экземпляр)

Плейсхолдер `<PROJECT_NAME>` заполняется значением из `package.json`/имени каталога (нижний
регистр) и попадает в ЗАГОЛОВКИ документов, которые человек читает первыми
(`# klas — Project History`). Канон того же релиза 2.1 вводит правило «право действия ≠
авторство идентичности»: имя — никогда не решение агента. Формулировка поля: «Машине это
правило тоже стоит соблюдать».

## Repro (полевые)

## Root cause

Источник имени — технический идентификатор (каталог/`package.json.name`), а не канон
(`.kaif/kaif.json` / «Идентичность проекта» AGENT_GUIDE); каскад: раз попав в манифест, имя
тиражируется дальше.
