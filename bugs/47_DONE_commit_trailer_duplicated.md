# Bug 47 — commit.mjs дублирует трейлер Co-Authored-By, если он уже есть в сообщении

**Status:** ✅ DONE (2026-08-07)
**Version/build:** 2.1 build 138 · **When/context:** 2026-08-07, чтение обратно коммита закрытия N4 (`1fba47f`) по дисциплине bugs/46
**Fix accepted when (observable):** коммит через `--msg-file`, чей файл УЖЕ содержит строку трейлера, даёт в `git log -1 --format=%B` ровно ОДНО вхождение `Co-Authored-By` (счёт грепом), а сообщение без трейлера — по-прежнему получает его автоматически.

## Symptom

Раунд-трип сообщения коммита `1fba47f` дал `byte-equal: false` при идентичном префиксе 4466
символов: хвост длиннее на 56 — в опубликованном сообщении ДВЕ строки
`Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`. Кириллица цела (класс bugs/46 не
воспроизвёлся) — дефект чисто косметический.

## Repro (deterministic)

`node tools/commit.mjs --msg-file <файл, оканчивающийся строкой трейлера>` (код до фикса) →
`git log -1 --format=%B | grep -c Co-Authored-By` → 2.

## Root cause

`tools/commit.mjs:58` дописывал трейлер БЕЗУСЛОВНО (`msg + '\n\n' + trailer`), а канон коммитов
AGENT_GUIDE требует завершать сообщение трейлером — авторы msg-файлов ему следуют. Два источника
одной строки без проверки идемпотентности.

## Fix

Однострочный: `msg.includes(trailer) ? msg + '\n' : msg + '\n\n' + trailer + '\n'` — трейлер
дописывается только если его ещё нет. Зелёное доказательство наблюдением — ЭТОТ фикс-коммит:
его msg-файл несёт трейлер, в `git log` он один (счёт грепом в закрытии). Сообщение `1fba47f`
не переписывается: история — журнал, amend опубликованного — только по слову владельца.

## Decisions made without the owner

1. Дубль в `1fba47f` оставлен как есть (amend + force-push — брендовое/историческое решение
   владельца, дефект косметический). 2. Проверка — `includes` по полной уникальной строке
   трейлера (стеречь полной формой, не коротким вхождением — канон Стражей).
