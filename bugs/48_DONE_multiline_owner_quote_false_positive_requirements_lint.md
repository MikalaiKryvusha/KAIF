# Bug 48 — стоп-словарь требований ложно флагует многострочные «…»-цитаты владельца

**Status:** ✅ DONE (2026-08-07, найден и закрыт в фазе N5, `plans/55` шаг 2)
**Version/build:** build 137 · **When/context:** 2026-08-07, первый прогон
`kaif-requirements-lint check` по живому корпусу обвязки (интеграция N5).
**Fix accepted when (observable):** двухстрочная «…»-цитата со стоп-словами в секции
требований даёт 0 находок (ассерт s13 «многострочная «…»-цитата — половинки кавычек
легальны»); обе живые находки этого класса (`plans/34:35`, `plans/53:10`) исчезают из
прогона по репо без правки самих строк.

## Symptom

Из 13 находок первого живого прогона 3 пришлись на строки, являющиеся ЦИТАТАМИ владельца в
«ёлочках»: `plans/34:35` («…легко поддерживаемым, модульным, для легкой и удобной…» — 2
находки: perception + vague-verb) и `plans/53:10` («для лучшей просматриваемости истории…» —
unbounded «лучш»). Доктрина самого линтера: цитаты — не требования и легальны по построению;
однострочные пары «…» он уже стрипает.

## Repro (deterministic)

Секция требований с цитатой, перенесённой через строку:

```
## Критерии приёмки

Слово владельца дословно: «пусть будет гибкий
и удобный инструмент, работает быстро» — вкус-вердикт, фиксируем дословно.
```

До фикса: 3 находки (гибк/удобн/быстр), exit 1. После: 0, exit 0. Живой ассерт — s13
(«многострочная «…»-цитата»), красный доказан на дофиксовом модуле наблюдением (лог прогона:
«❌ s13 многострочная … — 3 unverifiable-word finding(s)»).

## Root cause

`stripCodeSpans` заменял только ПАРНЫЕ `«[^»]*»` в пределах одной строки. Прозаическая
цитата в русских документах регулярно ВРАПАЕТСЯ: открывающая « на одной строке, закрывающая »
на другой — обе половинки оставались видимыми словарю, а построчная легальность (`isLegal`)
не могла знать о соседней строке.

## Fix

`framework/tools/kaif-requirements-lint.mjs`: после парных стрипов обрабатываются половинки —
одиночная » без « раньше неё скрывает всё ДО себя (закрытие цитаты с прошлой строки);
одиночная « без » после неё скрывает всё ПОСЛЕ себя (открытие цитаты, закрывающейся ниже).
Класс закрыт по построению для любых врапнутых «…»-цитат; страж — ассерт s13, красный
доказан до фикса. Поставка: пересборка бандла тем же заходом (payload-модуль едет в
`.kaif/tools/`).

## Decisions made without the owner

Фикс классом в инструменте вместо вечных `(оправдано: цитата)` на каждой врапнутой цитате —
выбор по канону «закрывай класс, а не экземпляр» (BUG_FIXING) и EXP-0024 (шумный советник
приучает себя игнорировать); половинки ограничены «ёлочками» (направленные кавычки
однозначны), прямые "…" через строки не трогались — у них половинки неотличимы от дюймов и
апострофов (риск ложной легализации выше пользы).
