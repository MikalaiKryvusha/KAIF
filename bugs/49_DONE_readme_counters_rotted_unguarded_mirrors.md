# Bug 49 — счётчики README протухли: страж стерёг одно зеркало из четырёх

> **Создан:** 2026-08-07 (найдено при исполнении фазы O3, `plans/57`, шаг 5 — сверка счётчиков
> перед вписыванием новых чисел). **Родитель:** класс `bugs/09` (протухшие счётчики прозы) —
> рецидив на НЕОХВАЧЕННОЙ поверхности. **Статус:** ✅ DONE 2026-08-07 — оба README выправлены,
> класс закрыт стражем `tools/counters-guard.mjs` (красный доказан мутацией). **Вовне:** —.

**Fix accepted when (observable):** `node tools/counters-guard.mjs` печатает `counters OK` на
живом дереве и падает с exit 1, если ЛЮБОЕ из ПЯТИ зеркал (строка счётчиков в AGENT_GUIDE ·
строка счётчиков README EN · README RU · число сводов полигона в EN-половине · то же в
RU-половине) расходится с числами, которые печатают сборка и полигон.

## Symptom

`README.md` (обе языковые половины) утверждал: «150 bundle blocks; **662 modules**» и «песочный
полигон (**13** сводов)». Фактические числа на момент находки — 150 блоков / **666** модулей
(вывод сборки на HEAD до правок O3) и **13** сводов (совпадало). То есть счётчик модулей
разошёлся с реальностью на 4 и жил так минимум с фазы N4 (карта росла 662 → 665 → 666 в N4/O2, а
README не двигался ни разу).

## Repro (deterministic)

```
node tools/build-framework.mjs            # печатает актуальные "bundle N blocks", "M modules"
grep -n "bundle blocks; 662 modules" README.md   # зеркало утверждает 662 — расхождение
```

## Forensics

- Реестр пар «истина↔зеркало» (`AGENT_GUIDE.md`) содержал строку сверки счётчиков, но её команда
  стерегла РОВНО ОДНО зеркало — строку в самом AGENT_GUIDE:
  `grep -q '= 56; бандл 150 блоков; карта — 666 модулей' AGENT_GUIDE.md`.
- Зеркал у этого факта на самом деле пять: строка счётчиков в AGENT_GUIDE · та же строка в обеих
  половинах README · число сводов полигона в каждой из половин. Четыре из пяти не стерёг никто.
- Класс уже был оплачен дважды: `bugs/09` (протухшие счётчики прозы → счётчики печатает сборка) и
  EXP-0025 (число в тексте — цитата вывода инструмента, не арифметика в голове). Оба лекарства
  работали ровно там, куда дотянулись; поверхность README осталась вне охвата.

## Root cause

Страж был написан под ЭКЗЕМПЛЯР (одна строка одного файла), а не под КЛАСС (все зеркала одного
факта). Пока правки счётчиков шли через AGENT_GUIDE, страж зеленел — и его зелёный читался как
«счётчики сверены», хотя сверена была четверть.

## Fix

`tools/counters-guard.mjs` — страж класса: берёт ЖИВЫЕ числа из артефактов
(`dist/KAIF-CORE-BUNDLE.md` — блоки, `dist/kaif-module-map.json` — модули, `framework/*` —
встроенные файлы, `tools/sandbox-suite.mjs` — число сводов) и сверяет их со ВСЕМИ зеркалами
разом; расхождение печатается парой «ожидалось ↔ найдено» с именем файла. Строка реестра пар
заменена на вызов стража. `--selftest` доказывает, что страж умеет краснеть: он портит число в
копии дерева и требует падения.

## Decisions made without the owner

- **Страж — новый инструмент обвязки, а не расширение `check-framework`.** Обоснование: сверка
  прозы документов обвязки — не инвариант ПОСТАВКИ (check-framework стережёт генераты payload и
  падает на релизе). Смешение уронило бы сборку из-за строки в русском README — разные скоупы,
  разные гейты (граница «каждый документ отвечает на свой вопрос»).
- **Число сводов полигона включено в охват стража.** Оно живёт в тех же абзацах README и
  протухает тем же механизмом; отдельный страж на соседнюю строку был бы вторым экземпляром той
  же ошибки.
- **Задним числом README не переписывается сверх счётчиков** — правятся только числа, проза
  владельца не трогается.
