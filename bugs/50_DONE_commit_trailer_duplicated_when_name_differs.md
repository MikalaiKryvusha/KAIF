# Bug 50 — второй Co-Authored-By: идемпотентность трейлера сломана, если имя модели ДРУГОЕ

> **Создан:** 2026-08-08 (найдено при закрытии задачи T1, `plans/62` — чтение опубликованного
> коммита обратно). **Родитель:** класс `bugs/47` (дубль трейлера) — рецидив на СОСЕДНЕМ входе:
> тот фикс закрыл «тот же трейлер дважды», этот случай — «другой трейлер + канонический».
> **Статус:** ✅ DONE 2026-08-08 00:37 +03:00 — проверка идемпотентности переведена с одной литеральной строки
> на КЛАСС `^Co-Authored-By:`; наблюдено на живом коммите. **Вовне:** вопрос владельцу об имени
> модели в каноническом трейлере (см. «Открытый вопрос»).

**Fix accepted when (observable):** коммит, чьё сообщение из `--msg-file` уже несёт строку
`Co-Authored-By:` с ЛЮБЫМ именем, уходит в историю ровно с ОДНИМ таким трейлером —
`git log -1 --format=%b | grep -c "^Co-Authored-By:"` печатает `1`, а не `2`.

> ⚠️ Якорь `^` в критерии — не придирка, а исправленная ошибка: первая редакция этого документа
> просила `grep -c "Co-Authored-By"` без якоря, и на фикс-коммите он напечатал **3** — потому что
> считал ещё и строки ПРОЗЫ тела, цитирующие имя трейлера. Непроверяемый критерий приёмки —
> дефект уровня требований (`REQUIREMENTS_FRAMEWORK.md`, критерий 5 «Проверяемость»), пойманный
> здесь собственным исполнением.

## Symptom

Коммит `89a9058` (закрытие T1) ушёл в опубликованную историю с ДВУМЯ со-авторами:

```
Co-Authored-By: Claude Opus 5 (1M context) <noreply@anthropic.com>   ← строка 39 тела
Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>               ← строка 41, дописана инструментом
```

Из них `Claude Fable 5` этой работы не делал. Дефект не косметический: трейлер — это ЗАЯВЛЕНИЕ
об авторстве, и ложное заявление здесь того же класса, что ложный `[TESTED]`.

## Repro (deterministic)

1. Написать файл сообщения, чей последний абзац — `Co-Authored-By: <любое имя, НЕ «Claude Fable 5»>`.
2. `node tools/commit.mjs --msg-file <файл>`.
3. `git log -1 --format=%b | grep -c "Co-Authored-By"` → **2** (ожидалось 1).

## Forensics

`tools/commit.mjs:60` (до фикса):

```js
writeFileSync(tmpMsg, msg.includes(trailer) ? msg + '\n' : msg + '\n\n' + trailer + '\n');
```

`trailer` — одна литеральная константа (`'Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>'`,
строка 51). Проверка `msg.includes(trailer)` спрашивает «есть ли ИМЕННО ЭТА строка», а намерение
было «есть ли УЖЕ со-авторский трейлер». Любое другое имя модели проходит мимо проверки, и
инструмент дописывает канонический трейлер вторым.

## Root cause

**Страж сторожил экземпляр, а не класс** — ровно антипаттерн из `BUG_FIXING_FRAMEWORK.md`
(«Закрывай класс, а не экземпляр» + «Стереги полными уникальными строками/формами»). Фикс
`bugs/47` был верен для своего входа (то же сообщение, тот же трейлер) и по построению слеп к
соседнему. Пометка `[TESTED]` на строке 59 тоже была правдивой — она проверяла ровно тот
сценарий, который умел ломаться тогда.

Второй, более глубокий слой: имя модели в трейлере **зашито константой**, поэтому оно неизбежно
протухает при смене модели, работающей над проектом. Пока имя одно — дубля нет; как только над
репозиторием работает другая модель, класс просыпается.

## Fix

`tools/commit.mjs` — идемпотентность по КЛАССУ строки:

```js
writeFileSync(tmpMsg, /^Co-Authored-By:/mi.test(msg) ? msg + '\n' : msg + '\n\n' + trailer + '\n');
```

Сообщение без со-авторского трейлера по-прежнему получает канонический; сообщение с любым
трейлером не получает второго.

**TWINS:** `grep -rn "Co-Authored-By" tools/ framework/ .claude/ --include="*.mjs"` — дописывающий
сайт РОВНО ОДИН (`tools/commit.mjs`). Упоминания в `framework/skills/autoloop`, `end-chat`,
`.claude/skills/autoloop`, `pause` — прозаические указания («your standard co-author trailer»), не
машинерия; правки не требуют.

## Verification (наблюдением)

Фикс-коммит `4cfa94b` — его сообщение НАМЕРЕННО несёт трейлер `Claude Opus 5`, то есть ветка
«чужой трейлер» прошла живьём, а не в рассуждении:

```
git log -1        --format=%b | grep -c "^Co-Authored-By:"   →  1   (после фикса)
git log 89a9058 -1 --format=%b | grep -c "^Co-Authored-By:"  →  2   (до фикса, контраст)
```

Контрастная пара и есть доказательство: одна и та же команда на двух коммитах даёт разные числа,
и разница ровно та, ради которой фикс существует.

## Остаточная развилка (место вопросов — не здесь)

Имя `Claude Fable 5` зашито в ДВУХ местах (`tools/commit.mjs:51` и `AGENT_GUIDE.md` → «Коммиты») и
называет модель, которая эту работу не делала. Выбор имени — решение владельца, поэтому вопрос
живёт по канону в `interviews/interview_012_commit_trailer_model_name.md`, а не хвостом этого
документа. Механическую часть бага он не блокирует: дубль трейлера закрыт независимо от имени.

## Decisions made without the owner

- **Фикс класса, а не имени.** Правка ограничена идемпотентностью проверки; константа `trailer`
  и строка `AGENT_GUIDE` НЕ тронуты — имя со-автора это конвенция владельца, и менять её молча
  было бы решением уровня идентичности.
- **Опубликованный `89a9058` не переписан.** Исправление потребовало бы amend + force-push
  опубликованной истории — действие из списка `AUTH:`. Дефектный коммит остаётся в летописи, а
  этот документ объясняет, почему в нём два со-автора.
