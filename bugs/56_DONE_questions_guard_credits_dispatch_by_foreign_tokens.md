## Вектор цели (Avoid)

Не допустить, чтобы система считала разнесённым ответ владельца, который физически не разнесён.
I20 — единственный механизм, доказывающий доезд оплаченного человеком решения до артефакта, и его
зелёное читают как факт `AGENT_GUIDE.md:652` и критерий готовности к пушу в `STATUS.md`.

**Fix accepted when (observable):** (1) фикстура «разнесён только Q3, но в адресате есть строки
чужих интервью» → `node tools/questions-guard.mjs --root <SBX> --baseline <SBX>/baseline.json`
даёт EXIT=1 и ровно две строки «✗ [разнос не выполнен (I20)]» — про Q1 и про Q2; (2) живой
репозиторий не покраснел: EXIT=0 и три строки статистики без изменений; (3) `--selftest` зелёный и
содержит новую мутацию «адресат цитирует ЧУЖОЕ интервью с тем же id вопроса».

**Сегодняшнее измеренное состояние:** все 11 живых пар (интервью 008–011) удовлетворяют совместной
форме — 6 из них в пределах 172 символов; критерий (2) достижим, живое дерево после сужения не
краснеет.

## Symptom

`tools/questions-guard.mjs:180` — два НЕЗАВИСИМЫХ теста существования по всему тексту
документа-адресата:

```js
          const cited = docs.some((c) => numRe.test(c.text) && c.text.includes(q.id));
```

Номер интервью в одном абзаце и голое `QN` в другом — в том числе оба из цитат ПОСТОРОННИХ
интервью — засчитываются как разнос. Подкласс: `includes('Q1')` истинно внутри `Q12`.

## Repro (deterministic)

Полностью — в карточке F2 аудит-отчёта, с обоими прогонами (как есть → EXIT=0; убрать две чужие
строки → EXIT=1 и два нарушения). Цена наступления в живом репозитории нулевая: `plans/26` уже
содержит нужные токены в строках 77 и 79.

## Root cause

Примета вместо утверждения (семейство 7): конъюнкция двух неограниченных existence-тестов вместо
одной совместной приметы в окне одной строки. Сужение по файлу-адресату сужает НАБОР ФАЙЛОВ, а не
место внутри файла.

## ✅ ЗАМЕР СНЯТ ПЕРЕД КОДОМ — и он опроверг ОБА числа карточки

Карточка предлагала окно `{0,40}`, а её же поле «сегодняшнее состояние» говорило «6 из 11 в
пределах 172 символов». Числа противоречили друг другу, поэтому измерено самостоятельно —
по всем 11 живым парам «отвеченный вопрос → адресат»:

| Что мерили | Результат |
|---|---|
| пар с совместной приметой | 11 из 11 (без совместной приметы — 0) |
| максимальный разрыв между номером интервью и `QN` **в одной строке** | **2 символа** (не 172) |
| пар, у которых цитата разорвана ПЕРЕНОСОМ строки | **1** — интервью 008 Q3 → `plans/48:102–103`: «…ПОДТВЕРЖДЕНО: интервью» / «   №008, Q3 …» |

**Оба вывода поменяли фикс.** Окно 172 оказалось лишним на два порядка. А жёсткое окно «одна
строка», которое буквально требовал эскиз, покрасило бы живое дерево на паре 008 Q3 — то есть
критерий (2) провалился бы, и это была бы потерянная итерация. Класс «врап не должен ослеплять
стража» в репозитории уже оплачен (`tools/counters-guard.mjs`), поэтому решение взято оттуда:
мягкий перенос снимается ПЕРЕД проверкой, пустая строка остаётся границей абзаца.

## Fix plan

- [x] 1. Совместная примета в окне, оба порядка следования.
      → `jointRe`: `NUM_SRC[^\n]{0,40}?qSrc | qSrc[^\n]{0,40}?NUM_SRC` по тексту, с которого снят
      мягкий перенос (`unwrap`). Константа `CITATION_WINDOW_CHARS = 40` — с запасом к замеренным 2.
- [x] 2. Граница `(?![0-9])` на идентификаторе вопроса — убивает подкласс `Q1` внутри `Q12`.
      → плюс экранирование `q.id` в регэкспе.
- [x] 3. Мутация в `--selftest`: адресат цитирует чужое интервью → КРАСНЫЙ.
      → добавлены ТРИ мутации (7, 8, 9), селфтест 6 → 9.
- [x] 4. Не трогать: эвристику I21, резервное чтение адресата-КОДА, ratchet G2 и базовую линию.
      → I21 продолжает пользоваться прежним `numRe` (вынесен в `NUM_SRC` без смены поведения);
      резервное чтение адресата-КОДА проверено ЖИВЬЁМ — пары интервью 008 Q1/Q2 живут в
      комментариях `tools/lib/review-core.mjs` и `tools/review.mjs` и остались зелёными;
      `tools/questions-guard.baseline.json` не тронут, строка долга «11 из 12» не изменилась.

## TWINS

`TWINS: searched` конъюнкции независимых existence-тестов по документу
(`X.test(t) && t.includes(Y)`, `corpus.some(...)`) по `tools/` и `framework/` — **found 1 site:
none other.** Кандидаты опровергнуты с причинами (`EXP-0051` — близнец определяется совпадением
МЕХАНИЗМА, а не формы):

- `tools/questions-guard.mjs` I21 (`corpus.some((c) => numRe.test(c.text))`) — ОДИН тест, и это
  канонизированная эвристика для старых интервью, где единица — ФАЙЛ, а не вопрос («не трогать»
  карточки). Ломаться нечему.
- Ассерты сводов (`s03`, `s05`, `s07`, `s08`, `s09`, `s11`) вида
  `/re/.test(r.out) && r.out.includes('…')` — корпус там короткий вывод ОДНОЙ команды, который
  породила сама проверяемая команда; третьей стороны, законно сеющей те же токены, не существует.
  Назвать поломку невозможно — это соседи по форме.
- `framework/installer/KAIF-CORE.mjs:1485` (`task.includes('checkpoint judge') && /^tag: judge
  done$/m.test(task) && …`) — тесты якорены на ПОЛНЫЕ строки машинного формата (`^…$`, флаг `m`), а
  не на свободные токены, и оба пишет сама машинерия. Более того, соседний цикл несёт комментарий
  о том, что этот класс там уже закрыт («a bare `/checkpoint (\w+)/` scan once matched the word
  "for"»), — урок применён до меня.

## Decisions made without the owner

1. **Окно взято 40, хотя замер дал 2.** Ровно замеренное число сделало бы стража хрупким к любой
   законной вставке внутрь цитаты («интервью №008 (контур K5), Q3»). 40 — компромисс: на два
   порядка уже прежнего «где угодно в файле» и с запасом к наблюдаемой практике. Число названо
   константой с обоснованием в комментарии, а не вписано в регэксп.
2. **Мягкий перенос снимается, а пустая строка — нет.** Полное схлопывание всех переносов (как во
   `flat()` у `counters-guard`) слило бы абзацы и вернуло бы часть исходного класса: токены из
   СОСЕДНЕГО абзаца снова оказались бы «рядом». Схлопывается только продолжение строки.
3. **Мутаций добавлено три, а не одна.** Карточка требовала одну («чужое интервью»). Но фикс несёт
   ТРИ независимых свойства (совместность · граница `Q1`/`Q12` · терпимость к врапу), и каждое
   обязано быть доказано своим красным либо своим зелёным — иначе следующая правка тихо снимет
   одно из них.
4. **Красный доказан на СТАРОМ коде, а не только на новом.** Вернул прежнее выражение в файл,
   прогнал селфтест: мутации 7 и 8 дали `red=false` — то есть страж молчал ровно там, где теперь
   краснеет. Без этого шага новые мутации были бы утверждением о себе.
