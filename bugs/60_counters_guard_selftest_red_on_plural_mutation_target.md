## Вектор цели (Avoid)

Не допустить, чтобы страж числовых зеркал стоял с НЕДОКАЗАННЫМ красным на одном из своих зеркал.
`counters-guard` — единственный исполнитель пяти строк реестра пар (`AGENT_GUIDE.md:516–520`), а
канон требует: «страж, который ни разу не краснел, ничего не доказывает»
(`BUG_FIXING_FRAMEWORK.md` → Стражи). Сегодня `--selftest` не может доказать красный на зеркале
AGENT_GUIDE и уходит с кодом 1 — то есть команда, которой доказывают стража, сама сломана.

**Fix accepted when (observable):** `node tools/counters-guard.mjs --selftest` → EXIT=0 и строка
`✅ selftest: испорченное число блоков в AGENT_GUIDE — КРАСНЫЙ`; при этом мутация обязана
по-прежнему ПАДАТЬ, если её цель не найдена (самопроверка мутации не ослабляется).
**Сегодняшнее измеренное состояние:** EXIT=1, первая строка вывода —
`❌ selftest: цель мутации не найдена в AGENT_GUIDE.md: "бандл 161 блоков"`.

## Root cause

`tools/counters-guard.mjs` строит цель мутации конкатенацией с зашитым окончанием:

```js
const hitGuide = mutate('AGENT_GUIDE.md', `бандл ${live.blocks} блоков`, `бандл ${live.blocks + 7} блоков`);
```

а проза согласует числительное по-русски (`AGENT_GUIDE.md:410`):

```
… = 57; бандл 161 блок; карта — 689 модулей) — не переписывай эти
```

161 оканчивается на «один» → «блок», а не «блоков». Пока число блоков было, например, 157, формы
совпадали и селфтест зеленел; на 161 они разошлись. То же ждёт остальные конкатенации с русскими
окончаниями внутри `selftest()` и `WORDS` при переходе через 1/2–4/5–20.

Класс — «зеркало факта, сшитое с источником ЧЕРЕЗ ОКОНЧАНИЕ СЛОВА»: сверка живёт в регэкспе
(`/бандл (\d+) блок\S*/` — терпит любую форму, потому и зелёная), а мутация — в конкатенации,
которая формы не знает. Один факт, две несогласованные формулы.

## Fix plan

- [ ] 1. Строить цель мутации ТЕМ ЖЕ способом, каким её ищет сверка: взять подстроку по регэкспу
      зеркала из живого текста (`guide.match(MIRRORS[0].re)`), а не собирать её из числа и
      угаданного окончания.
- [ ] 2. Самопроверку мутации («цель не найдена» → ❌) НЕ ослаблять — она и поймала этот дефект.
- [ ] 3. Пройти остальные конкатенации `selftest()` тем же взглядом (`полигон (N сводов)`,
      `**N модулей**`) — у них те же грабли на других числах.
- [ ] 4. Красный доказать: временно испортить регэксп зеркала → селфтест обязан краснеть.

## TWINS

`TWINS: searched` конкатенации русских окончаний с живым числом в `tools/counters-guard.mjs`
(`selftest()` + карта `WORDS`) — кандидатов три: `бандл N блоков`, `полигон (N сводов)`,
`**N модулей**`. Механизм провала один и тот же (окончание зашито, сверка терпима к форме),
поэтому это НАСТОЯЩИЕ близнецы, а не соседи по форме (`EXP-0051`). Наступают они на других
числах, поэтому сегодня молчат — инвентарь снят, чинить списком.
