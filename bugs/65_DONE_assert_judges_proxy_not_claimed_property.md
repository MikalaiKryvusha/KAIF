## Symptom

Четыре разных проверки в четырёх разных подсистемах зеленеют по признаку, который НЕ является тем
свойством, которое они объявлены стеречь. Каждая доказана мутацией: дефект внесён — проверка
осталась зелёной.

тождество множеств») и вернулся в четырёх новых местах.

## Root cause

Проверка пишется по тому, что удобно достать в точке проверки, а не по тому, что заявлено. Прокси
и свойство совпадают в момент написания — и расходятся при первом же изменении окрестностей
(появился режим `anonymous`; README стал двухполовинным; ловушка получила собственную фикстуру;
у смерти контура стало два канала). Зелёный при этом читается как «свойство проверено».

Второй, усиливающий слой: у трёх из четырёх ассертов красная мутация НИКОГДА не исполнялась —
проверка, которая ни разу не падала, ничего не доказывает (`BUG_FIXING_FRAMEWORK.md`:98).

## Decisions made without the owner

1. **Счётчик алиасов не перенесён к записи, а СНЯТ с плановой стороны и читается с диска.**
   План бага предлагал два хода — считать по факту `writeFileSync` или пересекать списки. Выбран
   третий: оба предложенных ведут счёт РЯДОМ с записью, то есть снова в точке, которая не знает о
   следующем фильтре, а этот класс уже дрейфовал дважды (ключи пакета → применённые правки).
   Чтение диска стоит 35 маленьких файлов раз в установку и не может разойтись по построению.
2. **Признак двухполовинности ВЫЧИСЛЯЕТСЯ, а не помечается флагом в реестре пар.** Флаг был бы
   списком, который кто-то однажды забудет продлить, — ровно форма, которую волна R1 и лечит.
   Цена: одноязычный документ, где кто-то поставит якорь `<a id="russian">` не по делу, начнёт
   судиться по половинам; конвенция якоря в проекте одна и уже используется двумя инструментами.
3. **Переменные окружения `KAIF_CONTOUR_*` принимают только БОЛЕЕ СТРОГОЕ значение, чем канон.**
   Тестовый knob, умеющий ослаблять поведение, — дыра в обещании владельцу (терпение контура к
   молчащему человеку). Односторонность делает knob безопасным по построению; расширить порог
   окружением нельзя.
4. **Бюджет ожидания смерти по тишине — 8 с, названной константой.** Не «побольше на всякий
   случай»: зависший контур иначе читался бы как медленный.
5. **Побочный `EPERM` в QA7 починен ЗДЕСЬ, а не отдельным документом** — дефект внесён этим же
   фиксом (убитый процесс держал каталог фикстуры) и жил ровно один прогон.
