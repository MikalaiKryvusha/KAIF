**Было:** `dedupScan` объявлялся замыканием внутри самого свода и читал каталог, созданный этим же
тестом тремя строками выше. Продукт в проверку не входил вовсе.

**Стало** (`tools/sandbox/s04-anon-legacy.mjs`): контракт читается из РАЗВЁРНУТОГО установкой
навыка `.claude/skills/report-bug/SKILL.md`, а формат отпечатка ВЫВОДИТСЯ из его же шаблона —
поэтому потеря контракта в поставке красит ловушку, а смена формата ведёт её за собой. Стерегутся
полные уникальные строки, не короткие вхождения:

- `A match on surface + symptom-class (the version is NOT part of the key) = the SAME signal`
- `kaif-fp: <surface> :: <symptom-class> :: v<major.minor>`

**Доказано красным на той же мутации, что прежде проходила зелёной:** вырезание из
`dist/KAIF-CORE-BUNDLE.md` всего KAIF-ветвления навыка `/report-bug` (блок `## Branch first …` →
`## What to do`, **4503 символа**: дедуп, fingerprint, шаблоны A/B, гейт отправителя) →
`node tools/sandbox/s04-anon-legacy.mjs` **exit=1**, два контрактных ассерта красные. До фикса тот
же вырез давал exit=0 и 50 ✅ / 0 ❌. База после фикса: **53 ✅ / 0 ❌**, `npm run test:core` —
all 14 suites green.
**Fix accepted when (observable):** каждый из четырёх ассертов краснеет на мутации, названной в
разделе «Инвентарь класса», и молчит на законной форме; мутация записана фикстурой или
`--selftest`, а не сессионным прогоном.

## Symptom

Четыре разных проверки в четырёх разных подсистемах зеленеют по признаку, который НЕ является тем
свойством, которое они объявлены стеречь. Каждая доказана мутацией: дефект внесён — проверка
осталась зелёной.

Класс оплачен проектом дважды (`bugs/55` F1, EXP-0056 «мощность множества — прокси, а свойство —
тождество множеств») и вернулся в четырёх новых местах.

## Root cause

Проверка пишется по тому, что удобно достать в точке проверки, а не по тому, что заявлено. Прокси
и свойство совпадают в момент написания — и расходятся при первом же изменении окрестностей
(появился режим `anonymous`; README стал двухполовинным; ловушка получила собственную фикстуру;
у смерти контура стало два канала). Зелёный при этом читается как «свойство проверено».

Второй, усиливающий слой: у трёх из четырёх ассертов красная мутация НИКОГДА не исполнялась —
проверка, которая ни разу не падала, ничего не доказывает (`BUG_FIXING_FRAMEWORK.md`:98).
