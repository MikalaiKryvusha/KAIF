# Bug 71 — правило объявлено механизированным, а исполнителя у него нет: четыре обещания без кода

**Status:** 🔴 OPEN
**Version/build:** build 237 · **When/context:** круг R1 фазы R (`plans/59` шаг 7), 2026-08-09
**Fix accepted when (observable):** у каждого из четырёх правил либо появляется исполнимая команда
в ритуале (и снятие команды краснит свод), либо формулировка канона правится с изъявительного
наклонения на честное «правило текстовое, механизации нет» — третьего исхода нет.

## Symptom

Канон обоих слоёв утверждает **изъявительно**, что четыре правила стерегутся механически. Ни у
одного из четырёх нет исполнителя: ни команды, ни ассерта, ни шага навыка, ни хука.

Читатель канона — в первую очередь слабая сессия — принимает такие строки за гарантию и не
проверяет то, что «уже проверено машиной». Это тот же класс, что ложный `[TESTED]`, только на
уровне правила, а не артефакта.

## Repro (deterministic)

**№1 — «показ — действие, а не ссылка» (I17).** `AGENT_GUIDE.md:745` (то же в `framework/` и
`dist/`): «Правило стережётся механически — греп собственного ответа на „двойным кликом /
открывается офлайн / см. файл / лежит по пути“ рядом с расширением артефакта».

```
grep -rn "двойным кликом\|см\. файл\|лежит по пути\|double-click\|see the file" tools/ --include=*.mjs
# → пусто (0 строк)
grep -rn "открывается офлайн\|лежит по пути" .claude/ --include=*.md --include=*.json
# → только сам текст нормы (owner-reviews/SKILL.md:18,117,123)
```

В `.claude/settings.json` три хука (`session-start-refresh`, `prompt-refresh-timer`,
`stop-status-guard`) — ни один не про показ. При этом блок «Доказательство красным, страж за
стражем» (`owner-reviews/SKILL.md:492`) объявляет для I17 красную фикстуру — красное доказательство
записано для проверки, которой не существует.

**№2 — отправка полевого отчёта наверх.** `framework/readmes/reports.md:14` (едет в чужие проекты):
«Origin-tracked deployments also send them upstream; detached ones keep them local only.»

```
grep -rn "UPDATE_REPORT|INSTALL_REPORT|field report|field-report" framework/ | grep -v readmes/reports.md
# → 24 строки, ни одна не описывает отправку отчёта в origin
```

Машинерия сознательно делегирует доставку навыкам (`KAIF-CORE.mjs:531-532` — «report delivery
upstream is the skills' business»), а навыки её не исполняют: `/kaif-update` ветвит наверх ТОЛЬКО
тикеты `/report-bug`; `/kaif-version` лишь упоминает неотправленные. Наверх не уходит ничего.

**№3 — маркер тест-статуса у машинерии.** `AGENT_GUIDE.md:49`, чек-лист, пункт 10 — обязательный.

```
for f in tools/*.mjs tools/lib/*.mjs tools/sandbox/*.mjs; do
  n=$(grep -c '\[TESTED:\|\[NOT-TESTED\]' "$f"); [ "$n" = 0 ] && echo "NO-MARKER: $f"; done
# → 20 файлов из 44 (45 %)
```

Нарушители — ровно те файлы, что правились чаще всего: `counters-guard.mjs` (правлен в фазе Q
2026-08-09), `sandbox-suite.mjs`, `sandbox-mute-guard.mjs`, `module-map-lib.mjs`,
`build-diagrams.mjs`, `readme-pdf.mjs`, `kaif.mjs`, `lib/sandbox-run.mjs` и своды
s02–s11, s13, s14. Исполняющей точки нет ни в коде, ни в npm-скриптах, ни в хуках.

**№4 — гарантия приватности слепка стоит на `[NOT-TESTED]`.** `tools/stylometry-snapshot.mjs:32`
несёт голый `// [NOT-TESTED]`, при этом `AGENT_GUIDE.md:628` и сам публичный
`AUTHOR_STYLOMETRY.md:29` публикуют его свойство как ФАКТ. У блокирующей приёмки `selfCheck`
(`:276`, `process.exit(1)` на `:409`) нет ни `--selftest`, ни любой другой фикстуры красного:
`grep -rln "\[TESTED:" --include=*.mjs tools/ | wc -l` → 22 файла с маркером, 15 инструментов с
`--selftest` — и ноль у этого.

## Root cause

Правило и его механизация писались одним заходом, и **текст обогнал код**: формулировка
«стережётся механически» звучит как описание существующего, хотя описывала намерение. Ни одна
проверка не ловит расхождение «канон обещает команду ↔ команда существует», потому что такой пары
нет в реестре.

У №4 механика отдельная и тяжёлая: маркер `[NOT-TESTED]` честно стоял в исходнике, а два
потребителя (канон обвязки и публичный артефакт) построили на нём вслепую — ровно то, что
`TESTING_FRAMEWORK.md:45` запрещает пунктом 2.

## Fix plan

- [ ] **№1:** написать греп-проверку показа (одна команда, форм-лист из дословных полевых слов) и
      поставить её шагом в `/end-chat`; либо снять из канона изъявительное «стережётся
      механически». Красная фикстура для неё уже описана в навыке — исполнить её.
- [ ] **№2:** либо реализовать доставку отчёта наверх (тот же путь, что у тикетов `/report-bug`,
      с гейтом одобрения), либо переписать строку README поставки на то, что происходит на самом
      деле. Строка едет в чужие проекты — цена неверной нормы умножается на парк.
- [ ] **№3:** завести линтер маркеров машинерии (`tools/*.mjs` обязаны нести `[TESTED: …]` или
      `[NOT-TESTED]`), поставить преполётом в `npm run test:core`; проставить маркеры двадцати
      файлам ПО НАБЛЮДЕНИЮ, а не штампом.
- [ ] **№4:** закрыть `--selftest` слепка (см. `bugs/66` №1) и только затем перевести маркер в
      `[TESTED: …]` с уликой; до этого — не публиковать его гарантию как факт ни в каноне, ни в
      самом слепке.
- [ ] Завести общий детектор класса: греп канона на изъявительные формы механизации
      («стережётся механически», «страж:», «проверяется командой») с требованием, чтобы названная
      команда существовала в `tools/` или в шаге навыка.
