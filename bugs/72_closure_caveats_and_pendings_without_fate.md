# Bug 72 — оговорки и PENDING закрытий уходят без судьбы и без адреса: шесть повисших обязательств

**Status:** 🔴 OPEN
**Version/build:** build 237 · **When/context:** круг R1 фазы R (`plans/59` шаг 7), 2026-08-09
**Fix accepted when (observable):** `grep -rn "PENDING" plans/ researches/` не даёт ни одной живой
строки без судьбы (*подтверждено / опровергнуто / спрошено*); у каждой оговорки закрытия есть
носитель по адресу; страж класса краснеет на подсунутом PENDING без судьбы.

## Symptom

Шесть обязательств, взятых при закрытии фаз, не имеют ни исполнителя, ни адреса, ни судьбы — при
этом их родительские документы записаны закрытыми, а два из них прямо утверждают «PENDING-строк
нет».

Канон говорит обратное дословно (`AGENT_GUIDE.md:676-678`): «Неразрешённые допущения (строки fable
`PENDING:`) закрываются здесь же: каждое — *подтверждено / опровергнуто / спрошено*, ни одно не
выпадает молча».

## Root cause

Закрытие фазы выполняется как **пересказ критериев**, а не как их переисполнение: обязательство
считается снятым в момент, когда о нём написали «вынесено в …», не проверив, что приёмник его
принял. Ни у PENDING, ни у оговорок нет машинного стража — в проекте нет ни одной проверки,
которая ищет живой `PENDING:` без судьбы.

Второй слой — **адрес вместо судьбы**: строка «вынесено в Фазу R» выглядит адресом, но приёмник о
ней не знает; долг, названный без принимающей стороны, эквивалентен долгу забытому.

## Fix plan

- [ ] Свести все шесть обязательств в один список и дать каждому судьбу
      (*подтверждено / опровергнуто / спрошено*) — прямо в этом документе, потом разнести.
- [ ] №1/№2: три PENDING эпика M — либо вопрос владельцу (место вопросов — `interviews/`), либо
      явное «опровергнуто» с причиной. Молча они не закрываются.
- [ ] №3: route-нота — либо в `TEMPLATE_NOTES['2.2']` (дополнять массив, не пересоздавать: ассерт
      `s04` стережёт), либо строкой долга с адресом в `STATUS.md`.
- [ ] №4/№5: проставить в `researches/19` §1.2 адреса источников; переписать строку Antigravity по
      живому источнику; сверить карту с `framework/hooks/README.md` — пара «карта ↔ поставка» в
      реестр пар.
- [ ] №6: ресинкнуть `claude-code.md` и `zoo-code.md`; в чек-листе деплоя эталона заменить ручные
      правила на мерж `.kaif/hooks/settings-fragment.json`.
- [ ] Grok Build: привести обе таблицы к двум исходам — либо «контракт подтверждён» с живой
      цитатой, либо «не верифицирована» в обоих файлах.
- [ ] Завести стража класса: живой `PENDING:` без судьбы и строка «вынесено в <документ>», которой
      нет в названном документе, — красный в `doc-header-lint`.
