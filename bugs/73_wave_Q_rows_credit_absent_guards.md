# Bug 73 — таблица волны Q кредитует стражей, которых нет: заявление «у каждого из 22 дефектов стоит страж» неверно для шести строк

**Status:** 🔴 OPEN
**Version/build:** build 237 · **When/context:** круг R1 фазы R (`plans/59` шаг 7), 2026-08-09
**Fix accepted when (observable):** для каждой из 22 строк таблицы `plans/67` названный страж
краснеет на ДОСЛОВНОЙ форме своего дефекта (мутация на копии) — либо строка честно переписана в
«правило текстовое, механизации нет»; `STATUS.md` повторяет ровно то, что доказано.

## Symptom

`STATUS.md:41` заявляет: «у каждого из **22 дефектов** волны стоит страж или правило». Заявление
переисполнено построчно и не выдержало: три строки не называют ни стража, ни правила (только
«текст исправлен»), а ещё три называют стража, который на дословной форме своего дефекта
**молчит**.

Фаза Q существовала ради того, чтобы волна владельца не повторилась. Класс, закрытый экземпляром,
вернётся тем же способом, каким пришёл.

## Repro (deterministic)

**(а) Закрыто экземпляром — стража нет.** Строки #8 (подпись таблицы), #17, #18 (блоки цитат у
фраз установки) закрыты формулировками «текст исправлен» / «блоки цитат на месте». Мутация на
копии возвращает дефект:

```
# снять '>' у фраз установки в ОБЕИХ половинах копии README и в копии нот
node tools/showcase-lint.mjs <копия>/README.md
# → exit=0 · «✅ нарушений правил витрины нет»
# подпись «Таблица 6 — Метрики версии KAIF 2.2» → «таблица 6 — цифры»
node tools/showcase-lint.mjs <копия>/README_caption.md   # → exit=0
```

Причина в исходнике: `tableLabels()` (`showcase-lint.mjs:189`) читает только первую клетку строки
таблицы; оси HALVES считают `###`, `##`, `<img>` и строки таблиц — блоки цитат и подписи не считает
никто.

**(б) Страж назван, но класс не держит.** Три строки:

| Строка волны | Кредитованный страж | Мутация дословной формы | Результат |
|---|---|---|---|
| #2 «грамматика авторской трактовки символики, три места» | `voice-lint` («жёсткие пункты портрета») | вернуть в копию нот сломанные падеж/управление/согласование («замыкание цикл», «под наблюдение проектов, который им пользуются») | `node tools/voice-lint.mjs` → **exit 0**, «жёстких нарушений нет» |
| #4 «портрета голоса нет в Таблице 1 канон-документов» | `counters-guard` («счётчик ключевых документов стережёт») | удалить обе строки `AUTHOR_STYLOMETRY.md` из Таблицы 1 | `counters-guard` → **exit 0**, «38 зеркал сверены»; `showcase-lint` → exit 0 |
| #21 «„Порядок сертифицирован в поле… (домашка 02)“ — очередное оправдание» | класс `EXCUSE` | фикстура «Порядок сертифицирован в поле на локальной модели 12B (домашка 02).» | `showcase-lint` → **exit 0**; контроль «(измерено в эпике 1.5)» → «❌ EXCUSE (1)» |

Дефект #21 — один из двух, названных владельцем УЖЕ ВНУТРИ фазы Q, то есть самый свежий рецидив
класса; в форм-листах `EXCUSE` (`showcase-lint.mjs:58-66`) нет ни «домашк», ни «план», ни «эпик»,
ни `bugs/`, ни `plans/`.

**(в) Оценочная ставка на витрине без источника.** `README.md:523` (и RU-двойник `:1072`):
«**1 194 typed pages** of 1 800 characters». Ставка «1 800 знаков на машинописную страницу» не
названа нигде в репозитории:

```
node tools/estimates-guard.mjs                       # exit 0, «констант без источника нет»
grep -rn "1800\|машинопис\|typed page" tools/*.mjs   # → ставки нет
grep -n "const WATCHED" tools/estimates-guard.mjs    # → ['tools/kaif-stats.mjs'] — витрину не смотрит
```

Арифметика подтверждает, что это настоящая внешняя ставка, посчитанная руками и написанная прямо
на витрину: 2 149 895 / 1 800 = 1 194,4. Правило 8 раздела «Витрина» (`AGENT_GUIDE.md:517-519`)
требует названного внешнего источника; критерий 4 `plans/67` при этом НЕ нарушен — он по своей
формулировке говорит только о константах инструментов, и страж по построению (`WATCHED` из одного
файла) рукописную витринную ставку не видит.

## Root cause

Таблица волны заполнялась **по факту исправления текста**, а колонка «Страж или правило» —
по факту существования подходящего инструмента, без переисполнения на дословной форме дефекта.
Там, где инструмент существовал, ему записали класс; проверку «краснеет ли он именно на этой
форме» не делали.

Это ровно тот промах, о котором предупреждает EXP-0074: правило языка стережётся ФОРМОЙ, в которой
его нарушили, а не обобщением этой формы. «Жёсткие пункты портрета» и «счётчик ключевых
документов» — обобщения; они ловят воздух.

Отдельная причина у (в): критерий приёмки фазы был сформулирован уже под возможности стража
(«константы инструментов»), а дефект живёт на витрине — зона, которую критерий не покрывает по
своей же формулировке.
