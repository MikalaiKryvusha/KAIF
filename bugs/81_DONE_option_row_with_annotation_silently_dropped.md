# Bug 81 — помеченный вариант молча выпадает из вопроса: владелец увидел три варианта из четырёх

**Status:** ✅ DONE (2026-08-09 13:35 +03:00)
**Version/build:** build 268 · **When/context:** починки R1, `bugs/72` (написание интервью №017),
2026-08-09 13:31 +03:00
**Fix accepted when (observable):** число вариантов, которые ВИДИТ владелец на странице, равно
числу буквенных строк, которые НАПИСАЛ автор, — на каждом живом документе; потеря части вариантов
краснит стража (не только потеря всех); мутация записана фикстурой `--selftest`, а не прогоном.

## Symptom

Клетка буквы с пометкой в скобках — `| **A** (рекомендация агента) | … |` — не опознавалась
разбором вариантов, и вариант ИСЧЕЗАЛ со страницы владельца. Молча: без ошибки, без
предупреждения, при зелёных гейтах.

Форма прижилась: ею написана рекомендация агента почти в каждом интервью. То есть выпадал
систематически **ровно тот вариант, который агент рекомендовал**.

**Дефект достиг владельца.** В `interviews/interview_016` (опубликован, отвечен 2026-08-09
00:14 +03:00) автор написал четыре варианта, страница показала **три** — потерялся `A`. Владелец
ответил свободным текстом, и его ответ совпал с содержанием `A`, то есть он выбрал вариант,
которого страница ему не предлагала.

## Repro (deterministic)

```
node tools/verify-contour.mjs --etalon-only     # ДО фикса: зелено
```
и при этом:
```
| **A** (рекомендация агента) | … |   ← человек видит вариант
parseQuestions(md)[0].options          ← парсер его не возвращает
```
Проба по всем живым интервью (счёт «жирная буква в начале первой клетки» против разбора):
`interview_016` — человек 4, парсер 3; `interview_017` — человек 8, парсер 4 (Q1 — ноль).

## Forensics — почему это не заметил НИ ОДИН страж

Три проверки стояли на этом самом месте, и все три были зелёными:

| Кто проверял | Что мерил | Почему молчал |
|---|---|---|
| `questions-guard` ось «вопрос НЕОТВЕЧАЕМ» (`bugs/62`) | вариантов **ноль** | ноль — ЧАСТНЫЙ случай потери; при 3 из 4 ось молчит по построению |
| `verify-contour` ось G11 «молча съеденный вариант невозможен» | строки-кандидаты == разобранные варианты | примета делила с парсером **ТО ЖЕ слепое пятно**: обе требовали разделитель клетки сразу после буквы |
| замороженный эталон | числа против прошлых чисел | прошлые числа были сняты с уже дефектного разбора — заморозили дефект |

Средняя строка — рецидив. Комментарий над приметой G11 УЖЕ рассказывал эту историю: «страж против
„молча съеденного варианта“ съел его сам… Независимость — это про ДРУГОЙ способ счёта, а не про
другую строку кода с тем же допущением». Урок был записан текстом и провалился во второй раз в
новой форме — по норме `EXPERIENCE.md` такой урок обязан стать механизмом.

## Root cause

Три зеркала одного факта (парсер · независимая примета · эталон) выведены из ОДНОГО допущения о
форме строки. Согласие трёх читалось как доказательство, хотя доказывало лишь общее происхождение.
Ровно класс круга R1: **проверка мерит прокси, а не заявленное свойство.** Свойство здесь — «каждая
написанная буква доехала до радиокнопки»; прокси — «вариантов не ноль» и «два счётчика сошлись».

## Fix

- [x] **Парсер знает помеченную клетку:** `OPTION_ROW_RE` принимает пометку в скобках после буквы.
      Расширение узкое намеренно — `[^|]*` проглотил бы обычную строку данных, а развилка от
      таблицы данных только этим и отличается.
- [x] **Страж судит РАЗНИЦУ, а не ноль:** ось «вариант ПОТЕРЯН» сверяет буквенные строки автора с
      разобранными вариантами и печатает, скольких владелец не увидит. Скоуп — живые (неотвеченные)
      вопросы: у отвеченного потеря уже история, и краснеть на ней вечно значит шуметь (`bugs/70`).
- [x] **Примета G11 считает то, что видит ЧЕЛОВЕК:** клетка, ОТКРЫТАЯ намеренной меткой варианта
      (жирная буква либо буква с точкой/скобкой), чем бы она дальше ни продолжалась. Независимость
      восстановлена: теперь примета краснеет, если парсер откажется от формы, которую написал автор.
- [x] **Эталон переморожен с пересмотром чисел глазами** (норма G7): `interview_016` — 3 → **4**
      (A, B, C, D — сверено по документу; тройка была замороженным дефектом), `interview_017` —
      новый живой документ, 3 вопроса / 8 вариантов (2+3+3).
- [x] **Мутации в фикстуре, оба ответа** (EXP-0059): красный на форме, которой парсер не знает
      (автор написал 3, парсер видит 2), и МОЛЧАНИЕ на пометке в скобках. Прогон: «селфтест
      зелёный: все 15 мутаций сбылись по предсказанию».

## Decisions made without the owner

1. **Ось скоупится живыми вопросами, а не всеми.** Потеря в отвеченном вопросе — история, и
   вечный красный на ней превратил бы стража в шум (тот же довод, что в `bugs/70`).
2. **`interview_016` НЕ переспрашивается.** Ответ владельца совпал с содержанием потерянного
   варианта `A`, то есть решение №65 отражает его волю; переспрашивать значило бы просить его
   подтвердить то, что он уже сказал. Факт потери записан здесь и в шапке интервью — история
   append-only (решение №55).
3. **Расширение формы — только скобка.** Свободный хвост (`[^|]*`) в ПАРСЕРЕ сделал бы вариантом
   любую строку данных с заглавной буквы; в независимой примете он допустим и там применён, потому
   что примета обязана видеть глазами человека, а её ложное срабатывание ловится сверкой с
   парсером, а не наоборот.
