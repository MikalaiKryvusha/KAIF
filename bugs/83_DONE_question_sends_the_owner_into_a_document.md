# Bug 83 — вопрос отправляет владельца в документ вместо того, чтобы показать предмет решения

**Status:** ✅ DONE (2026-08-09 13:48 +03:00)
**Version/build:** build 270 · **When/context:** починки R1, `bugs/72` — живая страница контура
интервью №017, 2026-08-09 13:45 +03:00
**Fix accepted when (observable):** живой вопрос, называющий адрес документа вместо его
содержания, краснит `questions-guard`; вопрос с приведённым содержанием и ссылкой-провенансом
рядом — молчит; обе формы записаны фикстурами `--selftest`.

## Symptom

Владелец открыл страницу контура и вместо ответа написал (дословно, страница контура
2026-08-09 13:45 +03:00):

> «покажи мне этот порядок в контексте задаваемого вопроса! не отправляй меня капаться в MD
> документах! Тысячу раз об этом просил! Открытый вопрос должен быть достаточен для моего
> понимания решаемого вопроса!»

Вопрос Q2 интервью №017 звучал так: «В `researches/18` перечислены цели контура обратной связи, и
агент расставил их по важности сам…» — то есть предмет решения (девять целей и их порядок) лежал
за ссылкой. Владелец не может принять решение, не увидев того, о чём решает.

## Repro (deterministic)

```
node tools/questions-guard.mjs      # ДО фикса: зелено на вопросе, отправляющем в документ
```
Фикстура — дословная первая редакция Q2 (в `--selftest`, мутация «вопрос ОТПРАВЛЯЕТ в документ»).

## Root cause

Канон уже требовал ровно этого — но **для артефактов**: «Показ — это действие, а не ссылка… „см.
файл X“ в адрес человека запрещены как способ показа». Вопрос артефактом не является, и правило до
него не дотягивалось. Агент, соблюдающий букву («я же не просил его открыть файл — я просто сослался
на него в тексте»), нарушал смысл.

Второй слой — то, что делает дефект дорогим: **владелец говорил это много раз до того, как оно
было записано** («тысячу раз об этом просил»). Правило, живущее только как вежливость и здравый
смысл, не держится: держится только то, что проверяет машина (EXP-0079).

## Fix

- [x] **Канон обоих слоёв:** новая норма «ВОПРОС САМОДОСТАТОЧЕН — предмет решения лежит ВНУТРИ
      него» рядом с правилом показа, со словами владельца дословно и с границей: ссылка РЯДОМ с
      приведённым содержанием законна (подтверждает), ссылка ВМЕСТО содержания — дефект.
- [x] **Механизация:** ось `questions-guard` «вопрос ОТПРАВЛЯЕТ в документ». Стережётся ФОРМА
      отправки (EXP-0074): глагол-указатель (`см.`, `перечислены`, `описан`, `живёт в`, `лежит в`,
      `находится в`…) РЯДОМ с адресом документа в одной строке. Клетки таблицы вариантов из оси
      исключены — там уже содержание. Скоуп — живые вопросы: прошлые интервью задним числом не
      переписываются (append-only, решение №55).
- [x] **Обе формы в фикстуре** (EXP-0059): красный на дословной первой редакции Q2 и МОЛЧАНИЕ на
      вопросе, где порядок приведён списком, а ссылка стоит провенансом. Прогон: «селфтест
      зелёный: все 18 мутаций сбылись по предсказанию».
- [x] **Сам вопрос переписан и переподнят:** девять целей и их порядок стоят таблицей внутри Q2,
      добавлено объяснение, где порядок вообще работает (когда две цели сталкиваются).

## Decisions made without the owner

1. **Q2 переписан, а не снят.** Замечание владельца было о ФОРМЕ вопроса, не о его надобности:
   порядок целей по-прежнему требует его слова. Снять вопрос значило бы принять решение за него.
2. **Ось не требует «цитаты» формально** (нельзя машинно отличить достаточную цитату от
   недостаточной) — она ловит ровно форму ОТПРАВКИ. Цена названа: вопрос, отправляющий владельца
   без глагола-указателя, ось пропустит; лечится расширением форм-листа по мере встреч.
