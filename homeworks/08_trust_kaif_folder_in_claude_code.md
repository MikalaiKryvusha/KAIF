## Что нужно от вас

С сегодняшнего утра Claude Code в VS Code считает папку KAIF недоверенной. Поэтому в каждом новом чате агент работает без правил проекта:
не видит навыков, не получает напоминаний и не останавливается перед ранним закрытием чата. Последний раз всё это работало 7 ноября, на
прежней версии расширения. Исправить может только вы — это вопрос прав, и агент его себе не выдаёт.

1. В VS Code с открытой папкой KAIF нажмите `Ctrl+Shift+P` и выберите **Developer: Reload Window**.
2. Откройте новый чат Claude Code. Если появится окно **«Trust this folder in Claude Code?»** — нажмите **«Trust folder»**.
3. Напишите в новом чате `resume`.

Что вы увидите: агент начнёт с ритуала входа сам, без подсказок. Если окно доверия не появилось — напишите в чат «окна не было»: тогда агент
даст другой способ.

Ту же галочку, скорее всего, ждут ndim, KPOT и KAGO — у них такая же запись «не доверять». Это не проверено: они откроются тем же окном,
если оно им нужно.

## Как агент проверит

В новом чате: в журнале расширения нет строки «setting sources stay unused» для папки KAIF, в состоянии хука окна появилась запись новой
сессии, навык `dayloop` вызывается.
