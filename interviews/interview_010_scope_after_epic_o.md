### Q1. Идея 22 (hook-конфиги под остальные агентские системы) — в 2.2 или в 2.3?

**Адресат ответа:** `ideas/22_hook_configs_for_other_agent_systems.md` (шапка «Вовне» + статус) и
`plans/26_kaif_2.2.md` §1 (состав 2.2)

**Происхождение:** ваше поручение дословно на развилке подключения хуков (2026-08-07, ~20:50
+03:00): «это механизм проекта! Поэтому он подключается в settings.json для Claude, и в
аналогичные хуки для другиех вгентских систем». Первая половина исполнена в фазе O4 (Claude
Code подключён), вторая осталась без скоупа — эпик O закрыт БЕЗ неё.

**Цена, чтобы решение было информированным.** Скрипты модуля переписывать не нужно: они читают
JSON на stdin и печатают JSON на stdout, системо-зависима только проводка (имя файла конфига,
имена событий, форма выходного поля). Цена системы = один живой fetch её доки + образец конфига
+ строка свода полигона. Правило реализации, уже записанное в идее: **система без живого fetch
контракта в день письма образца в модуль не едет** — иначе образец выглядит поставкой, а
работает гипотезой (класс EXP-0036). Из шести систем `researches/19` §1.2 первичным источником
подтверждены две (Cursor, Codex), у Copilot нет аналога `sessionStart`, Windsurf и Cline сняты со
вторичных источников, у Zoo Code (приоритет №1 по адаптерам) хуков нет вообще — там честный
markdown-фолбэк, и он уже работает.

- **A) (Рекомендовано) В 2.3.** 2.2 закрывается Фазой R как есть. Причина: это ровно тот класс
  работы, который решение №47 выносило из 2.2, а цена в живых fetch'ах ложится на релиз, который
  уже готов к суду. Модуль без чужих конфигов не сломан — `framework/hooks/README.md` честно
  называет проблему и отправляет авторить конфиг от образца.
- **B) В 2.2 фазой O5 — целиком:** все системы с хук-контрактом, каждая со своим живым fetch.
  Самый полный контур, самая длинная задержка релиза; часть систем придётся пометить
  «не верифицирована» всё равно (Copilot/Windsurf/Cline).
- **C) В 2.2 фазой O5, но узко:** только Cursor и Codex (единственные с первичным источником и
  полным набором событий), остальные — строкой «не верифицирована» в README и переезд в 2.3.
  Компромисс: поручение исполнено на проверяемой части, релиз не ждёт неверифицируемого.
