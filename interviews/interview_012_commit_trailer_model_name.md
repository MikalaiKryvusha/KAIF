# Interview #012 — имя модели в каноническом Co-Authored-By

> Topic: канонический со-авторский трейлер коммитов зашит именем `Claude Fable 5` в двух местах, а над проектом работает другая модель. Строка идентифицирует со-автора работы — это конвенция владельца, и агент не вправе менять её молча.
> Source of the idea: `bugs/50_DONE_commit_trailer_duplicated_when_name_differs.md` (найдено при закрытии T1, `plans/62`, 2026-08-08 00:45 +03:00).
> Status: **✅ ОТВЕЧЕНО 2026-08-08 06:48 +03:00** — Q1 = B (фактическое имя работающей модели), Q2 = A (историю не трогаем). Разнесено 2026-08-08 07:20 +03:00: решения №54/№55 в `MASTER_PLAN.md` §7, `tools/commit.mjs` берёт имя из `--as`/`KAIF_AGENT_MODEL` вместо зашитой константы, канон-строка в `AGENT_GUIDE.md` → «Коммиты».

## Context / что уже известно

При закрытии задачи T1 коммит `89a9058` ушёл в опубликованную историю с ДВУМЯ со-авторами:

```
Co-Authored-By: Claude Opus 5 (1M context) <noreply@anthropic.com>
Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>
```

Механическая часть закрыта (`bugs/50`): проверка идемпотентности переведена с одного литерала на
класс `^Co-Authored-By:`, дубля больше не будет, доказано контрастной парой. Осталась
**содержательная часть**: какое имя должен нести канонический трейлер, который инструмент
дописывает, когда своего трейлера в сообщении нет.

Сейчас имя `Claude Fable 5` зашито в **двух** местах:

- `tools/commit.mjs:51` — константа `trailer`, которой дописывается сообщение;
- `AGENT_GUIDE.md` → «Коммиты» — канон-строка, которую читает каждая сессия.

Это пара «истина ↔ зеркало»: расходиться им нельзя, а меняться — только вместе.

**Почему это не решение агента.** Трейлер — заявление об АВТОРСТВЕ работы. Проставить туда имя
по своему усмотрению значит либо приписать работу тому, кто её не делал, либо самому назвать себя
в каноне проекта. И то и другое — решение владельца, а не агента (`AGENT_GUIDE.md` →
«Разрешение на действие ≠ авторство идентичности»).

## Q1. Какое имя несёт канонический трейлер?

| Вариант | Что означает | Цена |
|---|---|---|
| **A** | Оставить `Claude Fable 5` как конвенцию проекта — трейлер обозначает «ИИ-со-автор KAIF» родовым именем, а не конкретную модель прогона | Ноль работы. Но строка неверна буквально: над проектом сейчас работают и другие модели, и история это уже показывает |
| **B** | Писать ФАКТИЧЕСКОЕ имя работающей модели (сессия подставляет своё) | Историческая точность: по `git log` видно, кто что делал. Цена — константа перестаёт быть константой, нужен способ узнать имя модели в момент коммита |
| **C** | Нейтральное родовое имя (например, `Claude <noreply@anthropic.com>` без версии) | Не устаревает никогда, не врёт ни про одну модель. Теряется различение моделей в истории |

**Рекомендация агента: C.** Она честна при любой модели и снимает класс целиком, а не его текущий
экземпляр: имя с версией протухает по построению — ровно тот же механизм, что вскрыла T1 на
счётчиках (`EXPERIENCE.md` → EXP-0044). Если различение моделей в истории ценно — **B**, но тогда
нужна ещё и договорённость, откуда сессия берёт своё имя.
