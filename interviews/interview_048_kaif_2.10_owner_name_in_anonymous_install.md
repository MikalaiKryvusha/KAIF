## Context / what I already found

- Обезличенный режим с версии 1.2 вычищает из развёртывания всё об авторе KAIF: имя, прозвища, ссылки на его GitHub. Ваше имя как ВЛАДЕЛЬЦА
  проекта справочник KAIF утечкой не считает («the owner's name is not a leak»), а критерий 16 версии 2.10 требует «ни git-имени» в дереве.
  В ваших проектах владелец проекта и автор KAIF — один человек, поэтому одно правило противоречит другому.
- Имя попадает в два места: символ веры в начале руководства и строку «Автор / владелец» в таблице проекта. Берётся из `git config user.name`.
- По-русски подстановка ломает падеж: «в замысел Mikalai Kryvusha» вместо «в замысел Николая».
