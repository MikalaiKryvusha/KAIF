## Context / what I already found

- Сейчас KAIF во всех проектах: на 80 % окна — одно предупреждение (вам голосом), с 85 % — агент доводит работу до среза и мягко закрывает
  чат. Пороги проект может поменять у себя (ваш ответ 06.11, №155). KUMM у себя поставил: мягкое закрытие с 80 %, срочное с 92 %.
- Сегодня агент закрыл чат на 53 %, «по ощущению». Теперь раннее закрытие отклоняется само, а агент меряет окно командой (`bugs/137`).
- Автоматическая смена чатов: ваш документ проверен на Mac, на Windows не запускался. На этой машине уже проверено: id чата агенту виден,
  команда `code` есть, ссылка открытия чата в расширении на месте. Само открытие окна и нажатие Enter — только при вас.
- Без доверия Claude Code к папке проекта (сегодня у KAIF его нет — `homeworks/08`) смена чатов не заработает вовсе.

### Q1. С какого заполнения окна агент закрывает чат во всех проектах?

**Адресат ответа:** `plans/136` критерий 35.

- **A)** Как сейчас, 0 ч.
  - Ситуация. Долгая работа, окно заполняется.
  - Действие. Окно доходит до 80 %, потом до 85 %.
  - Результат. На 80 % вы слышите предупреждение; с 85 % агент доводит шаг и закрывает чат.
  - Проверка. Самопроверка хука окна — пороги 80 / 85.
- **B) (рекомендация `[ИИ]`)** Как в KUMM, ≈ 1–2 ч.
  - Ситуация. Та же.
  - Действие. Окно доходит до 80 %, потом до 92 %.
  - Результат. С 80 % агент доводит шаг и закрывает чат; не успел — на 92 % закрывает сразу.
  - Проверка. Самопроверка хука окна — ступени 80 / 92.

### Q2. Автоматическая смена чатов — в эту версию или в следующую?

- **A) (рекомендация `[ИИ]`)** В эту, 2.10, ≈ 6–10 ч, из них ≈ 1 ч — проба при вас.

  - Ситуация. Та же.
  - Действие. Окно доходит до порога.
  - Результат. Чат закрывается, новый вы открываете сами и пишете `resume`, как сейчас.

### Q3. С чего новый чат продолжает работу?

**Адресат ответа:** `researches/45` §4.

- **A) (рекомендация `[ИИ]`)** Как при ручной смене сейчас.
  - Ситуация. Старый чат закрылся по окну.
  - Действие. Открывается новый чат.
  - Результат. В нём само появляется `resume`; агент берёт следующий шаг из эстафеты в STATUS.
  - Проверка. Один источник «с чего продолжить» — п. 0 `STATUS.md`.
- **B)** Как в документе.
  - Ситуация. Та же.
  - Действие. Открывается новый чат.
  - Результат. В нём появляется «auto-relay continue»; агент читает отдельный файл передачи.
  - Проверка. Рядом с эстафетой STATUS — второй файл передачи.
