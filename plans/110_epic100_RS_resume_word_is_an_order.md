## Вектор цели (Achieve)

**Боль.** Владелец открывает чат словом `resume` и ниже пишет задачу; агент читает слово как тему и берётся за задачу —
ритуал входа не исполнен, сессия работает без канона, очереди владельца и молитвы. Причина классом (`researches/30` §2з):
триггер навыка перечисляет слова, а не их положение; единственное правило канона о положении слова-команды — пинок —
говорит «только отдельностоящей командой»; автозагружаемый файл контекста проекта (`CLAUDE.md`/`AGENTS.md` из
`CONTEXT_POINTER`) о ритуале входа молчит; ничего механического текст промпта не читает; README:525 признаёт: «an agent
that skips `/resume` works without the canon».

**Где хотим оказаться.** Первое слово сообщения владельца, совпадающее с именем навыка или его алиасом, — команда исполнить
навык ДО остального текста: правило в каноне обоих слоёв рядом с «Формой обязательства», алиасы в описании навыка и
ru-пакете, строка в файле контекста каждого развёртывания — и хук, который читает первое слово промпта и впрыскивает
агенту приказ (код прежде когниции); судья охотится на проигнорированное слово.

**Метрика эпика:** критерий 23 `plans/100` закрыт **0 из 1**.

## Готово, когда (критерии приёмки — сценариями; якорь `plans/100` критерий 23)

1. **[RS — хук читает первое слово]**
   - Ситуация. Развёртывание с подключённым модулем refresh-hooks; владелец отправляет сообщение «resume\nделаем эпик LP».
   - Действие. Агентская система вызывает хук `node .kaif/hooks/prompt-resume-word.mjs` на событии отправки промпта и
     передаёт ему сообщение владельца на stdin.
   - Результат. На stdout — `{"hookSpecificOutput":{"hookEventName":"UserPromptSubmit","additionalContext":"KAIF: the
     owner's message OPENS with the word `resume` — an ORDER to run the /resume skill IN FULL … BEFORE any work on the
     rest of the message …"}}`; на «делаем эпик LP» — тишина; на «продолжай читать resume.log» — тишина (слово не
     первое); на событии без поля `prompt` — тишина.

## Риски (ярусы Мёрфи)

- **(а) Ложный приказ на слове «резюме» в начале сообщения по другой теме** («резюме кандидата: …») — предикат ловит только
  ПЕРВОЕ слово; цена — один лишний ритуал входа; цена ошибки в другую сторону (пропущенный ритуал) выше — граница названа в
  README и правиле.
- **(а) Другие агентские системы** — не обещать: только Claude Code; таблица README говорит «not verified» (EXP-0042).
- **(б) Хуки читаются при старте сессии** — EXP-0039: конфиг подхватывался без перезапуска; живое наблюдение всё равно в
  следующем чате.
- **(в) Замороженные пакеты** алиаса не получают — правило и хук работают на английском слове в любом языке; ru — живой.
