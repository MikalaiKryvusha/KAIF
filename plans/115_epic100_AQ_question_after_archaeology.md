## Риски (ярусы Мёрфи)

- **(а) Дверь краснеет на всех старых интервью поля после обновления** — порог по дате шапки (`ARCHAEOLOGY_SINCE`), как G5/G6;
  документ без даты в шапке — считается старым (молчит) и говорит это в `--check`.
- **(а) Грепом по существительным ничего не найти, хотя ответ есть** (синонимы, другой язык) — аттестация честно несёт
  `N = 0`; ось не обещает найти — она обещает, что агент ИСКАЛ и записал, чем; судья охотится на N > 0 без `prior:`, не на
  N = 0.
- **(б) Конфликт с LP в `core.mjs`/`review.mjs`** — AQ сливается после LP, конфликты глазами; ось — отдельная функция с одним
  вызовом из `preflight`.
- **(б) Комментарий не рендерится владельцу** — намеренно: аттестация — для агента и судьи; владелец видит только вопрос,
  которому она разрешила существовать (G8 — словарь агента не у владельца).
- **(в) Вопрос-имя (класс «вкус») без археологии** — законное исключение `n/a — <причина>`, с причиной.
