## Вектор цели (Achieve)

**Боль.** Шаблон руководства агента вырос с 356 строк (1.6) до 1200 (2.7) и стоит ровно на бюджете; шаблон канона
тестирования — 300 при 300. Каждое правило везёт «свидетельство о рождении» — цитату, номер тикета, эпик, версию, — и
каждая сессия каждого развёртывания перечитывает всё это на входе. Переведённые развёртывания не проходят закрытие, у
архива владельца и у убывающего долга нет законного выхода из ворот, постоянные правила владельца ложатся свалкой его
сообщений, а своих наработок агент перед задачей не ищет. Слова владельца: «AGENT_GUIDE — это должно быть руководство,
главное, важное, без воды, как для космонавта — там нет места воде и шуму, там максимум концентрированной пользы» (#93) ·
«он должен быть строгой инструкцией для ИИ агента, сводом правил, конституцией работ, а не свалкой сырых заний» (#89).

**Где хотим оказаться.** Критерии 1–4 `plans/117` закрыты: шаблоны короче и ниже бюджета на объявленный запас без единого
потерянного обязательства; постоянное правило владельца — правилом в файле домашних правил с адресом дословного текста;
наработки проекта ищутся перед задачей; у ворот бюджета есть законный выход для архива, убывающего долга, перевода целиком и
наследия журнала. Числовой цели длины НЕТ (слово владельца №75: «Я не вижу смысла стремиться к какому-то числу») — мера
качественная: вектор вниз, инвентарь до = после.

## Верификация наблюдением

Инвентарь обязательств ДО/ПОСЛЕ — скриптом, не глазом; сжатие руководства — функциональный прогон: свежий экземпляр
агента получает только новый шаблон и исполняет по нему три задачи-фикстуры (баг · вопрос владельцу · закрытие чата) —
судья сверяет, что обязательные шаги прошли, как по шаблону 2.7; ворота бюджета — по пяти случаям критерия 4 на дереве,
засеянном формой реальных развёртываний (KUMM STATUS 447/200 · KAGO архив GOAL · Unliminium перевод 1201/1200 · журнал 88
записей).

## Риски

- **(а) Потеря обязательства при сжатии** (у QA — 4 % при зелёном счёте) → CK2 до CK3, `lost 0` — условие выхода CK3.
- **(а) Переезд секций рвёт поле** (семья #72) → каждая переехавшая секция в карте переименований; свод «дерево 2.7 → 2.8»
  в UP; CK и UP едут одним релизом.
- **(б) Сжатие делает текст телеграфом** (урок QA R6) → метр голоса канона: правило читается полным предложением
  повелительного наклонения; судья чистым экземпляром читает три случайные секции вслух.
- **(б) Корневая русская копия расходится с шаблоном** → реестр пар `HOUSE_RULES.md` §2 — сверка на закрытии.
- **(в) Бюджет шаблона выбран без источника** → FORK (б) с авторитетом из CK1.
