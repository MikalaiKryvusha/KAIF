- **(в) Слепок хуже ядра для письма** (примеры «…») — класс «вкус»: судит владелец, при слове владельца «ядро как есть» — вариант A VO1.

## Решения, принятые агентом без владельца

1. `[ИИ]` VO1 — вариант B по решению владельца №60 (строка `FORK:` выше); ядро байт в байт в публичный KAIF — только словом владельца.
2. `[ИИ]` Имена жанров `--genre` — те же, что у инструмента хранилища ядра (`document · ticket · comment · message · reply · essay`): одна метка
   значит одно в обоих инструментах.
3. `[ИИ]` VO4, узнавание потребителя: `FORK: options <A — только публичные метки слепка | B — спросить владельца | C — оставить путь приватного
   хранилища и исключать по признаку файла> · price of error <C: развёртывание владельца стоит на отказе, пока его приватный портрет не
   заменят урезанным слепком (потеря доказательств); B: вопрос, на который владелец уже ответил данными ядра> · consulted <`version.json`
   приватного хранилища → `consumers` и `propagation` («Проекты KAIF (KAIF, ndim, unliminium) получают ядро только через версию KAIF»);
   решение №60; счёт меток в четырёх портретах>` → **A**. GAP: сырая копия приватного ядра под именем портрета узнаётся (метка ядра в нём
   есть) — такого потребителя в реестре ядра нет.
4. `[ИИ]` VO4, слияние: признак — первая строка публичного слепка любой раскладки в локальной части; GAP — слияние без первой строки
   прежнего слепка и оболочка жанра, оставленная как есть (её пере-вывод — работа `/owner-voice`). Строка «Результат» критерия 26 сужена
   до проверенного: строку отчёта обновления о версиях пишет агент по шагу 3 инструкции, машиной она не судится.
5. `[ИИ]` VO4, ось утечки: преполёт 1d судит ИНДЕКС и сообщение коммита, а не всё дерево (дерево судит `--check`); без приватного ядра
   на машине — SKIPPED вслух, коммит идёт; ось не исполнилась — стоп (приёмка личного падает закрыто).
