## Вектор цели (Avoid)

Линтер авторства (`kaif-attribution-lint`) не выносит личное владельца в коммит: скрытый от git файл не читается, базовая линия хранит
только отпечатки, а не текст строк; запись базовой линии по одному пути не стирает долг других файлов; новая копия уже учтённой строки —
находка, а не долг. Цитата-якорь мета-плана: «PV «Личное не уезжает в общий коммит» (дело 5; #111 · #112 · #121 R7 · `ideas/31` п. 22)» —
критерий 19.

## Риски

(а) База — коммитимый файл поля: смена формата обязана читать старую базу без потери долга (иначе первое закрытие после обновления
краснеет на всём учтённом долге). (б) Маршрут старого ядра к модулю не относится — модуль приезжает файлом поставки, но база поля
переписывается только следующей записью: проверка «без текста» на поле — после первой записи свежим модулем.
