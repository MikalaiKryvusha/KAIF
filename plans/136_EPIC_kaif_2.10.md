## Вектор цели (Achieve)

После 2.10 агент в любом проекте под KAIF: **(1)** не оставляет владельца ждать молча и говорит с ним просто — встал и ждёт, значит позвал
голосом; ход не кончается вопросом о собственном шаге; ответ без заготовленного начала; приказ ведущей сессии команды исполняется;
**(2)** помнит свой проект в документах — записывает новое и правит устаревшее в момент понимания, а не на коммите; **(3)** обновляется с 2.8
сразу до 2.10 без поломок; **(4)** не верит проверке на слово — ни зелёной, ни красной: проверка, которая ничего не проверила, не говорит «ок»,
а много красного после вчерашнего зелёного агент читает как одну системную причину в стенде или методе, а не как много поломок.

## Готово, когда (критерии приёмки)

Метрика версии: **закрыто N из 19**. Сценарии — по форме `REQUIREMENTS_FRAMEWORK.md` (Ситуация · Действие · Результат · Проверка); строка
«Проверка» дописывается операционным планом эпика до кода и меняется только с обоснованием в коммите.

### TK — «Разговор с владельцем» (`plans/137`)

1. **Встал и ждёт — позвал голосом** (#157).
   - Ситуация. Агент закончил шаг и не может продолжать без ответа или действия владельца.
   - Действие. Ход агента кончается.
   - Результат. До конца хода прозвучал зов с именем сессии; в чате — вопрос.
   - Проверка. Проба по транскрипту (по образцу `ow1-midturn-scan.mjs`): ходы, кончившиеся ожиданием владельца без `--call`, — 0 на прогоне эпика; у истока — `tools/sandbox/probes/tk1-wait-call-scan.mjs <транскрипт>` → `turns ending in a wait without a call: 0`.
2. **Ход не кончается вопросом о собственном шаге** (#140).
   - Ситуация. Агент закончил шаг, следующий шаг — его собственная работа по плану.
   - Действие. Ход кончается.
   - Результат. Последний текст хода не спрашивает владельца разрешения на этот шаг: шаг сделан или назван сделанным следом.
   - Проверка. Та же проба: `turns ending in a permission question for own work: 0`; строка канона обоих слоёв + охота судьи.
3. **Ответ без заготовленного начала** (#156).
   - Ситуация. Владелец пишет агенту посреди его работы.
   - Действие. Агент отвечает.
   - Результат. Ни одно правило поставки не предписывает, какими словами ответ открывается.
   - Проверка. `grep -rniE "first words|opening it with|открыв ответ" framework/ AGENT_GUIDE.md .claude/skills/` → только записи истории справочника §17 и журнала.
4. **Приказ ведущей сессии команды исполняется** (#137).
   - Ситуация. Развёрнута команда; ведущая сессия пишет сессии-работнику «закрывайся сейчас».
   - Действие. Работник получает сообщение посреди хода.
   - Результат. Работник останавливает работу и закрывается тем же ходом; приказ соседней сессии вне команды по-прежнему — сведения.
   - Проверка. Свод на шаблон конституции команды и правило «Слово владельца посреди хода» п. 1 обоих слоёв — строка о ведущей сессии стоит и стережётся; без останавливающего хука (№144).
5. **Дверь страницы не путает «выше» в значении «больше»** (#147).
   - Ситуация. Живой вопрос интервью содержит «Чем выше риск, тем…» и «у вора она выше.».
   - Действие. `review.mjs <док> --check`.
   - Результат. Код 0; настоящая отсылка «см. выше» по-прежнему даёт код 3.
   - Проверка. Случай селфтеста контура на обе формы + мутант на старую регулярку.
6. **Перед показом — предупреждение о длинном вопросе** (#142).
   - Ситуация. Вопрос интервью длиннее бюджета длины.
   - Действие. `review.mjs <док> --check`.
   - Результат. Строка-предупреждение с длиной и бюджетом; показ не запрещён.
   - Проверка. Случай селфтеста: длинная фикстура — предупреждение, короткая — тишина; бюджет — числом в одном месте (`texts`/константа).
7. **Открытый статус со словом «отвечено» читается открытым** (#109, обратный случай).
   - Ситуация. Строка статуса документа — 🟡 со словом «отвечено» в пояснении.
   - Действие. Очередь владельца (`--queue --list`).
   - Результат. Документ стоит в очереди как открытый; долг владельца не спрятан.
   - Проверка. Случай селфтеста `docStatus()` на обе формы (закрытая со «не отвечено» и открытая со «отвечено»).
8. **HTML-артефакт показан страницей** (#136).
   - Ситуация. Документ владельцу помечен `format: html`.
   - Действие. `review.mjs <док>`.
   - Результат. Страница показывает отрисованный HTML, а не экранированный исходник.
   - Проверка. Случай селфтеста контура (`--no-serve`): в сгенерированной странице нет `&lt;html` для такого артефакта.

### MM — «Агент помнит свой проект» (`plans/138`)

9. **Новое записано в момент понимания** (#160).
   - Ситуация. Сессия изучает подсистему, о которой документы проекта молчат.
   - Действие. Агент понял, как подсистема устроена (прочитал код, прогнал пробу).
   - Результат. Знание записано в документ проекта (карта · статус · опыт · домашние правила) до следующего шага работы и до любого вопроса владельцу; не на коммите, не на остановке хода, не только на правке кода.
   - Проверка. Определяется разведкой MM0 (форма механизма — после неё, строкой `FORK:`); у истока — живая проба сессией Claude Code по образцу `wh5-live-first-prompt.mjs`.
10. **Устаревшее исправлено в момент расхождения** (#159).
    - Ситуация. Документ проекта говорит X, а агент наблюдает Y.
    - Действие. Агент замечает расхождение.
    - Результат. Документ исправлен тем же движением: новое дописано, устаревшее исправлено или удалено.
    - Проверка. Та же живая проба, второй сценарий: фикстура с картой, противоречащей коду.

### UB — «Обновление ничего не ломает» (`plans/139`)

11. **Отказ харнесса не оставляет висячий хук** (#154).
    - Ситуация. Развёртывание 2.8 с проводкой снятого хука в `.claude/settings.json`; харнесс отказывает агенту в записи настроек.
    - Действие. Обновление до 2.10 и `wire-hooks`.
    - Результат. Ни одна запись настроек не указывает на отсутствующий файл.
    - Проверка. Свод полигона: отказ записи настроек → `check` без строки «hook command points to a missing file»; скрипт снятого хука жив до снятия проводки.
12. **Справочник не портится подстановкой** (#150).
    - Ситуация. Проект с заполненными слотами команд.
    - Действие. Обновление.
    - Результат. `.kaif/KAIF_REFERENCE.md` объясняет слоты их именами.
    - Проверка. Свод: строка справочника о слотах содержит `<BUILD_COMMAND>` после обновления.
13. **Проба хуков из README не даёт ложного «не работает»** (#151).
    - Проверка. Строка пробы README исполняется инструментом агента и печатает приказ `/resume` (функциональный прогон).
14. **Перенос фактов в домашние правила на переведённом развёртывании назван** (#152).
    - Проверка. Пункт задания обновления называет перевод перенесённых строк на рабочий язык; свод на ru-фикстуре.
15. **Закрытие чата не подметает коммит; грабли отчётов об обновлении до 2.9 закрыты** (`ideas/32` п. 5 · #148 · #149 · #153 · #155 · #158).
    - Проверка. `grep -rn "git add -A" framework/skills/` → 0; по строке на подтверждённую разведкой граблю — в операционном плане UB.
