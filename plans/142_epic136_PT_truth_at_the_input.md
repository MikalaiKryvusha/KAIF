## Вектор цели (Achieve)

хуки модуля refresh-hooks, подключаемые `wire-hooks` в каждом развёртывании; ни один ничего не останавливает (№144).

## Риски

- (а) `updatedInput` заменяет весь вход: потерянное поле записи — испорченный файл; селфтест сверяет вход до и после побайтно.
- (а) `permissionDecision: "allow"` обходит запрос разрешения — без авторежима хук молча одобрял бы запись и запуск субагента; форма — по PT0.
- (б) Цена контекста субагента: список `/resume` в поле ≈ 95–187 тыс. токенов на каждого; правило брифа называет «субагент — когда задача
  стоит своей цены»; у истока бюджет — не больше двух одновременно (§7).
- (б) Текст О заполнителях (шапка хука, строка канона, ноты) обязан их экранировать — в поле первая же шапка заполнилась временем.
- (в) Системы без `PreToolUse` — правило канона полно и без хука (пробой `date`; бриф пишется по шаблону).
