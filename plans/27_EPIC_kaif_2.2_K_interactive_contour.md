## Вектор цели

Один нормативный реестр инвариантов (без коллизий номеров) + один исполнимый контракт сборки +
стражи обоих плеч петли вопросов — так, чтобы в любом проекте любой агент собрал контур в том же
стиле, с тем же функционалом, и чтобы все три полевых инцидента 2026-08 стали НЕВОЗМОЖНЫМИ по
построению, а не поправимыми.

## Критерии приёмки эпика (наблюдаемые)

1. Единый реестр инвариантов: существующие I1–I7 + новые из И1–И15/I8/issue #2 в одном
   пространстве номеров; карта «номер источника → канонический номер» в реестре; греп находит
   каждый инвариант в payload.
2. Headless-проверка «убить сервер → вписать ответ → кликнуть → прочитать DOM» включена в
   чек-лист приёмки контура и даёт эталонные значения бага 54 «после починки» (спасательный
   блок=true · кнопка разблокирована=true · черновик=true · статус честный).
3. Страж обратного плеча (разнос ответов) с базовой линией долга и двуплечим итогом описан
   нормативом и доказан мутацией на референсе; «ждут владельца 0» как единственный итог больше
   невозможен по построению регламента.
4. Правило показа И6–И8 в каноне + механический греп собственного ответа на «двойным кликом /
   см. файл / лежит по пути» рядом с расширением артефакта.
5. Условия закрытия issue #2 (11 позиций из дайджеста) выполнены; сам тикет закрывается на
   Фазе R (когда исправления отгружены).
6. Dogfooding: минимальный контур построен в ЭТОМ репозитории (закрывает дефер D5 из 2.1);
   первое живое интервью после постройки отрендерено им; «полный цикл рутины без единого
   уточнения в чате» — критерий из 2.1 подтверждён у нас.
7. Развёртывание БЕЗ контура по-прежнему не краснеет (опциональный сахар — инвариант §9.10).
