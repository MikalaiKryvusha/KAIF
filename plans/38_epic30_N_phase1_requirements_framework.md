## Решения, принятые агентом без владельца

1. RU-часть словаря и RU-ключи EARS — в линтере и RU-копии, не в EN-теле шаблона (гард 5d;
   красный стража прочитан как канон — EXP-0022).
2. Форма стража — опциональный tool-модуль по прецеденту kaif-canon-lint (деплоится вместе с
   документом; selftest доказывает каждый класс на своих ❌/✅ примерах), не скрипт репо.
3. Скоуп линтера по умолчанию — только секции требований (точность > охват, EXP-0024); `--all`
   расширяет на весь файл.
4. Одна находка на класс на строку (строку переписывают один раз); ассерт s13 перестроен под
   это (два слова РАЗНЫХ классов), обоснование в комментарии свода.
5. Код-спаны и «…»/"…"-кавычки — цитаты по построению (легальны): снято 3 ложняка на живом
   репо в строке, цитирующей сам словарь.
6. Тройка канонов (REQUIREMENTS → TESTING → BUG_FIXING) вплетена в 12+ точек обоих слоёв по
   уточнению владельца; его же двумя замечаниями вычищены мета-этикетки («пару дополняет до
   тройки», «тройка:») и провенанс-пометки (чаты/идеи) из канон-текстов — канон не летопись.
7. README §5: счётчики обновлены цитатой сборки, «актуальны на v2.1» → «на линии разработки
   2.2» (M2-прецедент обновлял таблицы README, но не §5 — снято противоречие внутри документа);
