## Вектор цели

Обновление переведённого/локализованного развёртывания не пишет на диск ни одного английского
модуля и не предлагает ни одного пустого пункта слияния: всё, что машинерия не может заменить
механически, приходит в задание НАСТОЯЩИМ диффом «шаблон старой версии → шаблон новой»; файл,
чей шаблон не менялся, в задании не появляется вовсе.

## Риски

1. **Сломать сеть `translatedWholesale`** (лучшее в 2.1 для i18n-класса — Unliminium) →
   чек-лист регрессии гоняется на каждом шаге; сеть только перенастраивается порогом-долей.
2. **Пороги-доли вырождаются на малых N** (EXP-0019) → тесты N=1/N=2 в обе стороны — шаг 3.
3. **Дифф от предыдущего релиза требует старого бандла** — для легаси-пути он синтетический
   (уже скачивается); для до-1.6 проектов может отсутствовать → честная деградация: «дифф
   недоступен, шаблон изменился — перенеси вручную», НЕ пустой пункт (зелёное без содержания
   хуже красного, §9.5).
4. **Frontmatter-мерж против локализации** — обновление description не должно затирать
   переведённые описания (класс bugs/31) → фикс 5 идёт ПОСЛЕ фикса 3 и его тестов.

## Решения, принятые агентом без владельца

1. **Доля порога сети = 0.15** (`WHOLESALE_SURVIVOR_SHARE`): зажата между полевым лицом KLAS
   (2/21 = 9,5 % — обязано ловиться) и кейсом T6/EXP-0019 (целая база + владельческая добавка —
   обязана НЕ ловиться); порог механики, не продуктовая константа владельца.
2. **Конфликтные диффы остались «твоя версия → новый шаблон»** (канон 2.0, живой страж
   s02/S6); «шаблон → шаблон» — только там, где дисковый текст ничего не показывает
   (wholesale/translated/отсутствующие модули). Буква шага 4 про «сравнивает текст модуля
   между версиями шаблонов» исполнена для УСЛОВИЯ (оно и раньше шло по sha шаблонов).
3. **Baseline на core-update пути скачивается всегда** (не только по `--baseline`) — полевые
   отчёты просили настоящие диффы из коробки; офлайн деградирует честно (sha-детекция + пункт
   «diff unavailable») и не блокирует обновление.
4. **Отказ от гарда латиницы** (KCam Г2) — причина в шаге 6.
5. **RU-триггеры во frontmatter 26 навыков сохранены** — триггер-контракт; инвариант §9.11
   говорит о ТЕЛАХ, и телесные проверки преамбулу не судят.
6. **Первопричина bugs/43 переквалифицирована** по чтению кода (frontmatter БЫЛ модулем; дыра —
   вечное расхождение из-за алиас-хвоста); симптом и объём фикса не изменились.
7. **Свод s08 вписан в полигон вместе с фиксами** (конвенция s07: свод в SUITES — когда
   зеленеет); сценарий B полигона держит `--baseline` намеренно недостижимым — офлайн-
   детерминизм полигона против сетевой недетерминированности.
