## Вектор цели

Ни одно безобидное намерение у CLI ядра не исполняет деструктивной операции, ни один страж
поставки не зелен без конфигурации или без прогона, и ни один текст не обязан ехать через
аргумент командной строки: голый запуск и `help` — справка; мутирующая команда отказывает на
незнакомом аргументе/флаге; ненастроенный страж говорит `SKIPPED` отдельным кодом; счётчики
считают ЗАПИСЬ, не намерение; вердикт судьи принимается файлом.

## Готово, когда (критерии приёмки — родительские №4 и №5 дословно)

1. CLI-безопасность: голый запуск ядра НЕ деструктивен; `help` — команда; неизвестный
   флаг/аргумент мутирующей команды — отказ, не молчаливое исполнение — критерий эпика №4.
2. Ни один страж поставки не зелёный без конфигурации: отдельный код/`SKIPPED`; счётчики
   сводок считают запись, не намерение; чекпоинты с существующим сканером ИСПОЛНЯЮТ его —
   критерий эпика №5.
3. KCam-инцидент Г1 (безаргументный запуск ПЕРЕЗАПИСАЛ `KAIF_UPDATE_TASK.md` до первого
   чекпоинта — единственная потеря работы в поле за 4 отчёта) воспроизведён красным стражем
   ДО фикса и закрыт.
4. `checkpoint judge --verdict-file <путь>` существует и работает с кириллицей/ёлочками/
   многострочником на PowerShell 5.1 (лицо 1 класса «текст-через-CLI»); `--verdict` остаётся
   для коротких ASCII-вердиктов (совместимость заданий, уже напечатанных в поле).
5. Полигон: новый свод фазы (или расширение s01/s03) зелёный; каждый новый страж доказан
   красным на сломанной версии ДО фикса, с предсказанием (EXP-0016/0017); s01–s08 без
   регрессий; `node tools/build-framework.mjs` чистый.

## Верификация

Критерии 1–4 — стражи нового свода красные-до/зелёные-после с предсказаниями; критерий 5 —
`npm run test:core` целиком. Урок L2 в работе: чужие своды могут стеречь СЕМАНТИКУ, которую
меняешь, — перед правкой формата вывода/дефолтов прогони весь полигон и читай упавший страж
как канон, а не как помеху.

## Риски

1. **Сломать скрипты поля, зовущие ядро по-старому** (безаргументный запуск в чьих-то
   обвязках) → голый запуск меняет поведение с ДЕСТРУКТИВНОГО на справку — это безопасное
   направление отказа; мутирующие команды по имени работают как раньше.
2. **Вайтлист флагов отстанет от новых флагов** → вайтлист собирается у команды, добавление
   флага без вайтлиста валит собственный свод (страж на страже).
3. **`SKIPPED`-код 3 сломает чей-то `&&`-конвейер** → код 3 только у ЯВНО ненастроенных
   стражей; настроенные ведут себя как прежде; README tool-модулей дополняется таблицей кодов.
4. **PS5.1-профиль вердикта не воспроизвести в песочнице на не-Windows** → свод гоняет
   файловый путь всегда, а PS-специфику стережёт как минимум BOM/CRLF-фикстура (EXP-0013).

## Решения, принятые агентом без владельца

1. **Флаговый запуск без команды — exit 1** (не 0): скрипт, полагавшийся на старый
   install-дефолт, обязан заметить, что установки не было; чистый 0 — у голого запуска и
   `--help`/`-h`/`help`.
2. **Код SKIPPED = 3** (не 2: у многих CLI занят под misuse); зафиксирован в шапках обоих
   tool-модулей и policy-записи 2.2.
3. **`stale-claims`-тик не отказывает** (контракт «state why» легален), **`placeholders`-тик
   отказывает** (литеральный слот объективен) — граница гейт/видимость по проверяемости.
4. **Дрейф зеркал в голом `check` остаётся warning'ом**; окно закрывает `recheck`→`sync`
   (решение фазы по триажу L1; альтернатива «check красный» ломала бы штатное окно
   update→verify — дизайн bug 30.5).
5. **`diff <файл>` — отказ с подсказкой**, а не реализация по-файлового диффа (просьба Unlim —
   фича вне скоупа фазы; кандидат в будущий беклог).
6. **Пересмотр двух законсервированных решений** (EXP-0022 — с документированием): exit-0
   ненастроенного canon-lint (bug 30.2) и «гигиена-при-отсутствии-ключа» провенанса — оба
   заменены SKIPPED/3 по полевой цене (три проекта с «вечнозелёным гейтом»); стражи s05/s06
   обновлены с обоснованием в комментариях.
7. **В чекпоинт-строку — первая строка вердикта**, полный текст — в квитанцию (однострочный
   формат гейтов вшит в полевые задания).
8. **Цитаты полевых проектов в ДЕПЛОЯЩИХСЯ файлах — без бренд-токенов владельца** («KCam»
   вместо имени проекта с токеном): anonLeakScan сканирует tool-модули сырыми — урок
   регрессии s04/S13.

Неразрешённых допущений (PENDING) нет; грань Q14 — явный дефер с TODO в `bugs/34_DONE`.
