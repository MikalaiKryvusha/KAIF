молчать о немашинной работе (bugs/40), идентичность проекта берётся из канона, а не из

## Готово, когда (критерии приёмки)

1. Пункт `placeholders` задания строится СКАНОМ дерева на момент генерации: реальные пути
   (включая файл сферы и «слот только в бандле») или честное «слотов нет»; задание несёт
   пункты про немашинную работу — секции шаблона сферы → локальная сфера, локальный валидатор
   каркаса (bugs/40).
2. `<PROJECT_NAME>` заполняется из канона (маркер/`AGENT_GUIDE`-идентичность); каталог и
   `package.json` — только фолбэк с честной пометкой в задании; карта плейсхолдеров манифеста
   чинится при обновлении (bugs/41: «klas» в заголовках невозможен при канонном «KLAS»).
3. `route` квитанции: `bootstrap` при классификации свежим ядром по живому манифесту;
   `legacy-bootstrap` — только при синтетическом baseline (bugs/42).
4. Языковые пакеты: развёртывание/обновление печатает список «эти файлы приедут по-английски
   и требуют ручного переноса»; в сборке — страж протухания пакетов (изменился локализуемый
   EN-шаблон → пакет обязан измениться или файл помечен протухшим), доказан красным (bugs/44,
   решение №44; объём пакетов НЕ растёт).
5. `kaif-provenance` понимает заголовочную форму марки: `[AI]` в заголовке помечает секцию до
   следующего заголовка того же уровня, без парного закрытия (решение №45); свод s05
   дострожен, красный-до/зелёный-после.
6. Хвосты скелета L5 закрыты или честно деферированы с причиной: SEMANTIC REPLACE как класс
   задания (смена смысла навыка — ожог `/pause`; питает эпик P) · backup
   `.kaif/backup-<from>-<to>/` перед правками (KLAS D13) · `.gitattributes` для md (Unlim
   Г13) · машиночитаемый инвентарь скиллов (NDim N6) · команда «покажи неотвеченные вопросы»
   в поставку (сшивка с эпиком K) · полумеханическая помощь миграции летописи (KCam §5.8) ·
   `.gitignore`-гигиена по решению №42 · предупреждение «чек-листы могут содержать строки
   владельца» в задании слияния.
7. Свод фазы (s11) — каждый страж красный до фикса с предсказанием (EXP-0016/0017); полигон
   11/11; чек-лист регрессии родителя (`plans/28`, «не сломать») зелёный; **финальный судья
   ЭПИКА L** — адверсарная панель по всем фазам L1–L5, находки закрыты до коммита.

## Риски (с уроками L4)

1. **Тексты, попадающие в деплой, цитируют полевые проекты обезличенно** («KCam», «field
   report») — anonLeakScan сканирует tool-модули и шаблоны сырыми (EXP-0023; регрессия
   s04/S13 в L3).
2. **Правка не-ASCII файлов — ТОЛЬКО файловыми инструментами** (Write/Edit): PS5.1-конвейер
   перекодирует UTF-8-без-BOM в моджибейк (инцидент L3; AGENT_GUIDE «Гигиена», симптом 1).
3. **Чужие своды стерегут семантику** (EXP-0022): смена формата задания/квитанции заденет
   s02/s03/s07/s08/s10 — полный полигон после каждого шага, падение читать как решение.
4. **Пороговые эвристики — прогонять на вырожденных N** (EXP-0019): страж протухания пакетов
   на пакете из 1 файла.
5. **Сканер-фикстуры включают САМУ ПОСТАВКУ** (EXP-0017): страж протухания пакетов тестируй
   на фикстуре с реальными файлами пакетов, не на стерильной.
6. **Дата-эвристика stale-claims** (L4): строка с датой = журнал — задокументированный трейд;
   если L5 меняет формат квитанции/задания, не порождать датированных строк-клеймов.

   STATUS (кандидат первой автономной сессии).
