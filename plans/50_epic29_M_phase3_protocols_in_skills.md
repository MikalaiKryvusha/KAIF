## Вектор цели

Протоколы петли стоят В ТОЧКАХ РЕШЕНИЯ полевого агента: `/report-bug` ветвится на «дефект САМОГО
KAIF» с шаблонами A/B и дедупом; контур «дефект в САМОМ KAIF» (5 шагов) — в payload AGENT_GUIDE;
обновление и установка НЕ зелёные без полевого отчёта (шаблоны C/D в заданиях машинерии,
чекпоинт исполняет проверку файла); `/kaif-version` знает канал сигналов.

## Готово, когда (критерии приёмки)

1. `/report-bug` (payload EN + обвязка RU): ветка-детектор «это дефект фреймворка, не проекта» →
   `bugs/KAIF/` по шаблонам A/B (вендорены с якорей `researches/18` §8), режимы 8.1/8.2 по
   `tracking` маркера, дедуп-аттестация обязательна (греп `bugs/KAIF/` + `gh issue list` в 8.1),
   гейт качества отправителя (в апстрим — только с репро ИЛИ дословной цитатой), отправка от
   имени владельца — через гейт отправки (стоячая авторизация).
2. Контур «дефект в САМОМ KAIF» (5 шагов, п. 1.11 NDim — вендорить с адаптацией) — в payload
   `AGENT_GUIDE.md` (до фазы греп 0 совпадений) + сшивка с `/experience`; RU-зеркало обвязки
   (с оговоркой истока: здесь дефекты KAIF — прямо в `bugs/`).
3. `/kaif-update` + машинерия: задание обновления несёт пункт «полевой отчёт ОБЯЗАТЕЛЕН» (между
   verify и commit) со скелетом шаблона C; чекпоинт отчёта ИСПОЛНЯЕТ проверку существования
   файла в `reports/KAIF_UPDATES/`; `update-verify` не зелёный без вердикта судьи (№46) — сшить
   с существующим judge-чекпоинтом, не дублировать.
4. Финиш установки: задание адаптации ставит отчёт об установке (скелет шаблона D) той же
   механикой чекпоинта; анонимный профиль — отчёт локальный, БЕЗ попыток тянуться к origin.
5. `/kaif-version`: строка-подсказка о канале (дефекты/улучшения → `bugs/KAIF/` + issue origin
   для привязанных).
6. Полигон: красным-вперёд ассерты «задание содержит пункт отчёта» и «чекпоинт отчёта не
   ставится без файла» (профили s02/s03) + «анонимный профиль не требует origin» (s04); сборка
   чистая; судья лёгкий (№48); закрытие в родителе (дата+время, №49); планы M4/M5 по канону N+1
   (на закрытии решить: M4 — лёгкая канон-фаза, возможно одним планом с M5).

## Верификация

Каждый критерий — наблюдением: греп протокольных строк в dist; полигонные ассерты красные ДО и
зелёные ПОСЛЕ; чекпоинт без файла отчёта — красный живым прогоном песочницы; счётчики — цитатой
вывода сборки.
