## Вектор цели

Критерии качества требований работают ИСПОЛНЯЕМЫМ линтером и рубрикой судьи по написанному — не
благими намерениями и не входным шлагбаумом (Achieve; критерий эпика 7 — антипаттерн DoR не
воспроизводится). Эпик N закрывается судьёй с уликами по всем семи критериям приёмки.

## Критерии приёмки (готово, когда)

1. Линтер целевых документов существует: проверяет НАЛИЧИЕ блока «Вектор цели» + «Критерии
   приёмки» в живых целевых документах обвязки (plans/ideas; диалекты bugs/interviews — свои
   поля из N2/N3) и гоняет стоп-словарь `kaif-requirements-lint` по их секциям требований.
   Носителя выбрать по месту (расширение `tools/doc-header-lint.mjs` / отдельный шаг — KISS,
   одна строка обоснования); красный доказан на сломанной фикстуре ДО применения.
2. Полигон-свод покрывает новое поведение (расширение s13 или новый свод — по месту); свод
   печатает свой счёт; `npm run test:core` зелёный целиком (число сводов цитатой).
3. Антипаттерн-проверка исполнена: линтер КОНСУЛЬТИРУЕТ (exit-код/режим не блокирует старт
   работы; формулировка «переформулируй или оправдай на месте» — в выводе), критерий эпика 7.
4. Судья эпика N (лёгкий, №48): таблица «критерий эпика 1–7 → улика» в закрытии `plans/30`;
   эпик N закрыт в родителе и зонтике `plans/26`; следующий шаг — эпик O (мета-план O пишется
   на старте O, не здесь — канон N+1).

## Верификация

Каждый счёт — цитата вывода инструмента (EXP-0025): селфтест линтера («красный: N предсказанных
находок»), полигон («all N suites green»), счёт целевых документов с блоком вектора
(инструментом, не руками). Кириллические проверки — node-скан свойствами Unicode (EXP-0032),
не git-bash `grep -i`.

## Риски (уроки N1–N4)

1. Страж, не красневший на сломанном, ничего не доказывает — селфтест ДО применения (канон
   Стражей; так делали doc-header-lint и requirements-lint).
2. Линтер-шлагбаум = антипаттерн DoR (критерий эпика 7): консультирует по написанному, никогда
   не запрещает начинать работу; стоп-слово в цитате/❌-примере/оправдании — легально.
3. Смешение скоупов инструментов — дефект (решение N3 №7): payload-модуль про требования ≠
   обвязочный линтер меты; расширяя, не сращивать ответственности.
4. Числа в коммит/закрытие — только цитатой вывода (EXP-0025); счёт документов с блоком —
   скриптом.
5. Канон N+1: мета-план эпика O в этой фазе НЕ пишется — только строка «где продолжить» на O.
