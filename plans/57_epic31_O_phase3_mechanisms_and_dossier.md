> **Родитель:** `plans/31_EPIC_kaif_2.2_O_context_environment.md` → фаза O3 (якорь: «### O3.
> Механизмы и досье»).

## Вектор цели

Опциональный hook-контур освежения и досье окружения переходят из проектов O1 в поставку и в
это репо: система с хуками получает механические впрыски-приказы по проекту `researches/19` §3,
любая система — процедуру и шаблон датированного досье окружения по §4; развёртывание без хуков
не краснеет нигде (инвариант родителя §9.10).

## Критерии приёмки (наблюдаемые)

1. Опциональный модуль хуков в поставке: три скрипта по `researches/19` §3 — канон-после-сжатия
   `SessionStart` (matcher `compact|clear`) · таймер `UserPromptSubmit` (предикат: возраст
   `.kaif/refresh-marker.json` > 60 мин) · Stop-страж STATUS (cooldown 1 раз/сессию,
   единственный блокирующий) — каждый с предикатом и cooldown; в комплекте фрагмент-образец
   конфига; машинерия чужие `settings.json` не редактирует — подключение хуков только явным
   шагом с согласием владельца проекта (норма §3).
2. Регистрация модуля по инварианту поставки (Reference §9.6) + свод полигона: деплой с
   модулем и деплой без него — оба зелёные (инвариант §9.10: отсутствие хуков не краснеет).
3. Досье окружения: процедура сбора по 6 осям §4 + формат секции AGENT_GUIDE (таблица
   «факт → значение → проба-команда», дата снятия, команда перегенерации, staleness-правило
   «факты старше 4 недель — гипотеза») — в payload-шаблоне; носитель процедуры решён по Оккаму
   в фазе (склонность §4 — расширение `/refresh-context`, не отдельный навык).
4. AGENTS.md-совместимость оценена: форма «ссылка на AGENT_GUIDE + досье» сделана, если её
   цена — один шаблонный файл и строка регистрации; иначе отклонена с обоснованием в закрытии.
5. Сборка + полигон + doc-header-lint зелёные (счётчики печатают инструменты); судья фазы
   (лёгкий, №48) — критерии переисполнены независимыми командами; закрытие O3 в родителе;
   операционный план O4 написан по канону N+1.

## Верификация

Наблюдением: полигон-свод деплоя с хуками и без — оба прогона зелёные (счёт печатает полигон);
живой смок хука `SessionStart` на машине истока (Claude Code — референс-контракт
`researches/19` §1.1: JSON на stdin → `additionalContext` на stdout, кап 10 000 символов);
формат досье — сверка секции грепом по полям «дата снятия / команда перегенерации / staleness».

## Риски

1. Кап 10 000 символов `additionalContext` — впрыск приказом перечитать, никогда телами
   документов (`researches/19` §3, анти-шум).
2. Мутация чужих `settings.json` — только явный опциональный шаг с согласием владельца
   (прецедент дефера `.gitattributes` из L5 — вход эпика O в `plans/31`).
3. Шум хуков — предикат срабатывания и cooldown обязательны у каждого; частота пульса
   ограничена канон-требованием §3 (плотность инструкций сама разрушает следование).
4. Смок хука на этой машине может упереться в версию/поведение живого Claude Code —
   расхождение с картой §1.1 фиксируется правкой `researches/19` (карта — живой справочник),
   не обходом.
