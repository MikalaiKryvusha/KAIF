## Вектор цели

**Achieve:** проект на любой агентской системе с ПОДТВЕРЖДЁННЫМ хук-контрактом получает
механический контур освежения из коробки — свой образец конфига в модуле, при одних и тех же
скриптах. Боль: модуль поставляет проводку ровно под Claude Code, хотя хуки за лето 2026 стали
индустриальным стандартом; на всех прочих системах агент довольствуется markdown-ритуалом, хотя
механика там технически доступна.

**Maintain:** честность двухконтурности не размывается — система без живого подтверждения
контракта НЕ получает образец, а получает строку «не верифицирована»; развёртывание без хуков
по-прежнему не краснеет (инвариант §9.10).

**Avoid:** образец-гипотеза в поставке. Конфиг, написанный по вторичному источнику, выглядит
проверенной поставкой и ведёт себя как догадка — класс EXP-0036 («карта старше дня — уже
гипотеза»).

## Верификация

Наблюдением, не выводом. Контракт системы считается подтверждённым, только если он **прочитан в
живом источнике в день письма образца** — цитата с датой в карте; «в адаптере написано» и «летом
были такие события» подтверждением не являются (ровно этот класс закрывает правило владельца
«Делаем, если поддерживают»). Свод s14 доказывается мутацией: сломанный образец обязан ронять
полигон — проверка, которая ни разу не краснела, ничего не стережёт
(`BUG_FIXING_FRAMEWORK.md` → Стражи). Отсутствие образца у неподтверждённой системы проверяется
так же явно, как наличие у подтверждённой.

## Риски (ранжированы)

1. **Живая дока разойдётся с картой** — уже случалось дважды в этом эпике (O3: `additionalContext`
   оказался вложен в `hookSpecificOutput`; O4: в карте не было формы `args`). Реакция: правим
   КАРТУ по живому источнику, а не рабочий фрагмент по карте.
2. **Grok Build не подтвердит паритет.** Реакция: честная строка «не верифицирована»; соблазн
   «оно же читает `.claude/` целиком, значит подойдёт» — это и есть образец-гипотеза.
3. **У Meta/Google не окажется агентской системы или хуков.** Это не провал шага: вердикт «нет»
   с датой — полноценный результат, экономящий следующей сессии тот же поиск.
4. **Беты меняются под ногами** (Cursor hooks — beta, Copilot — public preview). Реакция: дата
   снятия в шапке каждого образца + staleness-правило по образцу досье окружения; образец без
   даты не едет.
5. **Расширение поставки не зарегистрировано полным кругом** (EXP-0038: гард был слеп к новой
   payload-поверхности). Реакция: шаг 4 проходит круг регистрации целиком, а не «положил файл».
