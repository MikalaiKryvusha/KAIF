   восстановлено задачей T9 дословно из `git show 1dd1747:README.md` — это первоисточник владельца.
2. **README актуален текущему состоянию** — каждое числовое и фактическое утверждение перевыведено
   из репозитория, а не перенесено по памяти: счётчики цитатой `node tools/counters-guard.mjs`,

3. **Голос владельца.** README и релиз-ноты прогнаны по портрету (`/owner-voice`, режим rewrite) с

   анонимно, добавьте `--mode anonymous`». Не раздел верхнего уровня, не в оглавлении рядом с
