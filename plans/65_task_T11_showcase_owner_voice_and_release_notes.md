1. **Определение «KAIF — это…» не тронуто ни в одной половине.** Проверка механическая: диапазон
   строк определения побайтно совпадает с текущим (`git diff` по этим строкам пуст). Определение
   восстановлено задачей T9 дословно из `git show 1dd1747:README.md` — это первоисточник владельца.
2. **README актуален текущему состоянию** — каждое числовое и фактическое утверждение перевыведено
   из репозитория, а не перенесено по памяти: счётчики цитатой `node tools/counters-guard.mjs`,
   состав навыков — по `framework/skills/`, `counters-guard` зелёный после правки.

   анонимно, добавьте `--mode anonymous`». Не раздел верхнего уровня, не в оглавлении рядом с

## Что сделано сверх плана — и почему это попало в задачу витрины

1. **Страница релиза опубликована 2026-08-08 23:28 +03:00** — по слову владельца в этой сессии:
   «задеплоить README и релиз ноутсы, чтобы они успели попасть в GitHub в красивую дату 08.08.2026»,

   неспеша их переделывам КАК ПОЛОЖЕНО». Страница помечена **pre-release** осознанно: релиз без
   артефактов, объявленный «latest», сломал бы загрузчик полевым проектам — канал release тянет
   ассеты из последнего релиза. При pre-release «latest» остаётся у v2.1 с настоящими ассетами.
2. **`version.json` поднят до 2.2 «Yolden KAIF», released 2026-08-08** — тег v2.2 при version.json
   = 2.1 дал бы дрейф пары «истина↔зеркало» ровно того класса, который проект стережёт.

   разбор нашёл рядом настоящий механизм — машинерия обновления ищет baseline-артефакт по
   `releases/download/v2.2`, которого нет, и путь обновления деградирует в legacy у всего парка на
   2.2. Снимается доездом артефактов.
4. **Построен внешний сторож `tools/guarded-watchdog.mjs`** — владелец попросил защищённый
