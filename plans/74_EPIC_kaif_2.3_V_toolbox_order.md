## Вектор цели (Achieve + Maintain — из `plans/64`, уточнено триажом)

**Achieve:** KAIF из «ящика, где всё перемешано» — в строгий порядок: у каждого модуля названо
предназначение, один смысл живёт в одном месте, противоречий нет, формулировки проверяемы; ревизия
35 навыков «каждый ли зарабатывает своё место» и снятие удвоения payload/обвязка исполнены
(раскладка №72). **Maintain:** повтор смысла не может вернуться молча — страж порядка доказан
красным.

## Готово, когда (критерии приёмки — наследуют восьмёрку `plans/64`, с уточнениями)

1. **Инвентарь исчислим:** каждый модуль поставки (на 2026-08-14 — 691 по
   `dist/kaif-module-map.json`; живое число печатает сборка) несёт строку: адрес · предназначение
   одной фразой · адресат (агент/владелец/машинерия) · вердикт (оставить · слить с N ·
   упразднить). Строк без вердикта нет — счёт по таблице скриптом.
2. **Повторы поимённо:** пары «X и Y несут один посыл» — с дословными цитатами ОБЕИХ сторон;
   решение на пару: слить · разграничить · упразднить одну. Намеренное дублирование В ТОЧКЕ
   РЕШЕНИЯ фиксируется «осознанным» и НЕ режется (риск Топ-1 `plans/64`).
3. **Противоречия разрешены:** цитаты обеих сторон + какая победила и почему (порядок
   авторитетов: слово владельца > спека > тесты > код).
4. **Размытость измерена:** прогон движка правил T2 (стоп-словарь + классы размытости) по
   канону; каждое попадание переформулировано или оправдано на месте.
5. **Ревизия 35 навыков:** таблица «навык → зарабатывает ли место → вердикт»; вердикты
   «упразднить/слить» — только через интервью владельцу.
6. **Удвоение payload/обвязка снято по классам:** для каждого класса повторов между слоями —
   решение «шаблон один, обвязка ссылается» или «намеренное зеркало» с причиной.
7. **Сжатие подтверждено числом:** до/после — модулей · строк канона · встроенных файлов;
   числа печатают инструменты (EXP-0025).
8. **Ничего не потеряно молча:** упразднённый модуль — строка в летописи (что нёс · куда переехал
   смысл); греп упразднённых заголовков по `PROJECT_HISTORY.md`.
9. **Порядок стерегом:** страж против возврата повторов (форма — из V1; кандидат — детектор
   дублирующихся посылов на движке T2), доказан красным.
10. Дерево зелёное целиком (сборка · полигон · счётчики · реестр пар · 27 локализаций/бандл
    перепинены тем же коммитом) + лёгкий судья эпика.

## Риски (наследуют `plans/64`, дополнены)

- **Топ-1: «сжатие» съест смысл/намеренные повторы в точках решения** — критерий 2 требует цитат
  обеих сторон; намеренное фиксируется осознанным и не режется.
- **Топ-2: правка канона задевает локализации и бандл** — перепин тем же коммитом, страж
  протухания пакетов, реестр пар.
- **Топ-3: эпик растекается** — фазы с исчислимыми гейтами; V3 не начинается до полноты V2
  (счёт скриптом).
- **Топ-4: вердикты по 691 модулю без ultracode станут вечностью** — фолбэк назван (сессии по
  срезам), но просьба об ultracode ставится в V1 явно.
