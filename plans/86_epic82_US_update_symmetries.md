«11 modules merged in-place»), и живой прогон дописал 416 строк английского канона в конец

переведённых развёртываний диффы — вся доставка, но задание не даёт готовой команды диффа на
diverged-файл, молчит о новых английских навыках при `language: ru` и не сканирует скрипты
проекта на пин старой версии; генератор пункта `placeholders` называет цитаты летописи местами
заполнения, а гейт цитаты пропускает — асимметрия сменила сторону; deprecation не называет
преемника, сводка не считает неубранные; `project-name` предупреждает о non-ASCII argv после
принятия значения; `writeMatchingEol` судит по наличию CRLF, а не по доминированию; smoke-строка
README хуков виснет на stdin.

**Где хотим оказаться.** Вердикт по каждому файлу-кандидату i18n-развёртывания ПЕЧАТАЕТСЯ с
числами и одинаков на байт-идентичном дереве (при расхождении с репетицией файл замораживается и
уходит в задание); якорные блоки `KAIF:*:BEGIN/END` — неделимые единицы: приезжают целиком в
заявленной позиции или целиком уходят в задание; задание обновления — самодостаточный носитель
(безусловный `stale-claims`, команда диффа на diverged-файл с baseline по умолчанию, английские
новинки пунктом, скрипты в скане, преемник у deprecation, счёт неубранных); `check` считает
языковую смесь; `project-name` предупреждает ДО акта; EOL — по доминированию. Каждый фикс — со
сводом полигона, красным на до-фиксовом поведении.

## Готово, когда (критерии приёмки)

1. **[P1, #27/#32 R-B] Детерминизм wholesale-вердикта + печать решения.** Классификация update
   печатает по каждому файлу-кандидату на wholesale (baseN > 2) строку
   `⟳ <файл>: baseFound N of M, ceiling K → frozen | merged` (числа из `WHOLESALE_SURVIVOR_SHARE`);
   два прогона `update --dry-run` по байт-идентичной копии дают один вердикт по каждому файлу;
   расхождение вердикта с репетицией (вердикт из квитанции репетиции или `--rehearsal <dir>`)
   замораживает файл и выносит его пунктом задания, а не мержит. Причина односторонней потери
   (легаси-baseline 1.6 / переход anonymous→origin, #32 R-B) — найдена и закрыта либо названа в
   документе бага с вердиктом «не воспроизводится в полигоне» и адресом 2.6. *Meter:* свод
   полигона: два прогона на одной копии → диффы выводов пусты; фикстура с синтетическим baseline
   даёт печать чисел по каждому кандидату; мутант с отключённой заморозкой краснит ассерт.
2. **[P2, #27 + KAGO R2] Якорные блоки неделимы.** Сплиттер и мерж знают маркеры
   `<!-- KAIF:<NAME>:BEGIN -->`…`<!-- KAIF:<NAME>:END -->`: модуль, содержащий один маркер пары,
   расширяется до целой пары — либо пара целиком уходит в задание с диффом; в дерево никогда не
   пишется `END` без `BEGIN` и не вставляется текст ВНУТРЬ локализованной пары; `check` краснит
   документ с непарным маркером. *Meter:* свод: фикстура «переведённый гайд с локализованной парой
   молитвы» → после update пара парна и не удвоена; фикстура «END без BEGIN» → `check` красный;
   красный до фикса на HEAD-ядре.
3. **[#31] `stale-claims` безусловный.** Пункт задания эмитится на КАЖДОМ версионном обновлении;
   при пустом скане тело — `no lines found (scanned N files)`; чекпоинт `stale-claims`
   перепрогоняет скан, как сейчас. *Meter:* свод: обновление без клеймов → пункт есть с телом
   `no lines found`; красный на HEAD (пункт отсутствует).
4. **[срез U2 — `plans/73` U2 пп. 1, 2, 4] Задание — самодостаточный носитель.** (а) для
   diverged/translated-файла — строка с точным путём апстрима и ГОТОВОЙ командой диффа с baseline
   по умолчанию (без ручного поиска `--baseline`); (б) при `language ≠ en` — пункт «эти N файлов
   приехали английскими — переведи, если проект переводит wholesale» со списком; (в) `stale-claims`
   сканирует и скрипты проекта (`*.mjs` · `*.js` · `*.py` · `*.sh` · `scripts` в `package.json`)
   на пин старой версии. *Meter:* свод-греп по сгенерированному `KAIF_UPDATE_TASK.md`: три
   свойства; красный на HEAD.
5. **[точечные] U2 quote-skip · U4/U5 deprecation · P3 · P4 · P5 · P6 · H10.** (а) один общий
   предикат quote-skip у генератора пункта `placeholders` и у гейта placeholders (KAGO
   `bugs/KAIF/10`: цитата летописи не называется местом заполнения); (б) deprecation называет
   преемника (`{ path, reason, successor }`), сводка печатает счёт неубранных deprecation; (в)
   `check` печатает счёт языковой смеси при `language ≠ en` («N of M skills are English») —
   предупреждение, не отказ; (г) переход anonymous→origin выносит пунктом задания список файлов,
   чей текст кодирует старый режим (`kaif-version`, `kaif-remove`); (д) `project-name` предупреждает
   о non-ASCII argv ДО принятия значения, пункт задания называет `--name-file`; (е) `< /dev/null` в
   smoke-строке README модуля хуков; (ж) `writeMatchingEol` — по доминированию (CRLF ≥ LF → CRLF).
   *Meter:* свод или ассерт на каждый пункт, красный на HEAD там, где меняется поведение
   (а, б, в, г, д, ж); (е) — греп README.
6. **Поставка и дерево.** Ноты и policy 2.5 в сборщике (INERT): строка эпика US; `KAIF_REFERENCE`
   §10 обновлён (печать вердикта, неделимые блоки, безусловный `stale-claims`);
   `node tools/build-framework.mjs` EXIT 0 · `npm run test:core` зелёный с новым сводом s18 (плюс
   правки s07/s10 там, где класс уже крыт) · `counters-guard` (число сводов — из вывода) · реестр
   пар · `doc-header-lint`; лёгкий судья эпика (№48) — критерии 1–5 пробами.

## Риски (ярусы Мёрфи)

- **(а)** P1 не воспроизводится в полигоне (модульный маршрут детерминирован — #32 R-B) — принят
  фолбэк `plans/82`: печать решения по файлу с числами + заморозка при расхождении с репетицией;
  охота за причиной не блокирует релиз.
- **(а)** Marker-aware мерж меняет сплиттер, а сплиттер запинен «ядро == сборка»
  (`tools/module-map-lib.mjs` ↔ `KAIF-CORE.mjs`) — правка идёт в ОБА, карта модулей
  пересобирается, пин в `check-framework` краснит рассинхрон.
- **(б)** Безусловный `stale-claims` вернёт шум класса bugs/35 — тело `no lines found` пустого
  скана шума не несёт; точность скана не трогаем.
- **(б)** Печать вердикта по каждому файлу раздует вывод update на больших развёртываниях —
  печатать только для кандидатов на wholesale (baseN > 2), остальное — счётчиком.
- **(в)** EOL по доминированию при равном счёте — тай-брейк в пользу CRLF на дереве с
  `core.autocrlf=true`, иначе LF; назван в комментарии функции.
