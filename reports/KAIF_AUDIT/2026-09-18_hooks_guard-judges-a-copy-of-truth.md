## F2 — Ассерт формы вывода подстрочный: опечатка в `--emit` проходит зелёной, а хук молча печатает конверт чужой системы

**1. Цитата.**
`tools/sandbox/s14-refresh-hooks.mjs:218`
```
  if (emit) ok(txt.includes(emit), `s14/O5 ${sys}: образец называет форму вывода явно (${emit})`);
```
Носитель заявления, которое этим ассертом НЕ обеспечено — `framework/hooks/session-start-refresh.mjs:24-25`:
```
// stdin. A hook must exit silently on anything unclear, so a wrong guess would fail invisibly —
// an explicit flag fails loudly at review time instead. Shapes:
```

**2. Сценарий провала.** `txt.includes('--emit cursor')` истинно для `--emit cursorX`,
`--emit cursor-flat`, `--emit cursor2`. Скрипт на неизвестной форме отдаёт конверт референса
(объявленное решение: опечатка обязана быть видна, `s14:307-310`), exit 0, 0 байт на stderr — а Cursor
читает только плоский `additional_context`, поэтому приказ не доезжает до агента молча, неотличимо от
неподключённого модуля. Второй вход того же класса (СУЖЕН скептиком): образец может назвать форму,
которой у АДРЕСУЕМОГО скрипта нет, и остаться зелёным — но только если требуемая строка флага в
командной строке сохранена; `--emit cursor --emit antigravity` (лишний флаг ПЕРЕД требуемым) зелёный и
поведенчески вреден, потому что `argv.indexOf('--emit')` берёт ПЕРВОЕ вхождение и
`prompt-refresh-timer.mjs` формы `cursor` не имеет → уходит конверт референса, а Antigravity
`PreInvocation` читает только `injectSteps`.

**3. Тяжесть.** Влияние высокое (весь смысл `--emit` — не угадывать; ошибка здесь = модуль молчит) ×
вероятность средняя (`README.md:99-103` прямо приглашает владельца добавлять систему и форму руками) →
**Attend**, верхняя граница.

**4. Базовая линия.** `known: EXP-0042` («свод обязан падать, если образец ссылается на хук, которого
система не тянет» — здесь не тянет ФОРМУ) + `known: bugs/66`.
`Dedup attestation:` грепнуто `includes('--`/`includes(emit)` по `tools/` — ровно ДВА сайта, оба в
`s14` (`:218` судит форму, `:221` — обратный «у Codex флага нет»); прочие попадания —
разбор `process.argv`, не ассерты. `kaif-fp: hooks-samples :: flag-judged-by-substring :: v2.7`

**5. Эскиз починки.** Сделать список форм машинно-читаемым (каждый скрипт печатает ключи `ENVELOPES`
по `--emit-list` либо экспортирует таблицу) и требовать в `s14` РОВНОГО совпадения: для каждой
командной строки каждого образца — распарсить `--emit <shape>` и проверить, что `shape` ∈ формы
ИМЕННО того скрипта, который в этой строке запускается (и что скрипт без флага адресуется только
системам формы `claude`). Плюс: на неизвестной форме писать одну строку в stderr, stdout не менять.

**6. Починка принята, когда.** На КОПИИ бандла: (1) мутант «`--emit cursor` → `--emit cursorX`» и
(2) мутант «лишний `--emit cursor` ПЕРЕД `--emit antigravity`» дают
`KAIF_DIST=<копия> node tools/sandbox/s14-refresh-hooks.mjs` → EXIT ≠ 0 поимённо.
**Измерено 2026-09-18 09:06 +03:00 (исполнитель):** мутант «`--emit cursorX`» → **EXIT 0, 68 ✅ / 0 ❌**
(красного нет); контрольные мутанты, которые УЖЕ стережены и доказательства не несут: «замена скрипта в
строке» → EXIT 1, 65 ✅ / 3 ❌; «удаление `--emit copilot`» → EXIT 1, 66 ✅ / 2 ❌. Скептик независимо
получил то же (его b1 зелёный; b2c — лишний флаг перед требуемым — зелёный и поведенчески вредный).

**7. Не трогать.** Фолбэк «неизвестная форма → конверт референса, НИКОГДА не тишина» (`s14:307-310`) —
объявленное решение. Ассерт `s14:221` (у Codex флага быть НЕ должно). Отсутствие `--emit` у
`stop-status-guard.mjs`. Половину заявления «fails loudly at review time» НЕ трогать как дефект: она

см. SUMMARY, инвентарь опровергнутого).

**8. Мета.** 2026-09-18. Оплаченные классы `EXP-0042`, `bugs/66`. Поправка к первой редакции карточки
