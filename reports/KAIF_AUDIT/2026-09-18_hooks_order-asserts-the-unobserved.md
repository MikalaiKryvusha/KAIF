## F7 — `source`, не равный `clear`, объявляется СЖАТИЕМ: приказ утверждает ложь и велит проштамповать ложный `trigger` — на двух образцах, которые модуль везёт сам

**1. Цитата.**
`framework/hooks/session-start-refresh.mjs:59`
```
  const trigger = source === 'clear' ? 'ritual:/clear' : 'compaction';
```
Рядом — дефолт, дающий то же на событии без поля (`framework/hooks/session-start-refresh.mjs:51`):
```
  let source = 'compact';
```

**2. Сценарий провала.** `SessionStart` в Claude Code несёт `source` из четырёх значений — `startup`,
`resume`, `clear`, `compact`. Код перечисляет ОДНО и сваливает всё прочее в «сжатие»: при
`source=startup` и `source=resume` в контекст впрыскивается «The context was just compacted: what this
session now remembers of the canon is a retelling, not the canon» и приказ проштамповать
`trigger: "compaction"`. Маркер — улика для судьи и вход соседнего хука-таймера, поэтому ложный
`trigger` делает улику ложной. Референс-проводка защищена матчером (`settings-fragment.json` →
`"matcher": "compact|clear"`, ассерт `s14:75`), НО модуль везёт ещё два образца БЕЗ матчера —
`sample-cursor-hooks.json` и `sample-copilot-hooks.json`, — и README помечает их `✅` в колонке «Canon
after compaction» (`:62`, `:64`). На этих системах поле `source` с доки не снято, хук берёт дефолт
`'compact'` и лжёт на КАЖДОМ старте сессии. Copilot-образец сам пишет, что событие «fires for new AND
resumed sessions», — то есть автор знал, что ловятся новые сессии.

**3. Тяжесть.** Влияние среднее (ложь в приказе + ложный `trigger` в машинной улике; шум на каждом
старте сессии) × вероятность: на референс-системе низкая, **на двух везомых образцах — 100 %** →
**Attend**.

**4. Базовая линия.** `known: bugs/66` — тот же оплаченный класс «охват перечислен фикс-списком вместо
вычисления», но в домене ЗНАЧЕНИЙ: `bugs/66` №4 закрыл у `s14` слепую зону ИМЁН событий, а домен
значений `source` остался списком из одного элемента.
`Dedup attestation:` `source` больше нигде не валидируется (файл прочитан целиком); греп `s14` на
`source:` → только `'compact'` (`:83`) и `'clear'` (`:94-95`), в O5-ветке `clear`/`clear`/`compact`
(`:295`, `:299`, `:308`) — ассертов на `startup`/`resume`/событие без поля ноль; греп по `*.md` на
`SessionStart:startup|source=startup|startup.*compacted` → 0 (записанного решения нет); ближайшее к
объявлению — `plans/58_DONE:157`, но это допущение о проводке С МАТЧЕРОМ.
`kaif-fp: hooks-session-start :: source-domain-collapsed-to-compaction :: v2.7`

**5. Эскиз починки.** Домен `source` назвать таблицей и брать из неё ОБА слова (предложение приказа и
`trigger`): `compact → ('compacted','compaction')` · `clear → ('cleared','ritual:/clear')` ·
`startup|resume|прочее → ('(re)started','session-start')`. Тишину НЕ вводить — доктрина модуля
«печатать что-то лучше, чем ничего» (`session-start-refresh.mjs:68-69`). В `s14` — два ассерта
(`startup`, `resume`) плюс третий на событие без поля `source`.

**6. Починка принята, когда.** Проба на копии хука: `source=startup` и `source=resume` не содержат ни
`The context was just compacted`, ни `"trigger": "compaction"`, при неизменных выводах для `compact` и
`clear`. **Измерено 2026-09-18 09:02 +03:00 (исполнитель):** `compact` → «was just compacted» +
`"trigger": "compaction"`; `clear` → «was just cleared» + `"trigger": "ritual:/clear"`; **`startup` →
«was just compacted» + `"trigger": "compaction"`; `resume` → то же**. Скептик независимо: то же плюс
событие БЕЗ поля `source` → тот же ложный текст (дефолт `:51`).

**7. Не трогать.** Ветки `compact` и `clear` побайтно — их стерегут `s14:88` и `s14:96-97`. Фолбэк
неизвестной формы `--emit` на конверт референса. Правило «впрыскивается ПРИКАЗ, не тела документов» и
кап 10 000.

**8. Мета.** 2026-09-18. Сужение по скептику принято и внесено выше: дефект держится не на самодельной
проводке владельца, а на ДВУХ ОБРАЗЦАХ самого модуля, отмеченных в README `✅`. Прочитанные решения:
комментарий `session-start-refresh.mjs:57-58` (сам признаёт класс: «a marker stamped "compaction" after a
/clear would misreport why the refresh happened»), `plans/58_DONE:157`, `framework/KAIF_REFERENCE.md:519`,
`framework/skills/fable-judge/SKILL.md:61`. Связано с F8 (тот же класс на другом хуке) и с F6 (BOM даёт
ровно этот же ложный `trigger` третьим путём).

## F8 — Страж STATUS утверждает агенту «this session changed the tree», наблюдая только состояние дерева

**1. Цитата.**
`framework/hooks/stop-status-guard.mjs:66`
```
      reason: `KAIF STATUS guard (fires once per session): this session changed the tree, but ${STATUS_FILE} was last ` +
```
Наблюдение под этим утверждением — `framework/hooks/stop-status-guard.mjs:55`:
```
    if (git(['status', '--porcelain'])) workHappened = true;
```

**2. Сценарий провала.** `git status --porcelain` — СОСТОЯНИЕ дерева, а не активность сессии; времени
старта сессии в предикат не входит ничего (`session_id` используется только как ключ cooldown). На
дереве, где грязь и последний коммит старше сессии на три дня, а сессия не изменила ничего, первый же
`Stop` печатает «this session changed the tree, but STATUS.md was last touched ~72 h ago». Ущерб не в
блоке (он мягкий и сам предлагает сказать «ничего не менялось»), а в том, что механический контур канона
подаёт агенту ненаблюдённое как ФАКТ — поимённо оплаченный класс claim-wider-than-the-observation, где
законная форма звучит «я сделал X; проверь, видишь ли Y». Спецификация требует именно наблюдения:
`plans/57` критерий 1 — «работа В СЕССИИ И STATUS старше 3 ч», `researches/19:339` — то же.

**3. Тяжесть.** Влияние низкое (один мягкий блок, текст сам предлагает выход) × вероятность средняя
(возврат владельца после многодневного перерыва с оставленной грязью; и особенно долгоживущее рабочее
место команды в worktree, где mtime ставится чекаутом и естественно старится) → **Track**.

**4. Базовая линия.** `new`.
`Dedup attestation:` файл прочитан целиком — ни `session_id`, ни время старта сессии в предикат работы
не входят; фикстура `s14:138-157` создаёт грязь ВНУТРИ прогона с комментарием «работа сессии есть —
дерево грязное», обратной фикстуры (грязь старше сессии) нет; греп по `bugs/` на
`this session changed the tree` / `status --porcelain` → 0 содержательных совпадений; объявленного
исключения и датированного долга нет.
`kaif-fp: hooks-stop-guard :: session-activity-proxied-by-tree-state :: v2.7`

**5. Эскиз починки.** Дешёвый и достаточный вариант — говорить только наблюдённое: «the worktree has
uncommitted changes (and/or the last commit is ~N h old), while STATUS.md was last touched ~M h ago»,
без слов «this session». Полный вариант — метка старта сессии в OS-temp (тот же ключ, что у cooldown), и
тогда «эта сессия» станет наблюдением. В `s14` — ассерт на фикстуре «грязь старше сессии»: либо тишина,
либо причина БЕЗ подстроки `this session changed the tree`.

**6. Починка принята, когда.** Проба на копии: фикстура, где последний коммит и грязь старше сессии, а
сессия ничего не меняла, печатает либо тишину, либо причину без подстроки `this session changed the tree`.
**Измерено 2026-09-18 09:05 +03:00 (исполнитель):** коммит датирован 2026-09-15 09:00, mtime `STATUS.md`
и грязи — 72 ч назад, `session_id` новый → «KAIF STATUS guard (fires once per session): this session
changed the tree, but STATUS.md was last touched ~72 h ago.» Скептик независимо: то же, и второй НОВЫЙ
`session_id` получает тот же текст.

**7. Не трогать.** Мягкость блока: одна причина, `decision: "block"`, предложение «или скажи, почему
ничего не изменилось» — объявленный контракт; подстрока `STATUS.md` в причине обязана остаться (её читает
ассерт `s14:159-160`). Тишину на не-git проекте и любой сбой git → `exit 0`. Порог `STALE_HOURS = 3`.

**8. Мета.** 2026-09-18. Сужение по скептику: заявление «в истоке это состояние по умолчанию» НЕ
подтверждено (живой `STATUS.md` свеж, страж молчал бы) — достижимо при долгом перерыве и в долгоживущем
worktree команды. Обе половины стоят: (а) предикат шире своей спецификации (`plans/57` критерий 1,
`researches/19:339`), фикстура свода написана тем же приближением (`EXP-0133`); (б) текст утверждает
ненаблюдённое — прокси не назван вслух (`framework/skills/fable-judge/SKILL.md:61`). Оплаченный класс:
`EXP-0133`. Связано с F7.
