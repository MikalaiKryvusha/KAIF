## Правила суда (нарушение = твой результат не принимается)

- **Репозиторий не правишь и не коммитишь.** Мутации и развёртывания — только на КОПИЯХ во временном
  каталоге ОС (`node -e "console.log(require('os').tmpdir())"`; в git-bash `$TMPDIR` ПУСТ — не используй его).
- **Тишина у владельца.** Ни одного окна и ни одного звука на его машине: генератор контура — только
  `node tools/review.mjs --selftest` и `node tools/review.mjs <док> --check`; НИКОГДА `node tools/review.mjs <док>`
  без `--check`, НИКОГДА `--no-open` (он поднимает сервер и ЗОВЁТ голосом), НИКОГДА `--queue` без `--list`.
  Шов `KAIF_DIST=<старая сборка>` НЕ применяй к сводам контура (`s12`, `s22`) и к любому своду, который
  запускает генератор страницы: старое ядро под швом показывало владельцу тестовую страницу и звало голосом
  (`bugs/116`). Нужен красный против старой сборки для такого свода — не делай, запиши в «не переисполнялось».
  `node tools/verify-contour.mjs` — только с `--etalon-only`.
- **Полигон и сборку не гоняешь:** `npm run test:core` и `node tools/build-framework.mjs` исполняет только
  оркестратор (`bugs/109` — параллельная нагрузка роняет `node`). Отдельный свод —
  `node tools/sandbox/sNN-*.mjs` — можно, по одному за раз; умер нативным крахом (`status 3221226505`,
  `run-fail-N.log`) — повтори ОДИН раз и доложи оба исхода.
- **Числа — только из вывода инструментов**; лог прогона — в ФАЙЛ во временном каталоге, не через `| tail`;
  каждая находка несёт ДОСЛОВНУЮ цитату `файл:строка`.
- **Скрипты правок и проб — файлом**, запуск по пути: инструмент Bash снимает уровень экранирования
  (`sed`, `node -e` с обратными слэшами врут молча). Не-ASCII в аргументы командной строки не передавай.
- **Соседние развёртывания на диске** (`d:/work/ai_sandbox/*`) — только чтение; имена проектов в отчёте —
  псевдонимами `project A…F` (правило №90), без имён людей.
- **Сеть:** `gh` — только чтение (`gh issue view`, `gh release view`); ничего не отправляй и не закрывай.
- **Время** — пробой `date '+%Y-%m-%d %H:%M %z'` в момент записи, не по памяти.
- Рабочий язык отчёта — русский; команды и цитаты — как в источнике.
