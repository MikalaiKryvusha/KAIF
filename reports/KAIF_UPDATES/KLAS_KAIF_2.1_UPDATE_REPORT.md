## 2. Дефекты — по убыванию цены

### D1. Модульное слияние ЗАДВОИЛО переведённые документы на двух языках

**Дословно из вывода установщика:**

```
↻ merged 18 module(s) into PHILOSOPHY.md (1 kept for you)
↻ merged 4 module(s) into .claude/skills/pause/SKILL.md (2 kept for you)
↻ merged 3 module(s) into .claude/skills/kaif-remove/SKILL.md (1 kept for you)
```

Результат в `PHILOSOPHY.md`: **21 английский модуль рядом с 21 русским**, файл **20 671 → 31 038 байт**.
Два модуля (`## The core idea`, `## Occam's Razor`) приклеены ПОСЛЕ русского чек-листа, то есть после
логического конца документа; блок `Learn once … The simplicity checklist` вставлен сплошным куском
В СЕРЕДИНУ русского списка принципов. Это ровно то удвоение, которое призвана предотвращать сеть
`translatedWholesale` (комментарий в ядре: *«a by-signature merge would read it as "all owner-added"
and DOUBLE the document with the English template (field: 25 files, +6534 lines)»*).

**Причины — ДВЕ РАЗНЫЕ, обе воспроизведены.** Я реализовал предикат сети из `kaif-core.mjs` отдельным
скриптом и прогнал на наших файлах:

```
PHILOSOPHY.md
  модулей в шаблоне: 21, порог baseFound: <= 1
  совпало сигнатур с диском: 2 -> ## KISS — Keep It Simple, Stupid | ### DRY — Don't Repeat Yourself
  кириллица в теле диска: true · кириллица в теле шаблона: false
  СЕТЬ translated-wholesale СРАБАТЫВАЕТ: НЕТ -> файл идёт в по-сигнатурное слияние

skills/pause
  совпало сигнатур с диском: 0
  кириллица в теле диска: true · кириллица в теле шаблона: true   ← сеть ослеплена
  СЕТЬ translated-wholesale СРАБАТЫВАЕТ: НЕТ
```

**Причина A (PHILOSOPHY): порог `wholesaleCeiling = 1` не переживает отраслевые термины.** Перевод
законно оставляет в заголовках `KISS` и `DRY` — их не переводят. Двух выживших сигнатур достаточно,
чтобы `baseFound (2) <= ceiling (1)` стало ложью, и полностью переведённый документ пошёл в
по-сигнатурное слияние. Порог «≤1» предполагает, что перевод меняет ВСЕ заголовки; реальный перевод
всегда оставляет термины.

**Причина B (pause, kaif-remove): в АНГЛИЙСКИХ шаблонах 2.1 есть русский текст в теле**, а третье
условие сети — `!script.test(bodyOf(newMods))`, то есть «во входящем шаблоне НЕТ письма владельца».
Я прогнал регулярку ядра `/[А-Яа-яЁё]/` по телам всех 34 шаблонов скиллов (без frontmatter):

```
kaif-remove/SKILL.md — кириллица в ТЕЛЕ (2 стр.):
  36: - A `--all` flag or an explicit phrase like "full removal" / "выжги полностью" counts as an explicit
  37: answer for **full**; "keep my artifacts" / "частично" counts as **partial**. Anything else → re-ask.
pause/SKILL.md — кириллица в ТЕЛЕ (1 стр.):
  32: "продолжаем"/"continue" picks up with zero re-derivation.

ИТОГО: кириллица в теле у 2 из 34 шаблонов скиллов 2.1
```

**Два шаблона из 34 содержат русские примеры — и ровно эти два получили двуязычный дубль.**
Совпадение исключено. Комментарий в ядре защищается от кириллицы, которую вставляет МАШИНА
(*«machinery-appended trigger aliases put the owner's script into every skill's frontmatter and would
blind the test»*), но не от кириллицы, которую написал АВТОР ШАБЛОНА.

**Лечение, которое я бы предложил:** судить не по «есть ли письмо владельца в шаблоне», а по ДОЛЕ:
язык шаблона определяется преобладанием, а не единственным вхождением. И порог `wholesaleCeiling`
считать не абсолютным числом, а долей выживших сигнатур (у нас 2 из 21 = 9.5% — это очевидный перевод).

### D2. Маркер не несёт `i18n`, и обновление его не ставит — защита по флагу выключена целиком

`.kaif/kaif.json` после обновления:

```json
{ "framework": "KAIF", "version": "2.1", "language": "ru", "tracking": "origin", … }
```

Ключа `i18n` нет. В ядре:

```js
const i18nTranslated = String((cur || {}).i18n || '').toLowerCase() === 'translated';
```

⇒ `false` ⇒ пофайловая защита `fileTranslated` не включилась ни разу, и единственным барьером осталась
эвристическая сеть из D1. При этом новости релиза заявляют: *«translated deployments ("i18n":
"translated") merge correctly»*. Проект, переведённый ДО 2.0, этого флага получить неоткуда: установщик
его не спрашивает, обновление не выставляет, `language: ru` в нём уже есть, но им не пользуются.

**Предложение:** при обновлении, если `language != en` И сеть `translatedWholesale` сработала хотя бы на
одном файле — записать `"i18n": "translated"` в маркер и сказать об этом в выводе. Один раз, механически.

### D3. «34 skills trigger-aliased» — на диск легло 23

Итоговая строка успеха обещает 34. Факт на диске:

```
ЕСТЬ строка алиасов (23): bug-research code-revision derive-styleguide end-chat experience fable-domain
  fable-judge fable-loop fable-method guarded-loop kaif-fork kaif-remove kaif-switch-origin kaif-update
  kaif-version owner-reviews owner-voice pause plan-epic plan-task propose-idea report-bug revision
НЕТ строки алиасов (11): autoloop check-backlog dayloop fix-vision help-kaif interview nightloop
  refresh-context release resume what-next
нет в языковом пакете (0)
```

Все 34 скилла есть в `templates/languages/ru/skill-triggers.json`. Алиас доехал только до тех файлов,
которые машинерия **переписала целиком**; для «разошедшихся» контент на диск не пишется, а счётчик в
сводке считает намерение, а не запись. `Trigger aliases (ru)` — машиночитаемая строка, которую сам
фреймворк объявляет непереводимой: её отсутствие тихо ломает распознавание команд на рабочем языке.

**Воспроизведение:** обновить любой проект с `language != en`, где часть скиллов адаптирована локально;
сравнить число в сводке с `grep -l 'Trigger aliases' .claude/skills/*/SKILL.md | wc -l`.

**Цена у нас:** 11 скиллов без алиасов. Дописал вручную. **Счётчик, который считает намерение, а не
результат, — это ровно тот класс, за которым охотится `/fable-judge`.**

### D4. Оба новых охранника 2.1 зелёные на ненастроенной установке

```
$ node .kaif/tools/kaif-canon-lint.mjs selftest
= .kaif/canon-lint-rules.json not found — canon lint is not configured yet (optional module).
  Seed it (see this file's header for the format); the linter grows with every fix.
exit=0

$ node .kaif/tools/kaif-provenance.mjs check
✅ provenance check OK (no canonArtifacts declared — only mark hygiene was checked)
exit=0
```

Заявленное назначение `selftest` — *«a selftest that proves every guard can fire»*. На ненастроенной
установке он не доказывает ничего и возвращает **успех**. Второй печатает **зелёную галочку** за то,
что проверять нечего. Оба предлагается «вставить в свои гейты» — вставленные сегодня, они дают
**вечнозелёный гейт**, и это не заметно ни по коду выхода, ни по значку.

Это тот самый класс, за который KLAS уже заплатил ночью 2026-07-31 (`EXPERIENCE.md` EXP-0042, «три
смертных греха охранника»): **(а) охранник обязан уметь вернуть ненулевой код; (б) пустой вход обязан
быть КРАСНЫМ — «нет данных» ≠ «нет проблем».** Фреймворк, который этому учит, нарушает это в
собственных модулях.

**Предложение:** отдельный код выхода для «не сконфигурировано» (например 3) и слово `SKIPPED` вместо
`✅`, чтобы гейт не мог молча зазеленеть. Плюс посеять `"canonArtifacts": []` в `kaif.json` при
развёртывании — сейчас `AGENT_GUIDE` велит объявить ключ, которого в маркере нет даже пустым.

### D5. Чекпойнты исполняют проверку в одном случае из семи

Новости релиза: *«checkpoints now EXECUTE their checks»*. Факт (`kaif-core.mjs`, `cmdCheckpoint`):
ветка исполнения существует только для `recheck`; `judge` требует строку вердикта. Остальные пять —
запись без проверки. Наблюдение прогона:

```
--- stale-claims ---   ✔ recorded: KAIF-UPDATE: stale-claims done       (ничего не проверено)
--- placeholders ---   ✔ recorded: KAIF-UPDATE: placeholders done       (ничего не проверено)
--- recheck ---        ✅ manifest satisfied: 65 files + 140 agent artifacts present
                       ✔ check ran green (executed by the checkpoint itself)
```

Обидно здесь то, что **у `stale-claims` и `placeholders` сканеры УЖЕ ЕСТЬ** — именно они породили
списки в задании. Перезапустить их в момент галочки стоит ноль. Сейчас слабая модель ставит обе галочки
бесплатно, а это ровно сценарий вашего же бага 17.

во ВСЕХ ДЕВЯТИ языковых пакетах** (`ar de es fr hi ja pt ru zh-Hans`). Агент, честно сверяющийся с
русским шаблоном, как ему велит задание, молча теряет новинку канона 2.1. Языковые пакеты протухают
относительно английского, и ничто это не ловит.

### D9. Новости релиза описывают правила сильнее, чем шаблон

Новости обещают: *«the truth↔mirror pairs registry (a mirrored/generated surface is edited at its
source and rebuilt, never patched in place)»*. В шаблоне `AGENT_GUIDE.md` абзац про реестр есть, а
клаузы нет:

```
"at its source"    → 0 вхождений
"patched in place" → 0 вхождений
"rebuilt, never"   → 0 вхождений
```

Между тем это самая ценная половина правила: без неё «реестр пар» — это таблица, а с ней — запрет
править зеркало на месте. Я перенёс клаузу в канон KLAS из новостей, а не из шаблона.

Второй случай той же болезни: новости приписывают канону `AGENT_GUIDE` строку *«EXPERIENCE entries:
Repro is REQUIRED, Trigger tags quoted before tasks, a repeating lesson gets mechanized»*. Проверка:

```
AGENT_GUIDE.md 2.1 :: "Repro"        → 0
AGENT_GUIDE.md 2.1 :: "Trigger tags" → 0
```

Правда живёт в `templates/EXPERIENCE.md`. Агент, назначенный на `AGENT_GUIDE`, потратил проход на
поиск несуществующего модуля.

Третий случай — самый заметный, потому что касается флагманской новинки релиза. Новости: *«STATUS.md is
now the living SUMMARY of the present (~200-line soft target, **warning-mode guard**)»*. Охранника нет:

```
$ grep -n '200\b' .kaif/kaif-core.mjs      → пусто
$ grep -n 'STATUS' .kaif/kaif-core.mjs | grep -i 'line|length|soft|warn'   → пусто
```

Единственное упоминание `STATUS.md` в ядре — исключение для сканера устаревших утверждений
(`kaif-core.mjs:440`). «Warning-mode guard» существует только как проза в шапке шаблона `STATUS.md`.
Наш файл дорос до **1928 строк** именно потому, что предупреждать было некому; прозой этот класс не
лечится — она и была всё это время в шапке.

### D12. Для переведённого файла `merge-diverged` не даёт списка новых модулей

`AGENT_GUIDE.md` отнесён в `merge-diverged` с честным пояснением «by-signature merge is impossible», но

переноса не гарантируется ничем, кроме внимательности агента, — и это единственное место всего
обновления, где нет ни одной механической проверки.

### D13. Обновление правит дерево, где `git diff` слеп

Не дефект KAIF (в KLAS обёртка вне git по решению владельца, идея 07), но машинерия — единственная
сторона, которая может это подстраховать. Цена всплыла в полный рост: когда 12 сабагентов волны 1
умерли на лимите модели посреди правок, **восстановить границу «что сделала машинерия / что успел
мёртвый агент» было нечем** — ни `git diff`, ни отката. Пришлось читать 8 файлов целиком и сверять с
шаблонами вручную.

**Предложение:** перед обновлением класть копии изменяемых файлов в `.kaif/backup-<from>-<to>/`
(манифест sha уже есть, тел нет). Тридцать строк кода превращают «обновление без страховки» в
«обновление с откатом» для любого проекта — и для тех, у кого обёртка под гитом, тоже: их `git stash`
не спасёт от правки, сделанной ДО коммита.

### D14. Плейсхолдер `<PROJECT_NAME>` заполнен в нижнем регистре

Первая строка засеянного `PROJECT_HISTORY.md`:

```
# klas — Project History (the chronicle)
```

Каноническое имя проекта — **KLAS** (`AGENT_GUIDE.md` → «Идентичность проекта»), и `STATUS.md` рядом
начинается с `# KLAS — Krinik Local Agent System`. Машинерия взяла имя из источника в нижнем регистре
(похоже, `package.json`/имя каталога) и подставила в **заголовок документа**, который человек читает
первым. Ирония в том, что новый канон 2.1 в этом же релизе вводит правило «право действия ≠ авторство
идентичности»: имя — никогда не решение агента. Машине это правило тоже стоит соблюдать: имя брать из
маркера/`AGENT_GUIDE`, а не из имени каталога.

## 4. Пожелания к 2.2

1. **Сеть распознавания перевода — по доле, а не по абсолютным порогам.** Считать долю выживших
   сигнатур (у нас 2 из 21) и долю письма владельца в теле, а не факт единственного вхождения. И
   выкинуть кириллицу из ТЕЛ английских шаблонов: `pause` и `kaif-remove` ослепили собственную защиту.
2. **Ставить `"i18n": "translated"` автоматически** при обновлении проекта с `language != en`, когда
   сеть сработала хотя бы раз. Флаг, который никто не может выставить, защищает ноль проектов.
3. **Счётчики в сводке должны считать ЗАПИСЬ, а не намерение.** «34 skills trigger-aliased» при 23 на
   диске — это отчёт о работе, которой не было. Если файл пропущен как разошедшийся, а машиночитаемая
   строка в него не доехала — это отдельная строка задания, а не молчание.
4. **Ни один охранник фреймворка не должен быть зелёным без конфигурации.** Код выхода 3 и слово
   `SKIPPED`. Ваши же доктрины (`fable-judge`, «охранник, доказанный мутацией») это требуют.
5. **Исполнять чекпойнты, у которых уже есть сканер** — `stale-claims` и `placeholders` перепроверяются
   бесплатно, потому что их сканеры породили сами списки.
6. **Для переведённых развёртываний — отдельный режим проверки.** Сейчас `update-verify` требует
   английских строк на диске и печатает 290 «absent» модулей. Правильный вопрос к переведённому файлу
   не «есть ли строка шаблона», а «покрыт ли СМЫСЛ модуля»; если машина этого не умеет — она должна
   молчать, а не выдавать гарантированный шум.
7. **Языковые пакеты: либо полные, либо честно помеченные неполными.** Минимум — сказать при
   развёртывании: «в пакете ru нет AGENT_GUIDE/PHILOSOPHY/скиллов; эти файлы приедут по-английски и
   требуют ручного переноса — список: …». Сейчас это выясняется постфактум.
8. **Раз обещан «warning-mode guard» на длину STATUS — пусть он существует.** Пять строк в `check`:
   посчитать строки `STATUS.md`, при превышении мягкой цели напечатать предупреждение со ссылкой на
   бонсай-подрезку. Наш файл дорос до 1928 строк ровно потому, что предупреждать было некому.
9. **Линтер на сам бандл перед релизом.** Он поймал бы D10 целиком за одну минуту: пункт 16 без
   `TESTING_FRAMEWORK`, `PROJECT_HISTORY` с нулём упоминаний в каноне, `(idea 17 §2)` в шаблонах,
   `plans/homework_*` при существующем `homeworks/`, рассинхрон `EXPERIENCE.md` со своим скиллом,
   абзац TASTE, потерянный во всех девяти языковых пакетах. Это ровно та работа, которую вы
   рекомендуете проектам (`/code-revision`), применённая к самому фреймворку.
9. **Резервная копия перед обновлением** — `.kaif/backup-<from>-<to>/` (D13).
10. **Класс «SEMANTIC REPLACE» в задании обновления.** Смена смысла существующего скилла (`/pause`)
    опаснее любого нового файла и должна выделяться из общего списка разошедшихся.
11. **Поставить исполняемую команду «покажи неотвеченные вопросы».** Канон 2.1 объявляет практику
