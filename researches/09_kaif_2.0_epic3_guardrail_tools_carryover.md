## Что именно было отложено (состав эпика — из plans/17, дословно по ideas/15)

1. **`kaif-provenance`** (15 §2.1) — механический провенанс ИИ-текста в канон-артефактах владельца:
   базлайн = коммит с чистым текстом владельца; блочное сопоставление token-F1 (пороги ~0.8/0.55);
   режимы `отчёт` / `--mark` (расстановка парных `[AI]…[/AI]`/`[AI-ed]…[/AI-ed]`) / `--check`
   (гейт: непомеченный ИИ-текст роняет сборку) / `--accept` (приёмка владельцем + реестр принятых);
   тонирование помеченных блоков в рендере.
2. **`/derive-styleguide`** (15 §2.2) — вход: образец владельца → выход: стайлгайд на утверждение
   (регистры, эталоны из текста владельца, словарь «одно понятие — одно слово») + список
   машинно линтуемых правил.
3. **Шаблон линтера канон-артефактов** (15 §2.6) — отменённое решение = запрещённая формулировка;
   принятое = стерегомая полная уникальная строка; страж проверяется на сломанной версии.
4. **Режимы строгости** (15 §2.10) — «черновик» (быстро, вне канона) / «канон» (полный конвейер);
   разметка шагов навыков «любая модель / только сильная»; машинно проверяемое проверяет код.

Предпосылка старта в plans/17 — «полевая обкатка конвенций 1.6» — **выполнена**: восемь отчётов и есть обкатка.

## Полевое ТЗ, которого не было при заведении plans/17

- Отчёт 02 (прямая цитата смысла): конвенция `[AI]`-пометок «держится только на дисциплине
  человека… без обещанного инструментария протухнет первой, а агенты начнут метить всё подряд» —
  просит минимум: greп-линтер «пометка без слова владельца» + правило «пометки живут только в
  перечисленных канон-артефактах». Это ровно `kaif-provenance --check` в его дешёвой форме.
- Отчёт 01 (D8): в сферах с машинно-потребляемым каноном (строка промпта → БД → LLM) пометка
  внутри артефакта — **порча данных**; носитель пометки — сопровождающий документ. Инструмент
  обязан знать это исключение с рождения (иначе `--mark` будет портить канон таких сфер).
- Полигон, названный в plans/17 (книга правил Unliminium), подтверждён отчётом 04 — проект жив,
  канон-артефакты реальные.
