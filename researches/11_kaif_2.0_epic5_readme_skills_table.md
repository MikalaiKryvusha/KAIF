## Факты

- Навыков в payload — **26** (по поддиректориям `framework/skills/`); в таблицах README
  присутствуют **все 26**, лишних нет, счётчики «26» в шести местах README верны.
- Обе таблицы (EN: строки 250–263; RU: 594–607) — **14 строк данных**; **7 строк несут по
  2–5 навыков** (в сумме 19): `/resume·/pause` · `/autoloop·/dayloop·/nightloop` ·
  `/refresh-context·/check-backlog` · `/report-bug·/bug-research` · `/propose-idea·/interview` ·
  `/revision·/fix-vision·/what-next` · пять `kaif-*` одной строкой. Требование владельца → таблицы
  должны стать **26-строчными**.
- EN и RU структурно идентичны; единственное содержательное расхождение: EN-описание `/resume·/pause`
  включает «push», RU (строка 594) — «закоммитить» без пуша (тот же класс потери нормы при
  переводе, что в отчёте 04, §9).
- Инлайн-списки «13 навыков» в Quick start (строки 157–159 / 500–502) — примеры, не перечень;
  требование владельца на них не распространяется (но проверить согласованность после правки).
