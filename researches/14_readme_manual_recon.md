8. Проход публичности: персональные данные третьих лиц/хосты/секреты в README не попадают.

зеркалит СТРУКТУРУ и жанровые нормы (скелет, таблицы, безличность, честные пределы — жанровые, не
стилометрические) в нейтральном регистре технического руководства. Это называется вслух, а не
маскируется.
