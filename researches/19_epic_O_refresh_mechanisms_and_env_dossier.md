## 1. Карта механизмов по системам [TESTED: 2026-08-07 · живой fetch доки + WebSearch; Claude Code — полный референс, конкуренты — по вторичным источникам]

### 1.1 Claude Code — референс-контракт (code.claude.com/docs/en/hooks, fetch 2026-08-07)

Пригодные эпику O события (полный список в доке — ~30 событий):

| Событие | Матчеры | Блокирует (exit 2)? | Роль в контуре O |
|---|---|---|---|
| `SessionStart` | `startup`, `resume`, `clear`, `compact`, `fork` | нет | впрыск «перечитай канон» на старте/после сжатия |
| `UserPromptSubmit` | — | да | stateful-таймер «>60 мин с последнего освежения» (дефолт timeout 30 с) |
| `Stop` | — | да (`decision: "block"` + `reason`) | страж «STATUS обновлён?» перед завершением ответа |
| `PreCompact` / `PostCompact` | `manual`, `auto` | PreCompact — да / PostCompact — нет | пред/пост-обработка сжатия (дублирует SessionStart(compact) — выбрать одно) |
| `PostToolBatch` | — | нет | периодическое напоминание в длинных прогонах без промптов |
| `FileChanged` | литеральные имена файлов | нет | слежение за самим каноном (watchPaths из SessionStart) |

Контракт: вход — JSON на stdin (`session_id`, `cwd`, `hook_event_name`, …); выход при exit 0 —
JSON на stdout, поле **`additionalContext`** впрыскивает текст в контекст модели, **кап 10 000
символов** (сверх — файл + превью-путь). Exit 2 = блокировка + stderr модели (только у
блокируемых событий). Конфиг: `.claude/settings.json` (проектный, коммитится) /
`settings.local.json` / `~/.claude/settings.json`; поля хэндлера: `type: "command"`, `command`,
`timeout`, `async`. Плейсхолдер `${CLAUDE_PROJECT_DIR}` — путь проекта.

### 1.2 Остальные системы — дельта против сверки адаптеров 2026-07-03

Хуки стали индустриальным стандартом за лето 2026 — несколько систем обзавелись ими ПОСЛЕ
последних сверок адаптеров (основная волна снимков — 2026-07-03, grok-build — 2026-07-16;
снимки в `framework/adapters/` хук-волну ещё не видят — ресинк карты = кандидат-задача O3):

| Система | Хук-механизм (состояние на 2026-08-07) | Для контура O |
|---|---|---|
| **Claude Code** | полный (см. 1.1) | референс: оба контура целиком |
| **Cursor** | `.cursor/hooks.json` (beta, с 1.7): `sessionStart`, `beforeSubmitPrompt`, `preCompact`, `stop`, pre/post tool | аналог референса почти 1:1; формат конфига свой |
| **OpenAI Codex** | `.codex/hooks.json`: `SessionStart`, `UserPromptSubmit`, `Stop`, `PreCompact`/`PostCompact` (май 2026) | аналог референса; скрипты в `.codex/hooks/` |
| **GitHub Copilot** | agent hooks (public preview; JetBrains GA-волна 2026-03): `userPromptSubmitted`, `preToolUse`, `postToolUse` | частично; `sessionStart`-аналог не подтверждён |
| **Windsurf/Cascade** | pre/post-action триггеры (вторичный источник) | частично; проверить при авторинге адаптер-хуков |
| **Cline** | lifecycle-хуки (путь «Memory Bank → хуки», предсказан в §11.3 researches/15) | частично |
| **Zoo Code** (приоритет №1!) | хуков в доке НЕТ — только allow/deny-листы команд и auto-approve гейты | **честный фолбэк: только markdown-ритуал** |
| **Grok Build** | заявляет чтение `.claude/`-раскладки ЦЕЛИКОМ, включая hooks; паритет с контрактом Claude Code — правдоподобен, но НЕ ВЕРИФИЦИРОВАН (адаптер, сверка 2026-07-16) | кандидат «референс-конфиг работает как есть» — проверить живьём до опоры |

**Честный вывод:** хуки есть у большинства, но контракты разные и версии беты; у приоритетной
Zoo Code хуков нет. Поэтому двухконтурность обязана быть честной: markdown-ритуал — полноценный
самодостаточный контур (не «деградация»), hook-контур — опциональное усиление там, где есть.
Порядок авторинга hook-конфигов: Claude Code (референс, фаза O3) → остальные по мере
верификации их контрактов живой докой (кандидаты пула, не скоуп 2.2).

## 2. Проект markdown-контура (обязательного) — правило освежения + свидетельство

**Правило освежения** (канон-секция AGENT_GUIDE, payload + обвязка, фаза O2). Триггеры
перечитывания яруса «re-read core» (девятка из таксономии N4 — второй список не заводим):

1. **Час:** прошло > 60 минут с последнего освежения в живой сессии (формула владельца «раз
   минимум в час»).
2. **Тяжёлая задача:** перед стартом задачи, проходящей тест тяжести (AGENT_GUIDE →
   «Дисциплина планирования»), в том же долгоживущем чате.
3. **После сжатия/паузы:** после компакции контекста, возврата из `/pause`, длинного простоя.
4. **Точки ритуалов:** `/resume` (полный проход — уже канон), `/refresh-context`, итерации
   длинных циклов (`/autoloop`, `/dayloop`, `/nightloop`, `/guarded-loop`).

**Свидетельство перечитывания** (DriftBench: recall ≠ adherence — пересказ правила не
доказывает следования). Предлагаемое решение по Оккаму — **двухчастное свидетельство**:

- **Маркер:** файл `.kaif/refresh-marker.json` (`{ "at": ISO, "docs": [...], "trigger": "..." }`),
  обновляемый агентом в момент освежения; в `.gitignore` (состояние сессии, не проекта).
  Машиночитаем: судья и хуки читают возраст маркера одной командой.
- **Цитата-приёмка:** обновление маркера легально ТОЛЬКО вместе с цитатой в чате одной
  конкретной строки из перечитанного, релевантной текущей задаче («освежил: STATUS п. 1 —
  „…“»). Маркер без цитаты — фрод класса ложного `[TESTED]`; строка охоты для `/fable-judge`
  (фаза O2 вшивает в hunt-list).

Отвергнутые альтернативы: строка в STATUS.md (git-шум на каждое освежение; STATUS — сводка
проекта, не журнал сессии); только цитата без маркера (непроверяема механически — хуку и судье
нечего прочитать); коммит-маркер (освежение не обязано рождать коммит).

## 3. Проект hook-контура (опционального модуля поставки)

**Состав** (минимум из мета-плана, все три — Claude Code; предикат + cooldown у каждого):

| Хук | Событие | Предикат (анти-шум) | Действие |
|---|---|---|---|
| канон-после-сжатия | `SessionStart` (matcher `compact\|clear`) | всегда (сжатие само — редкое событие) | `additionalContext`: ПРИКАЗ перечитать ярус re-read core + обновить маркер (не тела документов — кап 10k и token tax) |
| таймер освежения | `UserPromptSubmit` | возраст `refresh-marker.json` > 60 мин; cooldown — сам маркер (впрыск сбрасывает отсчёт только фактом освежения) | `additionalContext`: приказ освежиться до начала работы |
| страж STATUS | `Stop` | в сессии были правки/коммиты И STATUS.md не тронут дольше N часов; cooldown 1 раз/сессию | `decision: "block"` мягко — напомнить обновить STATUS (единственный блокирующий; nudging, не forcing) |

**Формат поставки:** скрипты в `.kaif/hooks/*.mjs` (Node — уже обязателен для KAIF) +
фрагмент-образец конфига; **KAIF не редактирует чужие `settings.json` молча** — установка
хуков = явный опциональный шаг с согласием владельца проекта (инструкция в модуле; прецедент
дефера `.gitattributes` из L5 — та же природа: мутация политики чужого репозитория).
Развёртывание без хуков не краснеет нигде (инвариант §9.10).

**Анти-шум как канон-требование:** впрыск — приказ, не документы; каждый хук несёт предикат
срабатывания и cooldown; частота пульса ограничена (наука: IFScale — плотность инструкций сама
разрушает следование; частые напоминания без cooldown — задокументированный антипаттерн).

## 4. Проект досье окружения + смок процедуры [TESTED: 2026-08-07 · процедура прогнана на машине истока, факты ниже — вывод проб]

**Процедура сбора** (образец — ansible facts: структурированный инвентарь хоста, снимаемый
заново, а не вспоминаемый). Пробы по осям, в КАЖДОМ доступном шелле отдельно (урок «разные
шеллы — разные миры»):

1. **ОС/железо:** версия ОС, CPU/ядра, RAM.
2. **Шеллы и кодировки:** какие шеллы есть (PS 5.1? pwsh 7? git-bash?), консольная кодировка,
   ANSI-кодировка по умолчанию (`Set-Content`-риск), локаль каждого шелла.
3. **Тулчейн:** node/npm/git/gh (+ версии), python, чем являются `tar`/`curl`/`find` в PATH
   каждого шелла (системный бинарь ≠ GNU).
4. **Git-политики:** `core.autocrlf`, credential helper.
5. **Пакетные менеджеры:** winget/choco/scoop (или apt/brew).
6. **Особенности поведения:** ссылки на оплаченные уроки (не дубли) — MSYS2-конвертация argv,
   BOM PS5.1, keep-alive Windows и т. п.

**Смок на машине истока (2026-08-07) — черновик нашего досье:**

| Факт | Значение (проба) |
|---|---|
| ОС | Windows 11 Pro 10.0.26200 |
| CPU/RAM | AMD Ryzen 7 5700G · 8 ядер/16 потоков · 32 ГБ |
| PowerShell | 5.1 Desktop (pwsh 7 НЕ установлен) |
| git-bash | GNU bash 5.2.21 (MINGW64), локаль ПУСТАЯ (`$LANG` не задан — корень класса EXP-0032: `grep -i` не кейс-фолдит кириллицу) |
| Кодировки | консоль 65001 (UTF-8), но ACP 1251 → `Set-Content` без `-Encoding utf8` пишет ANSI |
| node/npm | v24.15.0 / 10.8.2 |
| git | 2.43.0.windows.1 · `core.autocrlf=true` (уроки EXP-0005: `\r?\n` в регэкспах) |
| gh | 2.95.0, аутентифицирован (аккаунт MikalaiKryvusha) |
| python | C:\Python314 |
| `tar` | PS: `system32\tar.exe` (bsdtar) · bash: `/usr/bin/tar` (GNU) — РАЗНЫЕ программы |
| `find` | PS: `system32\find.exe` (Windows-фильтр строк!) · bash: `/usr/bin/find` (GNU) |
| `curl` | PS 5.1: **alias на `Invoke-WebRequest`** (молча ДРУГАЯ программа — `.Source` у алиаса пуст, проба обязана смотреть `CommandType`; находка судьи O1) · bash: `/mingw64/bin/curl` |
| Пакетный менеджер | winget 1.29.280 |

Смок подтвердил ценность процедуры наблюдением: пробы поймали ЖИВЬЁМ три класса, уже
оплаченных полем (шелло-зависимые `tar`/`find`, ACP-1251, пустая локаль git-bash), — досье
делает их видимыми будущей сессии ДО первого наступания.

**Формат секции** «Досье окружения» в AGENT_GUIDE (шаблон в payload, фаза O3): таблица
«факт → значение → проба-команда», шапка секции несёт **дату снятия**, **команду
перегенерации** и **staleness-правило: факты старше 4 недель — гипотеза, перепроверь пробой
перед тем, как на них опираться** (4 недели — интервал между полевыми обновлениями парка;
уточняется по опыту). Носитель процедуры — по Оккаму решить в O3: расширение
`/refresh-context` против отдельного навыка (склонность — расширение: отдельный глагол не
нужен, сбор досье и есть форма освежения знания об окружении).

**Граница DRY с «Гигиеной документов и текста»:** досье — ФАКТЫ машины (что установлено, чем
является `tar`, какая кодировка); гигиена — ПРАВИЛА ПОВЕДЕНИЯ, выведенные из инцидентов (текст
через файлы, читай записанное обратно). Досье ссылается на уроки по тегам (EXP-0005/0032/0034),
никогда не копирует их текст; правило поведения, найденное при сборе досье, уходит в гигиену
или EXPERIENCE, а в досье остаётся только ссылка.

## 5. Развилки и решения

**Развилок владельцу нет** — постановка идеи 20 пп. 3, 7 однозначна, интервал 60 минут взят из
формулировки владельца дословно («раз минимум в час»). Точечные решения агента (перечислены для
секции закрытия фазы, всё дёшево откатить): двухчастное свидетельство (маркер+цитата, §2);
маркер в `.gitignore`; три хука минимума и Stop — единственный блокирующий (§3); порядок
авторинга hook-конфигов «Claude Code первым» (§1.2); staleness 4 недели и склонность «процедура
досье — в `/refresh-context`» (§4).
