## §2. Граница браузера (источники)

- **File System Access API** пишет настоящий файл в выбранную папку только после выбора в системном диалоге и
  разрешения; «разрешать при каждом посещении» — с Chrome 122, всё равно через запрос
  ([Chrome for Developers — persistent permissions](https://developer.chrome.com/blog/persistent-permissions-for-the-file-system-access-api),
  [File System Access API](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access)). Под слово «никакого
  выбора» не подходит.
- **Скачивание** — видимая плашка «скачано» и папка «Загрузки». Не подходит.
- **Хранилище страницы** (localStorage · IndexedDB) браузер пишет сам, молча, в папку ПРОФИЛЯ — LevelDB, ключ
  `_<origin>\0<key>`, значение с байтом кодировки (0x00 UTF-16LE · 0x01 Latin-1)
  ([CCL — Chromium Local Storage](https://www.cclsolutionsgroup.com/post/chromium-session-storage-and-local-storage),
  [docs.rs chromium-storage-localstorage-core](https://docs.rs/chromium-storage-localstorage-core/latest/chromium_storage_localstorage_core/)).
  Профиль задаётся флагом `--user-data-dir` — а окно контура поднимает НАШ генератор. Отсюда путь: профиль окна — в
  папке проекта; значит, хранилище страницы — файл в папке проекта, записанный самим JS, без единого диалога.
- Отгружаемый генератор сегодня `--user-data-dir` не передаёт (`framework/tools/contour/review.mjs:783`) — окно живёт в
  рабочем профиле Edge владельца, черновик (`localStorage`, `:670–684`) — там же.

## §4. Предлагаемое устройство `[AI]`

`FORK: options <профиль окна в проекте + IndexedDB + безоконное чтение агентом | File System Access с диалогом | скачивание
в «Загрузки» | разбор LevelDB файлов самим Node> · price of error <потерянный ответ владельца; видимый диалог — нарушение
его слова> · consulted <слово владельца §1 · Chrome for Developers · CCL Chromium storage · пробы §3>`

1. Генератор поднимает окно с `--user-data-dir=<проект>/.kaif/contour-window` (строка в ignore до инструмента),
   `--no-first-run --no-default-browser-check --disable-features=msImplicitSignin,msEdgeSyncConsent,msEdgeFirstSyncOnFirstRun`
   (§3а); после запуска читает `account_info` профиля и называет вход вслух, если он случился; для владельца окно то же.
2. Страница пишет каждое поле при каждом вводе в IndexedDB (черновик) и помечает «нажато Сохранить»; сервер жив —
   ответ записывается, как сейчас; сервер погас — страница говорит «сохранено на этом компьютере, агент заберёт» вместо
   красной полосы.
3. Агент забирает: при следующем показе, `--queue --list` и `--check` генератор, увидев протухший замок с портом,
   поднимает тихий сервер на том же порте и безоконный браузер с тем же профилем; страница `/recover` читает IndexedDB и
   отдаёт серверу; «Сохранить» нажато — ответ записывается в решения; не нажато — черновик называется агенту поимённо.
4. Проверки: пробы §3/§3а перенесены в `tools/sandbox/probes/contour-answer-survives/` (сессия 64, на закрытии чата;
