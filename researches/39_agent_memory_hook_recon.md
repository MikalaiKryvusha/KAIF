## Вектор цели (Achieve)

Дать шагу MM1 доказательную базу: в какой МОМЕНТ система, которая помнит (мозг, нейросеть, агентская система), пишет новое и правит старое —
и как этот момент переносится на события, которые видит хук агентской системы, без таймера и без привязки к коммиту.

## §1. Мозг — запись на ошибке предсказания (снято с разведки полевого проекта; источники — её)

- **Новизна — несовпадение с ожиданием:** гиппокамп сравнивает предсказанное с пришедшим; не совпало — сигнал новизны, дофаминовая петля
  гиппокамп — VTA усиливает запись ([Lisman & Grace 2005](https://itb.biologie.hu-berlin.de/~kempter/Hippocampus_Journal_Club/Articles/lisman05.pdf),
  [Frontiers 2020](https://www.frontiersin.org/journals/human-neuroscience/articles/10.3389/fnhum.2020.00152/pdf)).
- **Величина ошибки решает, ПРАВИТЬ старое или ЗАВОДИТЬ новое:** малая ошибка при ВЫЗВАННОМ воспоминании — реконсолидация, правка; большая —
  новая память ([Durham: reconsolidation](https://durham-repository.worktribe.com/OutputFile/1390048),
  [Richter, bioRxiv](https://www.biorxiv.org/content/10.1101/805887.full.pdf)).
- **Схема:** новое, встраиваемое в существующую схему, запоминается быстрее ([Learning & Memory](https://pmc.ncbi.nlm.nih.gov/articles/PMC6049395)).
- **Граница события:** поток режется на события там, где предсказание трудно; память сильнее у границ
  ([Zacks, Kurby & Zacks 2008](https://www.gvsu.edu/cms4/asset/92386C7F-BF75-96ED-67D9FAA81701D122/kurby__zacks_2008.pdf),
  [Psychon Bull Rev](https://link.springer.com/article/10.3758/s13423-021-01954-5)).

## §2. Нейросети — запись по удивлению

- **Titans (2025):** память пишется тем сильнее, чем хуже она предсказала новый вход («удивление» — градиент ошибки); инерция — чтобы одно
  удивление не вытеснило следующее; затухание — забывание устаревшего ([arXiv 2501.00663](https://arxiv.org/pdf/2501.00663)).

## §3. Агентские системы — кто и когда пишет память проекта

- **Generative Agents (Park et al., 2023):** поток памяти с оценкой ВАЖНОСТИ каждого события (целое число, оценённое моделью; рутинные
  события — 1); **рефлексия запускается, когда СУММА важности накопленных событий превышает порог**, затем сумма обнуляется — не таймером
  ([agentpatterns.ai: memory stream](https://agentpatterns.ai/patterns/agent-design/generative-agents-memory-stream/),
  [LangChain generative_agents.memory](https://sj-langchain.readthedocs.io/en/latest/_modules/langchain_experimental/generative_agents/memory.html)).
- **Windsurf Cascade:** память пишется по ходу разговора, когда модель решает, что стоит запомнить, или по просьбе пользователя; привязана к
  рабочему пространству; сама дока советует правила / `AGENTS.md` для долговечного знания — авто-память менее надёжна
  ([docs.windsurf.com: memories](https://docs.windsurf.com/windsurf/cascade/memories.md)).
- **Claude Code (по сторонним источникам — сверить с официальной докой на MM1):** `CLAUDE.md` — правила, которые пишет человек; авто-память —
  заметки модели; ни то ни другое не принуждает ([ai-workshop.dometrain.com](https://ai-workshop.dometrain.com/docs/getting-started/first-steps/memory));
  хуки событий — `SessionStart` впрыскивает `additionalContext`, `PostToolUse` срабатывает после каждого вызова с его входом и выходом — так
  строят память сторонние модули ([claude-mem: hooks architecture](https://www.mintlify.com/thedotmack/claude-mem/hooks-architecture),
  [mem0: Claude Code](https://docs.mem0.ai/integrations/claude-code.md)). Отдаёт ли `PostToolUse` `additionalContext` агенту — официально
  не подтверждено поиском; прототип полевого проекта это НАБЛЮДАЛ живьём (`kumm-hook-review.md`: «все четыре дошли в контекст агента»).
- **Наблюдение поля (интервью агентов полевого проекта, `kumm-hook-review.md`):** слово владельца ПОСРЕДИ хода приходит внутри результата
  инструмента, а не событием промпта — хук промпта его не видит; общее окно на 10 минут глушит сильные моменты слабым.

## §4. Что переносится в механизм KAIF (вход в `FORK:` шага MM1)

| Момент записи (§1–§3) | Событие агентской системы | Носитель |
|---|---|---|
| ошибка предсказания: ожидал одно — пришло другое | `PostToolUse` с провалом по КОДУ выхода и stderr (не по словам вывода — ложные тревоги поля) | хук: «чего не знали документы?» |
| вызванное воспоминание + расхождение → ПРАВКА | `PostToolUse` на чтение документа знаний проекта (карты, STATUS, планы, разведка — не методички) | хук: «документ говорит то же, что ты знаешь?» |
| значимость усиливает запись | слово владельца: `UserPromptSubmit` И сообщение посреди хода (в результате инструмента) — оба | хук; правило владельца — дословно с цитатой |
| граница события | новое слово владельца после работы · смена задачи · конец хода | канон: строка `KNOWLEDGE:` в ритуалах закрытия и циклов (без блока остановки — развилка владельца) |
| понимание «в голове» без события | — (хук не видит рассуждения) | канон: обязательство KAIF к шагу «действуй» в точке вызова fable-цикла |
| накопленная важность, а не таймер (Generative Agents) | счёт значимых событий сессии; порог вместо окна 10 минут; рутинные события («сравни» на любом выводе, картинки) — вес 1 | хук: состояние по `session_id`, в `.kaif/` |

Вывод одной строкой: «момент новизны» живёт в рассуждении агента — поэтому основной носитель канонический (шаг в точке решения), а хук —
усилитель, который говорит на значимых событиях по накопленной важности, а не по часам; ни один источник не пишет память на коммите.
