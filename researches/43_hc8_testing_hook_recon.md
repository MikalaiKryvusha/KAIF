## 1. Что сходится в обоих полях

- Долг — запись в состоянии вне git (`.kaif/test-debt.json`): `{путь: {kind, at}}`; `PostToolUse` Write · Edit · MultiEdit файла, у которого
  есть вид, — запись долга и приказ в контекст (первая правка после чистого долга — полный: шаги канона тестирования; следующие — короткий,
  с числом).
- Гашение — `PostToolUse` Bash · PowerShell (и инструменты продукта, MCP игры): команда-прогон СВОЕГО вида гасит долг этого вида; сборка,
  `--check`, `--help`, `py_compile`, линтеры — гигиена, не гасят (оба поля поймали ложное гашение `--help` и самопроверку стражей).
- `Stop` с долгом → `{"decision":"block","reason": <приказ + список>}`; повторная остановка с `stop_hook_active` и той же подписью долга
  (ключи + последний момент) — пропуск: без вечного круга, долг остаётся.
- `--waive "<почему>"` — отказ с причиной в `waivers` (читает судья); `--status`; `--selftest` с мутантом «без записи долга».
- Сбой хука — молча код 0.

## 2. Что второе поле добавило (комментарий #176 и позже)

1. **Долг — всё, что меняет продукт, а не только код:** данные сборки (`modpack.json`, `.ini`, `.locres`, `.pak`) и сама раскатка (команды
   деплоя без `-DryRun`; `cp`/`Copy-Item` в папку продукта) — долг вида продукта; ключ раскатки — `deploy:<скрипт>`.
2. **Раскатку гасит только ЗАПУСК после неё** (снимок окна старого сеанса смотрит на старые файлы) — кроме горячей выкладки.
3. **Тело heredoc — данные, не команда** (имя скрипта игры в тексте кейса погасило долг).
4. **Шаблон «прогон» не пересекается с самопроверками проекта** (`tools/test-*.mjs` совпал с `tools/test-guards.mjs`).
5. **Открытые кейсы:** остановка читает таблицы `testcases/TC_*.md`, тронутые за 6 ч, — строка `[NOT-TESTED]` / `blocked` в колонке
   статуса — тот же долг; приказ «нужен владелец — позови голосом, `blocked` без зова — не исход».
6. Ключ долга — путь от общего корня нескольких репозиториев (сессия правит соседние).

## 3. Форма для поставки (предложение агента `[ИИ]`, к HC8)
