## 1. Критерии отбора

Проверялись: нативная совместимость с Kimi Code, активность разработки, признание пользователей, конкретная
работа, которую инструмент добавляет, и соответствие текущему стеку проекта. Количество звёзд само по себе
доказательством работы не считается; нужен живой манифест или проверка.

## 2. Superpowers — принять

Источники:

- Локальный checkout `D:/work/ai_sandbox/_tools/superpowers`, коммит `22f0b463`, 2026-11-03.
- https://github.com/obra/superpowers
- https://github.com/obra/superpowers/blob/main/docs/README.kimi.md
- GitHub API, снято 2026-11-21: 323 279 звёзд · 28 685 форков · репозиторий не архивирован;
  последний release v7.0.2 опубликован 2026-11-03; предыдущие релизы идут регулярно.

Проверенные факты:

1. Официальная документация содержит установку именно для Kimi Code через `/plugins`.
2. Нативный `.kimi-plugin/plugin.json` объявляет 15 навыков, `sessionStart.skill = using-superpowers` и
   отображение инструментов Kimi (`AskUserQuestion`, `TodoList`, `Agent`, `Skill`, `Read/Write/Edit/Bash`).
3. Навыки закрывают проектирование, планы, TDD, системную отладку, проверку перед завершением, code review,
   работу с worktree и завершение ветки. Это усиливает исполнение KAIF, не заменяя его канон.
4. Соседняя Kimi-сессия использует тот же нативный плагин. Это полевое свидетельство совместимости;
   отдельный acceptance prompt в текущей сессии ещё не выполнялся.

Штатная установка:

```text
/plugins install https://github.com/obra/superpowers
/new
```

Проверка после установки: `/plugins info superpowers` без диагностических ошибок; в новой сессии на prompt
`Let's make a react todo list` сначала загружается `brainstorming`. Текущий Bash не находит `kimi` в PATH,
поэтому установка идёт через интерфейс Kimi, без ручной записи managed plugins или `installed.json`.

## 4. Граница с KAIF

Superpowers — отдельный пользовательский плагин, не зависимость установщика KAIF. KAIF 2.10 не тащит чужой
репозиторий в бандл. После живой проверки можно записать рекомендацию в документацию, сохранив её опциональной.
