## 5. Найдено

- Регэксп строк происхождения разведчика (`researches/32` §2д Q-§2: «12 → 33, v2.4 → v2.7») нигде не записан — 12 → 33 один в один не
  воспроизводится; эта проба даёт 7 → 39 по своему, ЗАПИСАННОМУ регэкспу (`tools/sandbox/probes/ck0-canon-baseline.mjs`). Вектор тот же
  (0,8 → 3,3 на 100 строк); меряем впредь этой пробой.
- `wc -w` в Git Bash без `LC_ALL=C.UTF-8` завышает счёт слов русского текста: режет кириллическую «Р» (байты D0 A0) по второму байту 0xA0 —
  неразрывному пробелу однобайтовой локали. Корневое руководство v2.7: 13086 без локали · 12885 с `C.UTF-8` · 12889 проба (4 знака-одиночки
  `wc` словами не считает). Тот же класс, что EXP-0151 (#74): Git Bash без UTF-8-локали врёт о кириллице; английские шаблоны не задеты. Для
  критерия 1 слово «короче» меряется СТРОКАМИ (`wc -l`, локаль не влияет), слова — справочно, пробой.
- Дефектов продукта — ноль.
