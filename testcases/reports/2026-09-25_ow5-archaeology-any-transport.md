## 5. Найдено

1. **Два прежних случая оси стали бы красными по неправильной причине** (прогон 1): фикстура «находки · `read: none` · `prior: none`» теперь
   отказывается новым правилом раньше старого — перестроена (находки прочитаны), каждый случай стережёт своё правило; на v2.7 перестроенный
   случай зелёный, новый — красный кодом 0 → код 3. **Третий близнец класса — мутация 14 стража вопросов истока — пропущен и пойман
   полигоном** (прогон 9): поиск близнецов фикстур («hits · read: none» по `tools/` и `framework/`) сделан только после красного; после него
   близнецов нет. Урок того же класса, что EXP-0156: правишь правило — греп фикстур правила по всем селфтестам ДО полигона.
2. **Потеря смысла в тексте поставки, найденная до коммита**: при переносе английской строки руководства выпали слова «that outlive the task» —
   возвращены в тех же строках (1080).
3. **Зазор**: `--search` получает вопрос аргументом командной строки; вопрос со словом, начинающимся с `/`, Git Bash может развернуть в путь
   (класс «текст через файлы», `AGENT_GUIDE.md`) — слова вопроса сохраняются, добавляется шум путей; назван, не чинится (цена — лишние находки).
4. Ноль дефектов вне этого.
