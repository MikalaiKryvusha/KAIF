отдельный процесс; ПРОЧИТАНО: черновик старого образца показан блоком «Черновик прошлой редакции» с текстом, поле Q2 пусто; ответ Q1 →
статус «Записано. Осталось вопросов: 2 …», процесс жив, сторож завершился кодом 0 со строкой «Recorded: … — Q1 = A · questions left: 2»,
Q1 свёрнут в «архив решённого»; ответ Q2 → «Осталось вопросов: 1», `decision.json` несёт Q1 и Q2, `records: 2`; агент переписал Q3 при
открытой вкладке, «Записать» → полоса «Документ ИЗМЕНЁН …», текст ответа в кольце спасения, кнопка записи выключена, в решении и в документе
Q3 нет; «Открыть новую редакцию» → черновик переписанного Q3 блоком прошлой редакции, на новый Q3 не сел; ответ Q3 → контур завершился кодом 0,

## 5. Найдено

1. **Слабая проверка селфтеста** (прогон 3): `includes('location.reload()')` находила ту же строку в другом месте страницы — мутант «страница
   не перечитывается» выжил; проверка переписана на полную строку ветки частичной записи. Класс — страж, не доказанный против угрозы.
2. **Живой сервер селфтеста умирал в тихом окружении свода** (прогон 6): свод ставит терпение тишины 0,9 с, настоящая страница пульсирует,
   проверка — нет; пульс добавлен в живую часть селфтеста.
3. **Модель страницы в приёмке контура отстала от контракта** (прогон 10) — четыре места переписаны с причиной (запись несёт ревизию; черновик
   читается ключом страницы; «заполнить и записать» отвечает оба открытых вопроса фикстуры — последний ответ завершает контур, как прежде;
   комментарий без выбора — вопрос открыт, страница остаётся, затем закрытое окно завершает контур); селфтест получил свой срок в приёмке.
4. **Стоячая неточность шага OW5** (коммит `1ad0408`): спецификация контура §2, абзац двери в `KAIF_REFERENCE.md` и шаг 3d `/interview`
   обоих слоёв описывали дверь до OW5 (команда без локали, без поиска двери, без отказа «read: none») — исправлено здесь.
5. **Зазоры, названные соседней сессией полевого проекта** (сведения, не наше наблюдение; `plans/119` OW6): живость замка — по ответу сервера,
   а не по pid (Windows переиспользует PID); страница, чья ревизия устарела из-за ЧУЖОЙ записи, говорит «документ переписан», а не «ответ уже
   записан». Не чинятся в этом шаге — записаны.
6. Проба входов OW0 (`ow0-inputs.mjs`) печатает ABSENT у входов, которые съели OW5 и OW6, — ожидаемо для пробы времени OW0.
