ни проверки проекта; команда линтера из терминала на той же копии печатает прежнюю сводку (проверки разделов (2)–(5) `s26`).
РЕАЛЬНЫЙ МИР: накоплено — не участвует: импорт модуля не читает состояния проекта, поведение зависит только от файла модуля — проверено на
развёрнутой копии из поставки; данные и техника — эта машина, Windows, Node v24 — проверено на реальном; путь — инструмент проекта импортирует
модуль из `.kaif/tools/` — проверено на развёрнутой копии; сам полевой инструмент тикета — на машине проекта тестировщика (macOS, Node v23),
на этом диске его нет: подтверждение — полевым отчётом обновления 2.8.

## 5. Найдено

1. **Семь, а не четыре** — поправка OW0 подтверждена приёмкой: тикет насчитал четыре модуля, потому что читал только последнюю строку импорта.
2. **Зазор защиты** (тот же, что у контура с 2.6): запуск модуля через символическую ссылку на файл может сравниться как импорт и промолчать —
   на пути поставки (`node .kaif/tools/<модуль>`) не встречается; назван.
3. Ноль дефектов вне этого.
