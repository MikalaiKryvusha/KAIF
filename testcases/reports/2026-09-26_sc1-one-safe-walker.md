## 1. Работа

Критерий 16 `plans/117` (тикет origin #77 · находка Q-R1′), шаг SC1 `plans/123`. Скан устаревших заявлений о версии и шесть tool-модулей
обходили дерево сами: вложенные копии `.claude/worktrees/*` занимали лимит скана и прятали настоящий README; одна битая ссылка обрывала
обход внутри `try {} catch {}`, и скан печатал «no lines found»; `kaif-provenance check` падал на той же ссылке стектрейсом. Сделано:

- **Один обходчик** — блок `KAIF-WALK` в ядре: множество файлов — `git ls-files --cached --others --exclude-standard` (без git — обход с
  пропуском `.git`, `node_modules`, `.claude/worktrees`); вложенный репозиторий — не проект; битая ссылка — пропуск с именем
  (`walk: skipped N unreadable path(s) — …`); нечитаемый каталог — FAILED; git «could not open directory … No such file» — пропуск,
  иная причина — провал.
- **Восемь обходов на нём:** скан заявлений и скан анонимности ядра; `kaif-provenance` · `kaif-canon-lint` · `kaif-requirements-lint` ·
  `kaif-guard-lint` · `kaif-attribution-lint` · `kaif-scenario-lint` (шестой — найден нулёвкой). Пункт задания `stale-claims` при провале
  обхода говорит «could NOT see the whole tree», а не «no lines found»; чек модуля при провале — код 1.
- **Одна реализация — семь копий:** строка `FORK:` (`plans/123`) → B: источник — блок ядра, шесть модулей несут побайтные копии
  (модуль поставки не может импортировать ядро — прецедент стража 5k), `node tools/sync-walker.mjs` пишет копии, страж сборки 5l
  (`tools/check-framework.mjs`, `--selftest` — четыре ответа) отказывает разошедшейся копии.
- Записка §10 (пункт stale claims) и §14; заметка 2.8 для поля.
