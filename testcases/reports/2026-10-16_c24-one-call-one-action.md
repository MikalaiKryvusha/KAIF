## 1. Работа

Критерий 24 `plans/126` (тикет origin #146, слово владельца №145): поставка не предписывает склеенные `git add … && git commit … &&
git push`; правило «One tool call — one action» стоит в «Git workflow» шаблона руководства. Проверка критерия: `git grep -n "&& git
push\|&& git commit" -- framework` → пусто; `git grep -c "One tool call — one action" -- framework/AGENT_GUIDE.md` → 1.
Попутно — свод `s16`: случай CK5.6 «closing-gates перемеряет» в `8f20005` красный — он кодировал дефект поля, который UT3 убрал
(дверь бюджета при открытом задании обновления писала базу); правка соседней сессии 82 (дерево, 12:17) перестроила случай, проба
мутантов бюджета дописана под неё.
