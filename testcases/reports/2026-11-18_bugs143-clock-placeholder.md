- `bugs/139`: инвентарь нашёл ещё три места того же класса сверх двух известных (слот стенда руководства, форма археологии справочника,
  отказ доски шаблона конституции) — починены той же правкой.
- Проба полей UB5 краснела с `66a6b5c` (сессия 102 не перегнала её после `bugs/140`): её критерий принимал законные новые строки шаблона
  за ложный класс — переписан. **Исправлено 2026-11-18 02:26 +03:00 по судье сессии 103 (находка 1, REFUTED):** здесь стояло «доказательство … не
  переисполнялось — … критерий их по-прежнему судит» — ложно: судья переисполнил копию `dist` без образца заглушки, первая редакция критерия
  дала 3 BAD вместо 7 (печатная строка соавтора несёт ЗАПОЛНЕННОЕ значение и не совпадала с заглушкой шаблона). Критерий переписан: слиянием
  считается только строка, положительно опознанная как новая строка шаблона этой сборки; переисполнено — та же копия `dist` даёт ровно 7 BAD
  (поля #1–#7), настоящая сборка — 0 BAD, у поля #8 шесть новых строк опознаны слиянием.
- **По судье сессии 103 (находка 2):** первая редакция `codeSplit` держала заполнитель только в однострочном код-спане и закрывала ограду
  первой же «```» — переписано по правилам CommonMark (спан через перенос строки, ограда закрывается не короче открывающей); случай
  самопроверки «a code span across a line end … a four-backtick fence holds a three-backtick line» зелёный.
- Раннер `tools/sandbox/probes/mutants-of.mjs` (EXP-0214) — на этом дереве для хука окна 2 пробы OK; на дереве `76801dd` — «BAD
